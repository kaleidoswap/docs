## About

The Kaleidoswap API enables developers to integrate RGB-based liquidity services and trading functionalities into their applications. The API supports a variety of features, including real-time price updates, channel management, and seamless asset swaps.

Explore the [Getting Started](./GettingStarted.md) guide to begin integration.
