title: 从钱包提取资金
description: "从 KaleidoSwap 桌面应用提取比特币和 RGB 资产：链上与闪电两种方式的操作步骤、费率选择和发送前的核对要点。"
---

从钱包提取资金可以把比特币或 RGB 资产发送到其他地址，流程如下：


1. **打开提取界面**：点击左侧边栏的**「提取」(Withdraw)** 快捷操作按钮（也可从**「快捷操作」(Quick Actions)** 菜单进入）。这会打开提取弹窗。
2. **提取方式**：当你粘贴比特币链上地址、闪电发票／闪电地址或 RGB 发票时，提取方式会自动选定。
3. **输入金额**：指定要提取的比特币金额或 RGB 资产数量。
4. **费率**：链上交易可选慢速、普通或快速。
5. **核对交易**：仔细检查各项细节。
6. **确认并发送**：点击「提取」发起交易。

**BTC 与 RGB 链上提取的区别**：提取 RGB 资产的步骤与提取 BTC 几乎相同，唯一区别是你粘贴的是收款方的 RGB 发票，而不是比特币地址。盲化 UTXO 和 witness（基于地址）两种发票形式都支持，粘贴时应用会自动识别发票类型。
