## Browser Requirements

The KaleidoSwap Extension is built as a Manifest V3 web extension. The first closed beta is distributed as a Chromium-compatible zip archive for Developer Mode installation.

| Browser | Supported |
|---------|-----------|
| **Google Chrome** | Closed beta target |
| **Brave** | Closed beta target |
| **Edge** | Closed beta target |
| **Opera** | Closed beta target |
| **Firefox** | Not part of the first closed beta unless a Firefox build is provided |
| **Safari** | Not yet |

## Installation

### Closed Beta Zip (Developer Mode)

The first KaleidoSwap Extension release is an invite-only closed beta. There is no browser-store listing yet, and the extension source repository is not public yet. Invited testers receive a personal download link from the KaleidoSwap team, of the form `https://kaleidoswap.com/dl?t=...`. It always serves the latest beta build, so keep the email — the same link works for every update.

<Warning>
Only install beta archives shared through the official KaleidoSwap invite or support channel. Do not install forwarded archives from unverified sources. Your download link is personal to you; treat it as private.
</Warning>

<Steps>
  <Step title="Download the Beta Zip">
    Open the download link from your beta invite. It serves the current build as a zip archive.
  </Step>

  <Step title="Verify What You Downloaded">
    The published checksum and the maintainer's detached signature are available on the same link:

    ```bash
    # SHA-256 checksum of the current build
    curl -s "https://kaleidoswap.com/dl?t=YOUR_TOKEN&file=sha256"
    ```

    Compare it against the archive you downloaded:

    ```bash
    shasum -a 256 kaleidoswap-extension-beta-latest.zip
    ```

    To check the signature as well, fetch it with `&file=asc` and verify against the KaleidoSwap release signing key (`696F19C9DA0ADBE8B38E5346E007BFF05941433B`):

    ```bash
    curl -s "https://kaleidoswap.com/dl?t=YOUR_TOKEN&file=asc" -o kaleidoswap-extension.zip.asc
    gpg --verify kaleidoswap-extension.zip.asc kaleidoswap-extension-beta-latest.zip
    ```
  </Step>

  <Step title="Extract the Archive">
    Unzip the archive into a stable folder on your machine. Keep this extracted folder in place while the extension is installed, because the browser loads the extension from that folder.
  </Step>

  <Step title="Open Extensions Page">
    Navigate to `chrome://extensions` in your Chromium-based browser.
  </Step>

  <Step title="Enable Developer Mode">
    Toggle **Developer mode** in the top-right corner.
  </Step>

  <Step title="Load Unpacked">
    Click **Load unpacked** and select the extracted folder that contains `manifest.json`.
  </Step>

  <Step title="Pin the Extension">
    Pin the KaleidoSwap icon in your toolbar for easy access.
  </Step>
</Steps>

## First Launch

After installation, clicking the KaleidoSwap icon in your toolbar opens the wallet in the browser **side panel** (on browsers that don't support the side panel API, it falls back to a toolbar popup). On first launch, you are guided through the **onboarding flow**:

<img src="/assets/images/extension/01-welcome.png" alt="KaleidoSwap Extension first launch" style={{ maxWidth: "360px", width: "100%", height: "auto", display: "block", margin: "1.5rem auto" }} />

1. **Welcome screen** - Create a new wallet or import an existing phrase
2. **Password setup** - Create a secure password to protect the local wallet
3. **Recovery phrase backup** - Save the phrase that controls Spark, Arkade, and Nostr identity
4. **Optional RLN setup** - Connect an RGB Lightning Node, or skip and connect it later
5. **Ready** - Continue to the wallet dashboard

See [Getting Started](/extensions/kaleidoswap-extension/getting-started) for more information.

## Permissions

The KaleidoSwap Extension requests the following Chrome extension permissions:

| Permission | Purpose |
|-----------|---------|
| **Storage** | Store encrypted wallet data, preferences, and account configuration locally |
| **Tabs** | Coordinate approval and confirmation windows |
| **Alarms** | Run scheduled wallet/session tasks |
| **Notifications** | Notify the user about wallet events where supported |
| **Clipboard Read** | Read pasted invoices, addresses, and connection strings |
| **Side Panel** | Open the wallet in the browser side panel |
| **Declarative Net Request (with host access)** | Adjust request headers on the wallet's own API calls to already-permitted hosts |

The manifest also declares `host_permissions` for the specific endpoints the wallet talks to: KaleidoSwap services, block explorers and indexers, the RGB proxy, Spark/Flashnet, Arkade, and price APIs.

<Note>
The KaleidoSwap Extension stores the encrypted mnemonic in `chrome.storage.local`. Network calls are made only for the accounts and services you connect.
</Note>

## Updating

Closed beta builds do not auto-update through a browser store. When a new beta is available, open your download link again — it always serves the current build — extract it, then return to `chrome://extensions` and click **Reload** on the KaleidoSwap Extension card. If you extracted the new build into a different folder, remove the old unpacked extension and load the new folder.

Because beta builds ship a fixed extension ID (`mmldlmkphefjjbpbajnhnkbiahiabiog`), your accounts, balances and settings carry over across updates. Keep your recovery phrase to hand regardless.

## Uninstalling

To remove the KaleidoSwap Extension, follow the instructions provided by your browser.

<Warning>
Uninstalling the extension removes all locally stored wallet data. Make sure you have backed up your recovery phrase and any RGB Lightning Node backup material before uninstalling.
</Warning>
