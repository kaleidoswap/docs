## Client Initialization

### Creating a Client

<CodeGroup>
```typescript TypeScript
import { KaleidoClient, KaleidoConfig } from '@kaleidoswap/sdk';

const config: KaleidoConfig = {
  baseUrl: 'https://api.regtest.kaleidoswap.com',
  nodeUrl: 'http://localhost:3001',  // Optional
  apiKey: undefined,                  // Optional
  timeout: 30.0,                      // Optional
  maxRetries: 3,                      // Optional
};

const client = new KaleidoClient(config);
```

```python Python
from kaleidoswap import KaleidoClient, KaleidoConfig

config = KaleidoConfig(
    base_url="https://api.regtest.kaleidoswap.com",
    node_url="http://localhost:3001",  # Optional
    api_key=None,                       # Optional
    timeout=30.0,                       # Optional
    max_retries=3,                      # Optional
)

client = KaleidoClient(config)
```
</CodeGroup>

### Configuration Properties

| Property | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `baseUrl` / `base_url` | `string` | Yes | - | API base URL |
| `nodeUrl` / `node_url` | `string` | No | - | RGB Lightning Node URL |
| `apiKey` / `api_key` | `string` | No | - | API key for authentication |
| `timeout` | `number` | No | 30.0 | Request timeout in seconds |
| `maxRetries` / `max_retries` | `number` | No | 3 | Maximum retry attempts |

## Market Operations

### listAssets

List all available assets.

<CodeGroup>
```typescript TypeScript
const assets = await client.listAssets();
assets.forEach(asset => {
  console.log(`${asset.ticker}: ${asset.name}`);
});
```

```python Python
assets = client.list_assets()
for asset in assets:
    print(f"{asset.ticker}: {asset.name}")
```
</CodeGroup>

**Returns:** Array of `Asset` objects

---

### listPairs

### getQuoteByPair

Get a quote for a trading pair.

<CodeGroup>
```typescript TypeScript
// Quote with from amount
const quote = await client.getQuoteByPair('BTC/USDT', 1_000_000);
console.log(`RFQ ID: ${quote.rfqId}`);
console.log(`Price: ${quote.price}`);
console.log(`From: ${quote.fromAmount} -> To: ${quote.toAmount}`);
```

```python Python
# Quote with from amount
quote = client.get_quote_by_pair("BTC/USDT", from_amount=1_000_000)
print(f"RFQ ID: {quote.rfq_id}")
print(f"Price: {quote.price}")
print(f"From: {quote.from_asset.amount} -> To: {quote.to_asset.amount}")
```
</CodeGroup>

**Parameters:**
- `ticker`: Pair ticker (e.g., "BTC/USDT")
- `fromAmount` / `from_amount`: Amount to swap in atomic units
- `toAmount` / `to_amount`: Target amount (alternative to fromAmount)

**Returns:** `Quote` / `PairQuoteResponse` object

## Swap Operations

### initSwap

Initialize a swap (maker side).

<CodeGroup>
```typescript TypeScript
const result = await client.initSwap({
  rfq_id: quote.rfqId,
  from_asset: quote.fromAsset,
  from_amount: quote.fromAmount,
  to_asset: quote.toAsset,
  to_amount: quote.toAmount,
});
const { swapstring, payment_hash } = JSON.parse(result);
```

```python Python
result = client.init_swap({
    "rfq_id": quote.rfq_id,
    "from_asset": quote.from_asset.asset_id,
    "from_amount": quote.from_asset.amount,
    "to_asset": quote.to_asset.asset_id,
    "to_amount": quote.to_asset.amount,
})
import json
data = json.loads(result)
swapstring = data["swapstring"]
payment_hash = data["payment_hash"]
```
</CodeGroup>

**Returns:** JSON string with `swapstring` and `payment_hash`

### waitForSwapCompletion

Wait for a swap to complete with timeout.

<CodeGroup>
```typescript TypeScript
const finalStatus = await client.waitForSwapCompletion(
  paymentHash,
  180.0,  // timeout in seconds
  2.0,    // poll interval
);
```

```python Python
final_status = client.wait_for_swap_completion(
    payment_hash,
    timeout_secs=180.0,
    poll_interval_secs=2.0,
)
```
</CodeGroup>

**Parameters:**
- `paymentHash` / `payment_hash`: The payment hash to monitor
- `timeoutSecs` / `timeout_secs`: Maximum wait time in seconds
- `pollIntervalSecs` / `poll_interval_secs`: Polling interval in seconds

## WebSocket Operations

### createQuoteStream

Create a real-time quote stream.

<CodeGroup>
```typescript TypeScript
const stream = await client.createQuoteStream('BTC/USDT');
try {
  const quoteJson = await stream.recv(5.0);
  if (quoteJson) {
    const quote = JSON.parse(quoteJson);
    console.log(`Price: ${quote.price}`);
  }
} finally {
  stream.close();
}
```

```python Python
with client.subscribe_quotes("BTC/USDT") as stream:
    for quote in stream.iter_quotes(timeout=5.0, max_quotes=5):
        print(f"Price: {quote.price}")
```
</CodeGroup>

For more details, see the [WebSocket documentation](/sdk/websocket).
