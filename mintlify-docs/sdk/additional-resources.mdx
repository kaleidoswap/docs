The swap engine is a fork of [boltz-rust](https://github.com/SatoshiPortal/boltz-rust) by Bull Bitcoin (MIT).

## Protocol references

- [Boltz API documentation](https://docs.boltz.exchange/api/): the `/v2` swap protocol the SDK speaks
- [BIP85](https://github.com/bitcoin/bips/blob/master/bip-0085.mediawiki): deterministic entropy, used to derive the swap mnemonic
- [MuSig2 (BIP327)](https://github.com/bitcoin/bips/blob/master/bip-0327.mediawiki): cooperative key-path claims and refunds
- [Elements / Liquid](https://elementsproject.org/): confidential transactions and PSETs
- [RGB](https://rgb.tech/) and [rgb-lib](https://github.com/RGB-Tools/rgb-lib): the wallet library that handles USDT-RGB
- [Arkade](https://arkadeos.com/): the Ark implementation behind the Intents corridor
