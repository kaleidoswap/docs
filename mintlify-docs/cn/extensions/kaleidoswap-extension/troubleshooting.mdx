## 连接问题

<AccordionGroup>
  <Accordion title="无法连接到节点" icon="link-slash">
    **现象：** 连接失败或显示「已断开」(Disconnected)

    **解决办法：**
    1. 确认 **节点 URL** 填写正确
    2. 检查节点是否**正在运行且可访问**
    3. 使用本地节点时，确认它运行在预期端口上
    4. 使用远程节点时，检查网络／防火墙设置
    5. 使用 Biscuit／认证令牌时，确认**令牌仍然有效**
    6. 在**设置 > RGB > RLN 节点**（Settings > RGB > RLN node）中重新连接；LND/NWC 则在**设置 > Lightning Node**（Settings > Lightning Node）中重新连接
  </Accordion>

  <Accordion title="交易场所连不上" icon="plug-circle-xmark">
    **现象：** 交换功能不可用，或显示连接错误

    **解决办法：**
    1. 检查相关账户是否已连接
    2. 使用 KaleidoSwap 做市方交易对时，确认 RLN 状态
    3. 使用 Flashnet 路由时，确认 Spark 是否可用
    4. 尝试刷新交换界面
  </Accordion>

  <Accordion title="DApp 检测不到提供方" icon="eye-slash">
    **现象：** DApp 无法把 KaleidoSwap 扩展识别为钱包

    **解决办法：**
    1. 确认 KaleidoSwap 扩展**已安装并已解锁**
    2. 刷新网页
    3. 检查扩展是否对该站点**已启用**
    4. 确认 DApp 使用的是标准提供方——KaleidoSwap 扩展注入 `window.webln`（WebLN）、`window.webbtc`、`window.nostr`（NIP-07）、`window.bitcoin` 和 `window.rgb`
    5. 有些应用会等待就绪事件——扩展会派发 `webln:ready`、`webbtc:ready`、`nostr:ready`、`bitcoin:ready` 和 `rgb:ready`
  </Accordion>
</AccordionGroup>

## 支付问题

<AccordionGroup>
  <Accordion title="支付失败" icon="circle-xmark">
    **现象：** 发送支付时报错

    **解决办法：**
    1. 检查**余额**是否充足
    2. 确认**目标地址**填写正确
    3. Lightning 支付需要确认到目标存在可用**路由**
    4. 检查发送账户是否**在线且已同步**
    5. 稍等一会儿再重试
  </Accordion>

  <Accordion title="闪电支付一直处于待处理状态" icon="hourglass-half">
    **现象：** 一笔闪电支付显示为待处理，且发送功能对该目标被锁定

    **解决办法：**
    1. 钱包会在大约 3 分钟内持续检查支付状态；请等待它完成或失败
    2. 支付待处理期间，发送功能会对该目标保持锁定，以免重复支付
    3. 到**记录**（Activity）中查看最终状态，不要重复支付
  </Accordion>

  <Accordion title="发票生成失败" icon="receipt">
    **现象：** 无法生成接收发票

    **解决办法：**
    1. 检查**节点连接**
    2. 确认节点具备**入向流动性**（Lightning 场景）
    3. 尝试生成其他类型（用链上代替 Lightning）
    4. 重启扩展后重试
  </Accordion>
</AccordionGroup>

## 扩展问题

<AccordionGroup>
  <Accordion title="扩展无法加载" icon="puzzle-piece">
    **现象：** 点击图标没有反应，或弹出窗口空白

    **解决办法：**
    1. 打开 `chrome://extensions`，检查 KaleidoSwap 扩展是否**已启用**
    2. 尝试**先禁用再重新启用**扩展
    3. 清理浏览器缓存
    4. 重启浏览器
    5. 手动安装的版本可以尝试**重新加载**扩展
  </Accordion>

  <Accordion title="被锁在外／忘记密码" icon="lock">
    **现象：** 无法解锁扩展

    **解决办法：**
    1. KaleidoSwap 扩展无法找回密码
    2. 在锁定界面选择**忘记密码？重置钱包**（Forgot password? Reset wallet），并输入 `RESET` 确认。这会从当前浏览器中清除钱包。
    3. 选择**导入已有钱包**（Import Existing Wallet）并输入助记词
    4. 设置新密码
    5. 恢复 RGB 状态（通过云端备份提示或备份文件），并重新连接闪电节点等可选服务
  </Accordion>

  <Accordion title="余额不更新" icon="arrows-rotate">
    **现象：** 显示的余额是旧数据

    **解决办法：**
    1. 检查**节点连接**状态
    2. 点击余额卡片上的**刷新余额**（Refresh balances）
    3. 关闭扩展弹出窗口再重新打开
    4. 确认节点**已同步**
  </Accordion>
</AccordionGroup>

## 获取帮助

如果是疑问而不是报错，请查看[常见问题](/cn/extensions/kaleidoswap-extension/faq)；上游文档与相关链接见[更多资源](/cn/extensions/kaleidoswap-extension/additional-resources)。

其他情况请从下面的渠道中选择一个反馈问题，并附上：

1. 浏览器名称和版本
2. KaleidoSwap 扩展版本（Settings > About）
3. 闪电节点类型（RGB Lightning 节点、LND、NWC），如已连接
4. 复现步骤
5. 错误信息或截图
6. 诊断信息：**设置 > 发送反馈**（Settings > Send Feedback）→ **在消息中附加诊断信息**（Append diagnostics to message），或**下载诊断信息**（Download diagnostics）
