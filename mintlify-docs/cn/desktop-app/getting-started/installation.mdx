## 安装方式

安装 KaleidoSwap 桌面应用有两种方式：

### 1. 下载二进制文件

1. **下载**：从 [KaleidoSwap 下载页面](https://kaleidoswap.com/downloads) 或 GitHub [Releases](https://github.com/kaleidoswap/desktop-app/releases) 页面获取最新构建，选择与你操作系统匹配的二进制文件。
2. **校验**：安装前，用经 GPG 签名的 SHA256 校验和清单核对下载文件。详细步骤见[二进制文件校验指南](/cn/desktop-app/getting-started/verify-binaries)。
3. **安装**：执行该二进制文件即可运行应用。

### 2. 本地构建

#### 通用前置条件

- **Tauri 2.x**  
  确认已安装全部[官方 Tauri 前置依赖](https://v2.tauri.app/start/prerequisites/)（Rust、Node.js、pnpm）。
- **代码仓库**  
  ```sh
  git clone https://github.com/kaleidoswap/desktop-app
  cd desktop-app
  ```

#### 各平台专用说明

**Windows：**
- RGB Lightning Node 集成在 Windows 上尚未完全原生支持。要在 Windows 上使用 RLN，请在 Docker 容器中运行并远程连接 —— 参见[节点托管](/cn/desktop-app/getting-started/node-hosting)，其他远程节点方案见[故障排查](/cn/desktop-app/support/troubleshooting#connectivity)
- 安装 [vcpkg](https://github.com/microsoft/vcpkg)，用它安装 **openssl**、**sqlite3** 等库
- 确认已安装 **Microsoft Visual C++**（通过 Visual Studio 或 Build Tools）

**Linux：**
- 安装 `build-essential` 和 `pkg-config`
- 安装 CI 构建所用的 WebKitGTK / GTK 依赖：`libwebkit2gtk-4.1-dev`、`libwebkit2gtk-4.0-dev`、`libgtk-3-dev`、`libglib2.0-dev`、`librsvg2-dev`、`libappindicator3-dev` 和 `patchelf`
- 确认 Rust、Node.js 和 pnpm 均已正确安装

#### 构建与运行

1. **安装依赖**：  
   ```sh
   pnpm install
   ```
2. **构建 Tauri 应用**：  
   ```sh
   pnpm tauri build
   ```
3. **以开发模式运行 KaleidoSwap**：  
   ```sh
   pnpm tauri dev
   ```

## 节点配置选项

安装 KaleidoSwap 之后，你需要连接到一个 RGB Lightning Node。有两种选择：

### 方案 1：连接远程节点

如果你不想在本机运行节点，可以连接到远程 RGB Lightning Node：

- **自托管远程节点**：按照 [RGB Lightning Node 托管](/cn/desktop-app/getting-started/node-hosting)指南，在 VPS 或服务器上搭建自己的 RGB Lightning Node。
- **托管服务商**：连接由 ThunderStack 等服务商专业运维的节点。

**远程节点的优势：**
- 不占用本地资源
- 7×24 可用（托管方案）
- 配置流程更简单

### 方案 2：创建带集成节点的本地钱包

如果追求完全的控制权和隐私，可以直接在本机运行节点：

- 按照[创建新钱包](/cn/desktop-app/wallet/creating-wallet)指南，创建一个带集成 RGB Lightning Node 的本地钱包。

**本地节点的优势：**
- 完全掌控自己的节点
- 更强的隐私性
- 不依赖外部服务

<Note>
  本地节点集成在 **Windows** 上尚未完全原生支持。Windows 用户应选择上面的方案 1（远程节点：通过 [Docker](/cn/desktop-app/getting-started/node-hosting) 自托管，或使用 ThunderStack 等托管服务商）—— 详见[故障排查](/cn/desktop-app/support/troubleshooting#connectivity)。
</Note>

在继续 KaleidoSwap 的配置之前，请先选择最符合你技术水平和需求的方案。
