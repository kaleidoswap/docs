All four packages (Rust, Python, TypeScript, React Native) share one version number. Each entry lists breaking changes first. The full history, including fixes, is in the repository's [CHANGELOG.md](https://github.com/kaleidoswap/swap-sdk/blob/trunk/CHANGELOG.md).

## 0.12.0 (2026-10-19)

### Breaking changes

- **TypeScript: `createKaleidoMakerClient` refuses workers and extensions.** It already refused a page; it now also refuses Web, shared, and service workers and browser extension contexts. Pass `allowBrowser: true` to build it there on purpose. Plain Node is unaffected.
- **Rust and TypeScript: typed swap DTOs.** Create, status, and restore methods return types generated from the Rust definitions instead of `any`. Response amounts and heights are `bigint`; request literals reject unmodeled keys (including `pairId`); `RgbLock.cooperativeRefund` is `string | undefined`. Rust struct literals for `ClaimDetails`, `RefundDetails`, `SwapRestoreResponse`, `GetSwapResponse`, and `SwapEvent` must set the new optional fields.

### Added

- **Atomic BTC ↔ USDT-RGB swaps on L1:** `AtomicSwaps` in TypeScript and `atomic_*` methods in Rust and Python. See [RGB swaps](/sdk/rgb-swaps#atomic-swaps-on-l1).
- **Organization keys** for client-side partner attribution: `createKaleidoOrgClient`, `SwapClient.kaleido_org`, `KaleidoOrgClient`. See [Partner attribution](/sdk/partner-attribution).
- **Pay-through idempotency keys:** `create(request, { idempotencyKey })` and `supportsIdempotency()`.
- **Stateless claim and refund helpers** in TypeScript with confirmation and timeout checks. See [Claims and refunds](/sdk/claims-and-refunds#stateless-reconciliation-helpers-typescript).
- **`SwapScript.fromRestored`** rebuilds scripts from restore entries.
- **Lightning address and LNURL-pay lookup:** `resolveLightningAddress` / `resolve_lightning_address`.
- **Corridor discovery card:** `corridorCard()` and `corridorCardRaw()`.
- **Esplora chain-data helpers** in `@kaleidorg/swap-sdk/chain-data`.
- **Transaction recovery** from saved hex: `BtcLikeTransaction.fromHex`.
- `SwapWsApi.close()` (TypeScript) and `shutdown()` (Python) stop a status stream.

### Security

- Claims require trusted chain evidence and pin the lockup transaction before revealing a preimage; automatic claims fall back to the script path after a failed cooperative claim.
- Esplora broadcasts check the HTTP status and parse the returned txid.
- LNURL-pay resolution requires HTTPS on clearnet, rejects redirects, and verifies the invoice description hash.

## 0.11.0 (2026-10-12)

### Breaking changes

- **Rust core: RGB-aware Bitcoin swap scripts.** Rust struct literals for `Cooperative`, `TransactionOptions`, `BtcSwapScript`, and the submarine and reverse create responses gain optional fields (`swap_auth`, `rgb`); add `None` where you build them. `Currency` gains `UsdtRgb`. Python defaults the new fields; TypeScript is unchanged.

### Added

- **USDT-RGB submarine and reverse swaps** in Rust, Python, and TypeScript, with rgb-lib wallet integration. See [RGB swaps](/sdk/rgb-swaps).
- **RGB cooperative submarine refunds** (`rgb-coop-refund-v1`).
- **Cooperative refund authorization** with `swapAuth`, and signed credential recovery with `recoverSwapAuth`.

## 0.10.0 (2026-09-24)

### Breaking changes

- **Rust core:** chain-swap validation takes the preimage hash. TypeScript and Python call sites are unchanged.

### Added

- Swap responses are checked on every route: hashlock, timeout height and encoding, lockup txid, claim preimage, counterparty key, and dust.
- Multi-output claims and refunds.
- `@kaleidorg/swap-sdk/pay-through`, a client for the maker's pay-through API.

## 0.9.0 (2026-09-23)

### Breaking changes

- **The binding surfaces stop saying Boltz.** There are no aliases; rename on upgrade:

| Was | Now |
|---|---|
| `BoltzClient` | `SwapClient` |
| `BoltzWsApi` | `SwapWsApi` |
| `BoltzWsUpdates` | `SwapWsUpdates` |
| `TxParams.boltzBaseUrl`, `LiquidPsetParams.boltzBaseUrl` | `makerBaseUrl` |
| `TxParams.boltzTimeoutSecs`, `LiquidPsetParams.boltzTimeoutSecs` | `makerTimeoutSecs` |

### Added

- Versioning and security policies, and runnable TypeScript examples.
