## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="What is KaleidoSwap Desktop App?">
    KaleidoSwap Desktop App is an open source desktop application that enables trading of RGB assets on the Lightning Network. It provides a user-friendly interface for managing RGB Lightning nodes and connecting to Lightning Service Providers (LSPs).
  </Accordion>

  <Accordion title="What assets can I trade on KaleidoSwap Desktop App?">
    The wallet supports all four RGB schemas: NIA (Non-Inflatable Assets), CFA (Collectible Fungible Assets), UDA (Unique Digital Assets), and IFA (Inflatable Fungible Assets). The pairs currently traded on the platform are NIA assets (formerly known as RGB20) — client-validated smart contracts on Bitcoin that represent fixed-supply fungible tokens.
  </Accordion>

  <Accordion title="Is KaleidoSwap Desktop App custodial?">
    **No**, KaleidoSwap Desktop App is non-custodial. You maintain full control of your private keys and assets at all times. The application provides secure key management and encrypted backups.
  </Accordion>

  <Accordion title="Do I need to run my own RGB Lightning node?">
    **No**, you have two options:
    - Run your own RGB Lightning node
    - Connect to existing nodes through the application
  </Accordion>

  <Accordion title="How does the trading protocol work?">
    KaleidoSwap Desktop App uses a taker-maker model for trading:
    1. Makers provide liquidity and set prices
    2. Takers can view real-time price updates
    3. Trades are executed through atomic swaps via RLN API
    4. All trades are secured by Lightning Network and RGB Protocol
  </Accordion>

  <Accordion title="Why can't I trade all the sats on my side of the channel?">
    **Dust reserve (3,000 sats):** In RGB Lightning swaps, the taker (you) must always send 3,000 sats to the maker as part of the swap. These sats aren't lost — they act as a temporary "dust amount." When the maker completes the HTLC and sends assets back, you also receive 3,000 sats with the assets on top. So, you need to keep at least 3,000 sats untradeable in your balance to make the swap process work.

    Beyond the dust reserve, the tradeable amount is bounded by your channel's outbound capacity and by the per-asset limits the maker advertises for each route.
  </Accordion>

  <Accordion title="How secure are my assets?">
    KaleidoSwap Desktop App implements multiple security measures:
    - Non-custodial architecture
    - Encrypted channel backups
    - Secure key management
    - Trustless trading protocol
    - Client-side validation for RGB assets
  </Accordion>

  <Accordion title="Are my trades private?">
    Yes, KaleidoSwap Desktop App prioritizes privacy:
    - Channel operations can be private
    - Trade details are only known to participants
    - No KYC required for basic operations
  </Accordion>

  <Accordion title="What do I need to start trading?">
    To start trading on KaleidoSwap Desktop App:
    1. Install the desktop application
    2. Create or import a wallet
    3. Fund your wallet with Bitcoin
    4. Open Lightning channels
    5. Acquire RGB assets
  </Accordion>

  <Accordion title="How do I get RGB assets?">
    You can acquire RGB assets by:
    - Trading through KaleidoSwap Desktop App
    - Connecting to RGB LSPs
    - Participating in RGB token distributions
  </Accordion>

  <Accordion title="What are the minimum requirements?">
    Minimum requirements for running KaleidoSwap Desktop App:
    - Modern operating system (Windows, macOS, Linux)
    - 4GB RAM recommended
    - Stable internet connection
    - Sufficient storage for blockchain data if running a full node
  </Accordion>

  <Accordion title="How do I report bugs?">
    To report bugs:
    1. Check existing GitHub issues
    2. Provide detailed reproduction steps
    3. Include relevant logs and system information
    4. Submit through GitHub issues
  </Accordion>

  <Accordion title="Is there documentation for developers?">
    Yes, developers can refer to:
    - [API Documentation](/api-reference/introduction)
    - [RGB LSPS1 Specification](/api-reference/rgb-lsps1-apis)
    - [Trading Protocol](/api-reference/swap-apis)
  </Accordion>
</AccordionGroup>

## Get Help

Check the [Troubleshooting](/desktop-app/support/troubleshooting) for errors rather than questions. For anything else, report a problem through your preferred channel from the options below, including:

1. Your OS and version (macOS, Windows, or Linux)
2. KaleidoSwap Desktop App version
3. Node type (local or remote) and version
4. Steps to reproduce
5. Error messages or screenshots
6. Log files:
   - macOS: `~/Library/Logs/com.kaleidoswap.dev/`
   - Windows: `%APPDATA%\com.kaleidoswap.dev\logs`
   - Linux: `~/.local/share/com.kaleidoswap.dev/logs`
