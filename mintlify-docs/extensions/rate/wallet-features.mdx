## Asset Management

### Viewing Balances

The Rate dashboard displays all your assets:

- **BTC Balance Card** - Total Bitcoin balance with breakdown:
  - On-chain BTC
  - Lightning BTC
- **RGB Asset List** - All RGB-20 tokens with balances
- **Layer Filters** - Filter assets by: All Assets, On-chain, Lightning

### Asset Details

Tap any asset to view details:

| Field | Description |
|-------|-------------|
| **Ticker** | Short asset symbol (e.g., USDT) |
| **Name** | Full asset name |
| **Precision** | Decimal places |
| **On-chain Balance** | Amount held on-chain |
| **Lightning Balance** | Amount held on Lightning |

## Sending Payments

Rate automatically detects the payment type based on what you paste or enter in the destination field.

### Supported Destination Formats

| Format | Detected As | Example |
|--------|------------|---------|
| **BOLT11 invoice** | Lightning payment | `lnbc1...` |
| **RGB invoice** | RGB asset transfer | `rgb:...` |
| **Bitcoin address** | On-chain payment | `bc1q...`, `3...`, `1...` |
| **Node pubkey** | Keysend payment | `02abc...` |

### Send Flow

<Steps>
  <Step title="Enter Destination">
    Paste or type the destination address, invoice, or pubkey. Rate auto-detects the payment type.
  </Step>

  <Step title="Enter Amount">
    For addresses and keysend, enter the amount in sats or BTC. For invoices, the amount is pre-filled from the invoice.
  </Step>

  <Step title="Review">
    Review the payment details:
    - Destination
    - Amount
    - Estimated fee
    - Payment type
  </Step>

  <Step title="Confirm">
    Click **Send** to execute the payment. A status screen shows the result.
  </Step>
</Steps>

## Receiving Payments

Generate invoices and addresses to receive BTC or RGB assets.

### Receive Tabs

| Tab | What It Generates |
|-----|-------------------|
| **Lightning** | BOLT11 invoice for BTC or RGB assets |
| **On-chain** | Bitcoin address for on-chain deposits |
| **RGB** | RGB invoice for RGB asset transfers |

### Receive Flow

<Steps>
  <Step title="Select Tab">
    Choose Lightning, On-chain, or RGB.
  </Step>

  <Step title="Enter Details">
    - **Amount** (optional for on-chain) - How much to receive
    - **Memo** (optional) - Description for the payment
  </Step>

  <Step title="Generate">
    Click **Generate** to create the invoice or address. A QR code is displayed along with the text.
  </Step>

  <Step title="Share">
    - **Copy** the invoice/address to clipboard
    - **Show QR** for the sender to scan
    - Lightning invoices show an **expiration countdown**
  </Step>
</Steps>

## Deposit and Withdraw

### Deposit

Deposit BTC on-chain into your RGB Lightning Node:
1. Click **Deposit** on the dashboard
2. An on-chain Bitcoin address is displayed
3. Send BTC to this address from any wallet

### Withdraw

Withdraw on-chain BTC from your node:
1. Click **Withdraw** on the dashboard
2. Enter the destination Bitcoin address
3. Enter the amount
4. Review and confirm

## Activity History

View all your transactions in the **Activity** tab:

### Transaction List

- Lists all recent transactions
- Each entry shows: type, amount, status, and timestamp
- Filter by transaction type or status

### Transaction Details

Click any transaction to see:
- Full transaction details
- Transaction ID
- Amounts and fees
- Status
- Timestamp

## Settings

Access settings from the gear icon or bottom navigation.

### Nostr Account

- View your **public key** (npub)
- View and export your **private key** (nsec)
- Generate a new keypair

<Warning>
Never share your Nostr private key (nsec). Anyone with this key can sign events and act as you.
</Warning>

### Preferences

| Setting | Options |
|---------|---------|
| **Currency** | USD, EUR, etc. |
| **Theme** | Dark mode (default) |
| **Auto-lock Timeout** | 1, 5, 10, 30 minutes |

### Networks

- **Node URL** - Change or reconnect to a different RGB Lightning Node
- **Maker URL** - Configure the Kaleidoswap maker API endpoint
- **Connection history** - Quick-switch between recent node connections

### Security

- **Change Password** - Update your wallet password
- **Backup Wallet** - Export wallet data for backup
