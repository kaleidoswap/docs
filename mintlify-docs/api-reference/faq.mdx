## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="Should I call this API directly?">
    Prefer the [Swap SDK](/sdk/introduction). Every swap the maker creates must be verified against your own keys before you fund it, and claims and refunds are transactions you build and sign. The SDK does both, in TypeScript, Python, Rust, and React Native.
  </Accordion>

  <Accordion title="Is it compatible with Boltz?">
    Yes, for submarine, reverse, and chain swaps: the request and response shapes, the swap tree, cooperative MuSig2 signing, and the WebSocket envelope follow the Boltz `/v2` protocol. A Boltz client pointed at the maker's base URL works for those routes. Some upstream Boltz routes are not served, such as submarine claim co-signing, raw transaction broadcast, and BOLT12 offer management.
  </Accordion>

  <Accordion title="Do I need an API key?">
    No. Swaps can be created without credentials. Partners add an organization key (client side) or an organization API key (servers) to have swaps attributed to them. See [Conventions](/api-reference/getting-started#authentication).
  </Accordion>

  <Accordion title="What is swapAuth?">
    A per-swap credential returned once when a swap is created. Send it as `X-Swap-Auth` to accept a re-quote, make a rate decision, or request a cooperative refund. Store it with the swap.
  </Accordion>

  <Accordion title="Which networks are available?">
    Signet (Mutinynet) at `https://maker.signet.kaleidoswap.com`. Mainnet is not available yet.
  </Accordion>

  <Accordion title="What units are amounts in?">
    The asset's smallest unit: sats for BTC and L-BTC, the contract's smallest unit for RGB assets. LSPS1 routes use decimal strings.
  </Accordion>

  <Accordion title="How long is a quote valid?">
    A quote from `POST /v2/quote` carries an expiry timestamp. When you create a swap with `pairHash`, the maker rejects it with `400 pair_hash_mismatch` if the pair's terms changed since you read them.
  </Accordion>

  <Accordion title="Does the maker accept zero-conf lockups?">
    No. Pair cards advertise `maximalZeroConf: 0`; the maker waits for confirmations before acting on a lockup.
  </Accordion>

  <Accordion title="How do I swap with Arkade?">
    Lightning ↔ Arkade swaps use a separate request-for-quote corridor, not these routes. Use the Swap SDK's `IntentsCorridor`.
  </Accordion>

  <Accordion title="Can I call it from a browser?">
    Yes for public routes, subject to the maker's CORS policy. Never put an organization API key in browser code; use an organization key there instead.
  </Accordion>
</AccordionGroup>
