## 通道操作

`channel` 命令组用于直接管理本地节点上的闪电通道。

| 命令 | 用途 |
|--------|---------|
| `kaleido channel list` | 列出当前通道 |
| `kaleido channel open <peer>` | 向某个对等节点开通通道 |
| `kaleido channel close <channel-id> --peer <pubkey>` | 关闭通道 |

对等节点参数使用 `pubkey@host:port` 格式。关闭通道同时需要通道 ID 和 `--peer`；只有在对端无响应时才加 `--force` 做单方面关闭，因为它会把资金锁定到时间锁到期为止。

## 开通通道

```bash
kaleido channel open 03abc...@peer.host:9735 --capacity 100000
```

值得关注的选项：

- `--capacity`
- `--push-msat`
- `--asset-id`
- `--asset-amount`
- `--push-asset-amount`
- `--public` 或 `--private`
- `--with-anchors`
- `--fee-base-msat`
- `--fee-proportional-millionths`

染色通道示例：

```bash
kaleido channel open 03abc...@peer.host:9735 \
  --capacity 100000 \
  --asset-id rgb:abc... \
  --asset-amount 5000
```

## LSP 通道订单

如果你希望使用 KaleidoSwap 的 LSP 流程，而不是手动开通对等通道，请使用 `channel order`。

### 子命令

| 命令 | 用途 |
|--------|---------|
| `kaleido channel order create [client-pubkey]` | 创建通道订单，默认使用本地节点公钥 |
| `kaleido channel order get <order-id>` | 获取订单状态与详情 |
| `kaleido channel order pay <order-id>` | 用本地钱包资金支付订单（`--onchain` 或 `--offchain`） |
| `kaleido channel order decide <order-id>` | 提交费率决定 |
| `kaleido channel order estimate-fees` | 估算开通费用 |

### 创建订单

```bash
kaleido channel order create 03abc... \
  --lsp-balance 1000000 \
  --client-balance 500000
```

公钥是可选的，默认使用你的本地节点，因此为自己订购时，`kaleido channel order create --lsp-balance 1000000 --client-balance 500000` 是等价写法。

常用选项：

- `--confirmations`，默认 6
- `--funding-within`，默认 144 个区块
- `--expiry-blocks`，至少为 1
- `--refund-address`，默认使用本地节点的地址
- `--announce` 或 `--private`
- `--asset-id`
- `--lsp-asset-amount`，与 `--asset-id` 同时使用时必填
- `--client-asset-amount`，不得超过 `--lsp-asset-amount`
- `--email`
- `--yes`、`-y` 接受获取到的 RFQ 价格，非交互模式下必需

### 支付订单

```bash
kaleido channel order pay <order-id> --access-token <token> --offchain
```

用 `--onchain` 或 `--offchain` 选择资金来源；交互模式下 CLI 会询问，但在 `--agent` 或 `--json` 模式下必须恰好指定其一，并同时传入 `--yes`。链上支付可用 `--fee-rate` 指定 sat/vbyte。

染色通道订单示例：

```bash
kaleido channel order create 03abc... \
  --lsp-balance 1000000 \
  --client-balance 500000 \
  --asset-id rgb:xyz... \
  --lsp-asset-amount 5000 \
  --client-asset-amount 2000
```

## LSP 元数据

`lsp` 子命令组用于查看服务端元数据和网络详情：

| 命令 | 用途 |
|--------|---------|
| `kaleido channel lsp info` | 显示 LSP 信息和可用选项 |
| `kaleido channel lsp network-info` | 显示该 LSP 的网络元数据 |

在创建订单之前，或者在设定客户端默认值时，这些命令很有用。

## 实用操作顺序

```bash
kaleido channel lsp info
kaleido node swap pubkey
kaleido channel order estimate-fees --lsp-balance 1000000 --client-balance 500000
kaleido channel order create 03abc... --lsp-balance 1000000 --client-balance 500000
```

服务端交易流程通常与通道和流动性管理同时进行，详见[市场与交换](/cn/cli/market-and-swaps)；通道或订单无法完成时，请查阅[故障排查](/cn/cli/troubleshooting#channels-and-lsp-orders)。
