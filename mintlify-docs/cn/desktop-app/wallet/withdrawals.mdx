从钱包提取资金可以把比特币或 RGB 资产发送到其他地址，流程如下：


1. **打开提取界面**：点击左侧边栏底部的「提取」(Withdraw)，打开「提取资金」(Withdraw Funds) 窗口。
2. **粘贴目标**：在「地址或发票」(Address or Invoice) 中粘贴比特币地址、闪电发票、闪电地址或 RGB 发票。类型会自动识别。
3. **输入金额**（点击「最大」(Max) 使用全部余额）。闪电金额受通道容量限制。
4. **费率**（链上）：「慢速」(Slow)、「普通」(Normal)、「快速」(Fast) 或「自定义」(Custom)。
5. 点击「提取」(Withdraw，链上)、「支付发票」(Pay Invoice，闪电) 或「发送 RGB 资产」(Send RGB Asset，RGB)。
6. **确认提取** (Confirm Withdrawal)：核对明细后点击「确认」(Confirm)。

**BTC 与 RGB 链上提取的区别**：提取 RGB 资产的步骤与提取 BTC 几乎相同，唯一区别是你粘贴的是收款方的 RGB 发票，而不是比特币地址。盲化 UTXO 和 witness（基于地址）两种发票形式都支持，粘贴时应用会自动识别发票类型。对于 witness RGB 发票，还需设置「见证 UTXO 的比特币金额（聪）」(Bitcoin Amount (sats) for Witness UTXO)（最少 512 聪，建议 1,000-2,000 聪）。「作为礼物/捐赠发送」(Send as Gift/Donation) 会在不经接收方验证的情况下发送。
