This page takes you from nothing to a finished swap on signet, in TypeScript. It needs Node 22 or later, a Lightning wallet with signet sats, and a Liquid testnet address to receive into.

## 1. Install

```bash
npm install @kaleidorg/swap-sdk
```

## 2. List what the maker trades

No keys, no funds. If this prints routes, the SDK and the maker are both reachable.

```typescript routes.ts
import { init, SwapClient } from "@kaleidorg/swap-sdk";

await init();
const client = SwapClient.forNetwork("signet");

const catalogues = {
  "on-chain -> Lightning": await client.submarinePairs(),
  "Lightning -> on-chain": await client.reversePairs(),
  "chain -> chain": await client.chainPairs(),
};

for (const [kind, pairs] of Object.entries(catalogues)) {
  for (const [from, tos] of Object.entries(pairs)) {
    for (const [to, card] of Object.entries(tos)) {
      console.log(`${kind}: ${from} -> ${to}  ${card.limits.minimal}-${card.limits.maximal}  fee ${card.fees.percentage}%`);
    }
  }
}
```

Each route has a **card** with its limits (in sats for BTC and L-BTC), its fees, and a `hash` you pass back when you create a swap, to hold the maker to those terms.

## 3. Receive L-BTC from a Lightning payment

This is a [reverse swap](/sdk/reverse-swaps): you pay a Lightning invoice, the maker locks L-BTC for you, and you claim it.

```typescript swap.ts
import { init, SwapClient, SwapMasterKey, SwapScript, toJson } from "@kaleidorg/swap-sdk";
import { writeFile } from "node:fs/promises";

await init();
const network = "signet";
const makerUrl = "https://maker.signet.kaleidoswap.com/v2";
const liquidEsploraUrl = "https://blockstream.info/liquidtestnet/api";
const payoutAddress = process.env.LIQUID_ADDRESS!; // a Liquid testnet address you control

const client = new SwapClient(makerUrl);

// Keys and the swap secret come from a mnemonic you keep. Use a new index for every swap.
const master = SwapMasterKey.fromWalletMnemonic(process.env.WALLET_MNEMONIC!, network);
const index = 0n;
const claimKey = master.deriveSwapKey(index);
const preimage = master.derivePreimage(index);

// Create the swap. The SDK checks the maker's answer against your key and secret.
const card = (await client.reversePairs()).BTC["L-BTC"];
const swap = await client.createReverseSwap(network, {
  from: "BTC",
  to: "L-BTC",
  invoiceAmount: 50_000n,
  preimageHash: preimage.sha256,
  claimPublicKey: claimKey.publicKey,
  pairHash: card.hash,
});
await writeFile(`${swap.id}.json`, toJson({ index, swap })); // save before paying

console.log(`Pay this invoice:\n${swap.invoice}`);

// Wait until the maker's lockup confirms.
while ((await client.swap(swap.id)).status !== "transaction.confirmed") {
  await new Promise((r) => setTimeout(r, 5_000));
}

// Claim it. Broadcasting reveals the secret, and the maker settles your payment.
const script = SwapScript.fromReverse("liquid", network, swap, claimKey.publicKey);
const claim = await script.constructClaim(preimage.preimage, {
  outputAddress: payoutAddress,
  swapId: swap.id,
  keysSecretHex: claimKey.secretKey,
  makerBaseUrl: makerUrl,
  network,
  liquidEsploraUrl,
});
console.log("Claimed:", await claim.broadcast(network, undefined, liquidEsploraUrl));
```

Run it, pay the printed invoice, and the script claims the L-BTC once the maker's lockup confirms. The swap ends in `invoice.settled`.

<Warning>
This script keeps it short: a fixed index, a polling loop, and no failure handling. A real app keeps a counter of used indexes, saves signed transactions before broadcasting, and handles failed swaps. See [Common mistakes](/sdk/common-mistakes).
</Warning>
