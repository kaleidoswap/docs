## Key Features

- **Type Safety**: Full TypeScript support with comprehensive type definitions
- **WebSocket Support**: Real-time updates for trades, orders, and market data
- **Error Handling**: Consistent error handling across all SDK methods
- **Authentication**: Built-in support for API authentication
- **Examples**: Rich collection of examples to get you started quickly

## Getting Started

Choose your preferred SDK from the options above to get started. Each SDK includes:

- Installation instructions
- Quick start guide
- API reference documentation
- Code examples
- WebSocket integration guides
- Error handling patterns
