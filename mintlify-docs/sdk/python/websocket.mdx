## Overview

The Python SDK includes WebSocket support for real-time market data updates. WebSocket connections provide:

- **Live Quotes** - Real-time price updates
- **Market Events** - Instant notifications of market changes
- **Low Latency** - Faster than polling REST endpoints
- **Efficient** - Single connection for multiple subscriptions

## Quick Start

### Basic WebSocket Usage

```python
import asyncio
from kaleidoswap_sdk import KaleidoClient

async def main():
    client = KaleidoClient(
        api_url="https://api.staging.kaleidoswap.com/api/v1",
        node_url="<Your node URL>"
    )

    try:
        # Connect to WebSocket
        await client.connect()
        print("WebSocket connected")

        # Your WebSocket operations here

    finally:
        # Disconnect
        await client.disconnect()
        await client.close()

asyncio.run(main())
```

## Live Quote Streaming

### Subscribe to Real-time Quotes

```python
import asyncio
from kaleidoswap_sdk import KaleidoClient

async def stream_quotes():
    client = KaleidoClient(
        api_url="https://api.staging.kaleidoswap.com/api/v1",
        node_url="<Your node URL>"
    )

    # Define callback for quote updates
    async def quote_callback(quote):
        print(f"📊 Live Quote Update:")
        print(f"  Rate: {quote.exchange_rate}")
        print(f"  From: {quote.from_amount} {quote.from_asset}")
        print(f"  To: {quote.to_amount} {quote.to_asset}")
        print(f"  Time: {quote.timestamp}\n")

    try:
        # Connect WebSocket
        await client.connect()

        # Subscribe to BTC/USDT quotes
        await client.get_quote_websocket(
            from_asset="BTC",
            to_asset="rgb:q1O5Mn5y-7EoxdTy-xu3ChkP-HmhgGvJ-vQ3ryQ9-CcMxkfg",
            amount=100000,  # 0.001 BTC
            callback=quote_callback
        )

        # Keep connection alive
        await asyncio.sleep(300)  # Stream for 5 minutes

    finally:
        await client.disconnect()
        await client.close()

asyncio.run(stream_quotes())
```

## Configuration

### WebSocket Parameters

Configure WebSocket behavior when initializing the client:

```python
from kaleidoswap_sdk import KaleidoClient

client = KaleidoClient(
    api_url="https://api.staging.kaleidoswap.com/api/v1",
    node_url="<Your node URL>",

    # WebSocket configuration
    ping_interval=30,        # Ping interval in seconds
    ping_timeout=10,          # Ping timeout in seconds
    close_timeout=10,         # Close timeout in seconds
    max_size=2**20,           # Max message size (1MB)
    max_queue=32,             # Max message queue size
    compression=None          # Compression method (None, 'deflate', etc.)
)
```

### Handling Connection Issues

```python
import asyncio
from kaleidoswap_sdk import KaleidoClient
from kaleidoswap_sdk.exceptions import WebSocketError

async def robust_websocket():
    client = KaleidoClient(
        api_url="https://api.staging.kaleidoswap.com/api/v1",
        node_url="<Your node URL>"
    )

    max_retries = 3
    retry_delay = 5

    for attempt in range(max_retries):
        try:
            await client.connect()
            print(f"Connected (attempt {attempt + 1})")

            # Your WebSocket operations
            await asyncio.sleep(300)
            break

        except WebSocketError as e:
            print(f"WebSocket error: {e.message}")
            if attempt < max_retries - 1:
                print(f"Retrying in {retry_delay}s...")
                await asyncio.sleep(retry_delay)
            else:
                print("Max retries reached")

        finally:
            try:
                await client.disconnect()
            except:
                pass
            await client.close()
```

## Best Practices

### 1. Always Clean Up Connections

```python
async with KaleidoClient(api_url="...", node_url="...") as client:
    await client.connect()
    # WebSocket operations
    await client.disconnect()
    # Client auto-closes
```

### 2. Handle Reconnection

```python
async def auto_reconnect_websocket():
    while True:
        try:
            async with KaleidoClient(...) as client:
                await client.connect()
                # Operations
                await asyncio.sleep(3600)
        except WebSocketError:
            print("Reconnecting...")
            await asyncio.sleep(5)
```

### 3. Process Updates Asynchronously

```python
import asyncio
from collections import deque

quote_queue = deque(maxlen=100)

async def quote_callback(quote):
    # Queue updates for processing
    quote_queue.append(quote)

async def process_quotes():
    while True:
        if quote_queue:
            quote = quote_queue.popleft()
            # Process quote
            print(f"Processing: {quote.exchange_rate}")
        await asyncio.sleep(0.1)

async def main():
    async with KaleidoClient(...) as client:
        await client.connect()

        # Start processor
        processor_task = asyncio.create_task(process_quotes())

        # Subscribe to quotes
        await client.get_quote_websocket(
            from_asset="BTC",
            to_asset="USDT",
            amount=100000,
            callback=quote_callback
        )

        await asyncio.sleep(300)
        processor_task.cancel()
```

## Troubleshooting

### Connection Fails

**Issue**: WebSocket connection fails to establish

**Solutions**:
- Check API URL is correct
- Verify network connectivity
- Check firewall settings
- Ensure WebSocket port is not blocked

### Messages Not Received

**Issue**: Connected but no messages received

**Solutions**:
- Verify subscription was successful
- Check callback function is async
- Ensure connection is still alive
- Review ping/pong settings

### Memory Usage Growing

**Issue**: Memory usage increases over time

**Solutions**:
- Limit message queue size
- Process messages promptly
- Unsubscribe from unused channels
- Implement message rate limiting

## Comparison: WebSocket vs REST

| Feature | WebSocket | REST API |
|---------|-----------|----------|
| Latency | Low (~10-50ms) | Higher (~100-500ms) |
| Updates | Real-time push | Poll required |
| Efficiency | High | Lower |
| Complexity | More complex | Simpler |
| Use Case | Live data | One-time queries |
