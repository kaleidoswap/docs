## General Questions

<AccordionGroup>
  <Accordion title="When will the web app be available?">
    We're targeting Q3 2025 for public beta. Join our [Telegram](https://t.me/kaleidoswap) for updates.
  </Accordion>

  <Accordion title="Is it free to use?">
    Yes! The web app is free. You only pay network fees for transactions.
  </Accordion>

  <Accordion title="Which browsers are supported?">
    Chrome, Firefox, Safari, and Edge (latest versions).
  </Accordion>

  <Accordion title="Do I need to download anything?">
    No installation required - just visit the web app URL in your browser.
  </Accordion>
</AccordionGroup>

## Wallet & Security

<AccordionGroup>
  <Accordion title="Which wallets can I use?">
    MetaMask, WalletConnect, Coinbase Wallet, Rainbow, Trust Wallet, and more.
  </Accordion>

  <Accordion title="Is it safe?">
    Yes! Non-custodial architecture means you maintain control of your keys.
  </Accordion>

  <Accordion title="Can I use hardware wallet?">
    Yes, via wallet providers that support hardware wallets (e.g., MetaMask + Ledger).
  </Accordion>
</AccordionGroup>

## Trading

<AccordionGroup>
  <Accordion title="What can I trade?">
    RGB20 assets like USDT, XAUT, and other supported assets.
  </Accordion>

  <Accordion title="Are there trading fees?">
    Only network fees for Lightning transactions - typically very low (< $0.01).
  </Accordion>

  <Accordion title="How fast are swaps?">
    Lightning swaps complete in seconds.
  </Accordion>
</AccordionGroup>

## Comparison

<AccordionGroup>
  <Accordion title="Web app vs Desktop app?">
    **Web App**: Browser-based, quick access, casual trading
    **Desktop App**: Full features, node management, power users
  </Accordion>

  <Accordion title="Can I use both?">
    Yes! Both can connect to the same RGB Lightning node.
  </Accordion>

  <Accordion title="Which should I use?">
    Desktop app for full control, web app for quick trading access.
  </Accordion>
</AccordionGroup>
