## 集成标准

KaleidoSwap 向其他软件暴露的接口所遵循的规范。

<CardGroup cols={2}>
  <Card title="Model Context Protocol" icon="plug" href="https://modelcontextprotocol.io">
    每个 KaleidoSwap [MCP 服务器](/cn/ai-tools/mcp-servers)都实现的工具协议。
  </Card>
  <Card title="WebLN" icon="bolt" href="https://www.webln.dev/">
    闪电网络的浏览器 provider 标准，注入在 `window.webln`。
  </Card>
  <Card title="NIP-07" icon="signature" href="https://github.com/nostr-protocol/nips/blob/master/07.md">
    页面内的 Nostr 签名，注入在 `window.nostr`。
  </Card>
  <Card title="NIP-46" icon="tower-broadcast" href="https://github.com/nostr-protocol/nips/blob/master/46.md">
    通过 `bunker://` 字符串、经由中继完成的 Nostr Connect 远程签名。
  </Card>
  <Card title="QVAC SDK" icon="microchip" href="https://www.npmjs.com/package/@qvac/sdk">
    KaleidoMind 用于 LLM、嵌入、语音转文字和文字转语音的本地端推理运行时。
  </Card>
</CardGroup>

这些浏览器 provider 如何暴露给网页，见 [DApp 连接](/cn/extensions/kaleidoswap-extension/dapp-connectivity)。

## 获取帮助

报错请先看[故障排查](/cn/whats-kaleidoswap/troubleshooting)，术语请看[术语表](/cn/whats-kaleidoswap/glossary)。每个产品在自己的「参考」分组下也各有一份 FAQ 和故障排查。

反馈问题时，请附上你使用的产品与版本、所在网络（Signet 或主网）、复现步骤，以及错误信息或截图。各产品页面还列出了值得附带的额外信息，比如日志文件位置和查看版本的命令。
