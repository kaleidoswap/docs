KaleidoSwap is an open-source desktop application that enables seamless trading of RGB assets on the Lightning Network. It provides a user-friendly interface for managing RGB Lightning nodes, connecting to Lightning Service Providers (LSPs), and executing atomic swaps.

## Key Features

<CardGroup cols={2}>
  <Card title="RGB Lightning Node Management" icon="server">
    - Run your own RGB Lightning node or connect to existing ones
    - Manage channels and liquidity with ease
    - Built-in security features for safe asset transfers
  </Card>

  <Card title="RGB Asset Trading" icon="coins">
    - Trade RGB20 assets on the Lightning Network
    - Connect to RGB LSPs for instant liquidity
    - Real-time price updates and market data
    - Atomic swap execution with built-in security
  </Card>

  <Card title="Lightning Network Integration" icon="bolt">
    - Fast and low-cost transactions
    - Secure channel management
    - Automated channel backups
    - Support for both public and private channels
  </Card>

  <Card title="Security First" icon="shield-check">
    - Non-custodial architecture
    - Secure key management
    - Encrypted channel backups
    - Trustless trading protocol
  </Card>
</CardGroup>

## Architecture Overview

KaleidoSwap operates on a decentralized architecture combining RGB Protocol capabilities with Lightning Network scalability:

<AccordionGroup>
  <Accordion title="RGB Protocol">
    Enables the creation and transfer of client-validated smart contracts on Bitcoin, allowing for scalable and private asset issuance
  </Accordion>

  <Accordion title="Lightning Network">
    Provides instant, low-cost transactions and scalability through payment channels
  </Accordion>

  <Accordion title="LSP Integration">
    Lightning Service Providers offer liquidity and channel management services
  </Accordion>

  <Accordion title="Desktop Client">
    Provides a secure, user-friendly interface for all operations with full control of your keys
  </Accordion>
</AccordionGroup>
