## AI 工具包含什么

KaleidoSwap 通过开源软件，把交换、钱包和节点基础设施开放给 AI 代理。三类接入方式覆盖了全部场景：从一个完整的自主代理，到在现有客户端里接入单个 MCP 连接。

产品总览请见 [kaleidoswap.com/products/ai-tools](https://kaleidoswap.com/products/ai-tools)。

<CardGroup cols={2}>
  <Card title="KaleidoAgent" icon="robot" href="/cn/ai-tools/kaleido-agent">
    基于 KaleidoCLI 与 WDK 钱包原语的自主投资组合管理与钱包操作代理。
  </Card>
  <Card title="KaleidoMind" icon="brain" href="/cn/ai-tools/kaleido-mind">
    面向 Spark、RGB Lightning 与 Arkade 钱包的本地端推理引擎，支持聊天或语音操作。
  </Card>
  <Card title="MCP 服务器" icon="server" href="/cn/ai-tools/mcp-servers">
    为任意兼容 MCP 的客户端提供钱包、DEX、节点与支付工具。
  </Card>
  <Card title="Skills" icon="sparkles" href="/cn/ai-tools/skills">
    `SKILL.md` 操作手册，用于限定工具范围并承载执行计划。
  </Card>
</CardGroup>

<Warning>
  这里的每一种接入方式都会使用真实的 BIP-39 助记词签名，或直接驱动一个运行中的节点。请参阅[安装](/cn/ai-tools/installation)，了解如何把测试种子与主网种子分开保管。
</Warning>
