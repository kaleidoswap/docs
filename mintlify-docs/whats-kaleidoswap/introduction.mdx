KaleidoSwap is building the liquidity layer for Bitcoin-native atomic swaps, enabling anyone to exchange Bitcoin-based assets freely, privately, and without intermediaries.

Its vertically integrated stack spans end-user applications such as the Desktop App and the Browser Extension, a multi-language SDK, AI tools for autonomous AI agents and local AI brains, and market-maker software.

## Platform Overview

![KaleidoSwap platform diagram: Desktop, Extension, Mobile, and Web App clients connecting through the swap-sdk and wallet-sdk integration layer to Bitcoin, Lightning, and Layer 2 protocol icons, the KaleidoSwap LSP and market makers, and the KaleidoMind and KaleidoAgent intelligence layer](/assets/images/overview/kaleidoswap-platform-overview.jpg)

The stack is vertically integrated: a single SDK powers every client we ship and every third-party integration, so each surface talks to the same swap engine, the same protocols, and the same liquidity.

- **Clients & integrators** — Desktop, Extension, Mobile, and Web App, alongside third-party wallets, neobanks, payment processors, and AI agents building on the same interfaces.
- **Integration layer** — `swap-sdk` for swap integration (TypeScript, Python, Rust) and `wallet-sdk` for wallet primitives (TypeScript). [Start with the SDK →](/sdk/introduction)
- **Protocols** — Bitcoin on-chain and Lightning, plus the Bitcoin Layer protocols swaps can settle on. [How it works →](/whats-kaleidoswap/background)
- **Liquidity layer** — the KaleidoSwap LSP bootstraps liquidity today; external market makers join from 2027.
- **Intelligence layer** — KaleidoMind, the self-hosted AI brain (QVAC runtime, Skills and MCP libraries, fine-tuned models), and KaleidoAgent, an autonomous trading agent that runs against a local model or Claude and OpenAI. [Explore AI Tools →](/ai-tools/introduction)

Components marked LIVE are in production today; the rest are on the 2026 roadmap.

## For Builders

Build on KaleidoSwap with our SDKs, APIs, and AI Tools:

### Getting Started

<Steps>
  <Step title="Install the SDK">
    `npm install kaleido-sdk` for TypeScript, `pip install kaleido-sdk` for Python.
    [Installation Guide →](/sdk/getting-started)
  </Step>

  <Step title="Create a client">
    Point `KaleidoClient.create()` at a regtest, signet, or mainnet endpoint.
    [Client Reference →](/sdk/api-reference)
  </Step>

  <Step title="Request a quote">
    Fetch trading pairs and live quotes from the maker.
    [Market APIs →](/api-reference/market-apis)
  </Step>

  <Step title="Execute a swap">
    Run your first non-custodial atomic swap end to end.
    [How to Swap →](/sdk/how-to-swap)
  </Step>
</Steps>

<CodeGroup>
```typescript TypeScript
import { KaleidoClient } from 'kaleido-sdk';

const client = KaleidoClient.create({
  baseUrl: 'https://api.signet.kaleidoswap.com'
});

// Get available trading pairs
const pairs = await client.maker.listPairs();

// Get a quote
const quote = await client.maker.getQuote({
  from_asset: { asset_id: 'BTC', layer: 'BTC_LN', amount: 100000 },
  to_asset: { asset_id: 'USDT', layer: 'RGB_LN' }
});
```

```python Python
from kaleido_sdk import KaleidoClient

client = KaleidoClient.create(
    base_url="https://api.signet.kaleidoswap.com"
)

# Get available trading pairs
pairs = client.maker.list_pairs()

# Get a quote
quote = client.maker.get_quote({
    "from_asset": {"asset_id": "BTC", "layer": "BTC_LN", "amount": 100000},
    "to_asset": {"asset_id": "USDT", "layer": "RGB_LN"}
})
```
</CodeGroup>
