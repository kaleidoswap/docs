## 账户

KaleidoSwap 扩展从同一组助记词派生多个协议账户：

| 账户 | 持有内容 | 说明 |
|---------|---------------|-------|
| **Spark** | Spark BTC、Spark 原生资产、Lightning 收发 | 同时支撑 Flashnet 交换和跨链桥 |
| **Arkade** | Arkade BTC 和 Arkade 原生资产 | 进出通道（boarding/offboarding）和 VTXO 生命周期；可选轮换地址（HD）模式 |
| **Liquid** | L-BTC 以及 USDt 等 Liquid 资产 | 无节点、自主保管；默认主网 |
| **RGB-L1** | Bitcoin L1 上的 RGB 资产和 BTC | 无节点，运行于 WebAssembly；默认主网 |
| **RGB Lightning（RLN）** | 通过闪电通道流转的 RGB 资产 | 可选、实验性；连接后会替换 RGB-L1 后端 |
| **Bark** | Second 的 Ark 上的 BTC | 仅限测试网络（signet）；支持闪电收付；在**设置 > Bark**（Settings > Bark）中接收和入场 |

### 查看余额

KaleidoSwap 仪表盘会显示你的全部资产：

- **BTC 余额**，覆盖 Spark、Arkade、Liquid、Bitcoin L1，以及已连接时的 RLN Lightning
- 来自 Spark 账户的 **Spark 资产**
- 来自 Arkade 账户的 **Arkade 资产**
- 来自 Liquid 账户的 **Liquid 资产**
- 来自无节点 RGB-L1 账户、或已连接时来自 RLN 的 **RGB 资产**
- **协议和网络筛选器**，用于聚焦单一后端或某个网络分片

不同后端中代码相同的资产会合并为仪表盘上的同一行，展开后可查看各网络的余额明细。

### 隐藏资产

通过「你的资产」(Your Assets) 旁的**管理资产列表**（Manage asset list）按钮，你可以隐藏不想显示在仪表盘上的资产。隐藏的资产余额不受影响，只是从列表中移除，直到你取消隐藏。

### 资产详情

点击任意资产可查看详情：

| 字段 | 说明 |
|-------|-------------|
| **代码**（Ticker） | 资产简称（例如 USDT） |
| **名称**（Name） | 资产全称 |
| **精度**（Precision） | 小数位数 |
| **账户**（Account） | 持有该资产的协议账户 |
| **可用余额**（Spendable Balance） | 所选路由可动用的金额 |
| **网络标签**（Network Badges） | 该资产可用的位置，例如 Spark、Arkade、Liquid、RGB-L1 或 RGB-LN |

## 发送支付

KaleidoSwap 扩展会根据你在目标字段中粘贴或输入的内容，自动识别支付类型。

### 支持的目标格式

| 格式 | 识别为 | 示例 |
|--------|------------|---------|
| **BOLT11 发票** | Lightning 支付 | `lnbc1...` |
| **Lightning Address** | Lightning 支付 | `name@example.com` |
| **LNURL-pay** | Lightning 支付 | `lnurl1...` |
| **BOLT12 offer** | Lightning 支付 | `lno1...` |
| **RGB 发票** | RGB 资产转移 | `rgb:...` |
| **比特币地址** | 链上支付 | `bc1q...`、`3...`、`1...` |
| **Liquid 地址／URI** | Liquid 转移 | `lq1...`、`liquidnetwork:...` |
| **Spark 地址** | Spark 转移 | Spark 地址字符串 |
| **Arkade 路由** | Arkade 转移或离场路由 | 兼容 Arkade 的目标 |

<FeatureVideo name="address-auto-routing" title="粘贴任意地址，钱包自动选择网络" portrait />

### 发送流程

<Steps>
  <Step title="输入目标">
    粘贴、输入或扫描（二维码图片）目标地址或发票。KaleidoSwap 扩展会自动识别支付类型。
  </Step>

  <Step title="输入金额">
    对于地址、Lightning Address、LNURL-pay 和未指定金额的发票，请输入以聪计的金额，或点击输入框旁的单位切换为法币。对于带金额的发票，金额会自动填入。**最大**（Max）会填入可用余额，并在链上发送时预留网络费用。链上发送提供**慢 / 普通 / 快 / 自定义**（Slow / Normal / Fast / Custom）几档费率。
  </Step>

  <Step title="核对">
    选择**核对支付**（Review Payment），核对支付详情：
    - 目标
    - 金额
    - 所选路由／账户
    - 可用时显示的费用或路由提示
  </Step>

  <Step title="确认">
    选择**确认并发送**（Confirm & Send）执行支付。状态页面会显示结果。如果一笔闪电支付几分钟后仍处于待处理状态，发送功能会对该目标保持锁定；请到**记录**（Activity）中查看，不要重复支付。
  </Step>
</Steps>

</Note>

### 以法币输入金额

金额可以用法币输入：点击金额输入框旁的单位，即可在聪和法币之间切换，或选择其他币种。实际发送的始终是聪，换算后的数字随价格变动。凡是表单要求输入 BTC 金额的地方都支持此功能。

### 支付链接

在网页上点击 `bitcoin:`、`lightning:` 或 `lnurl:` 链接，会打开钱包并进入已预填的发送界面，或弹出 LNURL-auth / LNURL-withdraw 提示。

### 接收流程

<Steps>
  <Step title="选择资产">
    点击**接收**（Receive），然后选择**比特币**（Bitcoin，下一步再选账户）、**你的资产**（Your assets）中的一项、**添加资产**（Add an asset），或**从其他链跨链转入**（Bridge from another chain）。
  </Step>

  <Step title="选择路由">
    选择**按方式**（By method，即付款方如何支付：比特币地址、闪电发票、Spark 转账、Arkade 转账、Boarding、Liquid 地址）或**按账户**（By account，即资金到达的位置）。每一行都会显示预计速度和费用。
  </Step>

  <Step title="设置金额（可选）">
    留空表示任意金额，也可以输入以聪计的金额，或点击单位后以你的法币输入。
  </Step>

  <Step title="分享">
    复制地址或发票，或显示二维码。过期的闪电发票会被标记出来，并可重新生成。
  </Step>
</Steps>

## 接收与发送

### 接收

把 BTC 或受支持的资产接收到所选账户：

1. 在仪表盘上点击**接收**（Receive）
2. 选择资产和路由
3. 复制地址或发票，或显示二维码
4. 从外部钱包或服务发送资金

### 发送

发送是从所选账户支付到已识别的目标：

1. 在仪表盘上点击**发送**（Send）
2. 粘贴比特币地址、闪电发票、BOLT12 offer、Lightning Address、LNURL、RGB 发票、Liquid 地址或 `liquidnetwork:` URI、Spark 地址，或 Arkade 目标
3. 输入金额
4. 选择**核对支付**（Review Payment），核对建议路由后选择**确认并发送**（Confirm & Send）

<img src="/assets/images/extension/16-withdraw-form.png" alt="空白的发送界面，「可发送至」面板列出 Lightning、Bitcoin、Spark、Liquid、Arkade、RGB，以及跨链 USDC 或 USDT" style={{ maxWidth: "360px", width: "100%", height: "auto", display: "block", margin: "1.5rem auto" }} />

从 Spark 发送到外部链（EVM 网络、Solana 等）的方式，请参见[跨链桥](/cn/extensions/kaleidoswap-extension/bridge)。

## 设置

从底部导航打开**设置**（Settings）。页面分为**账户**（Accounts）、**支付**（Payments）、**安全**（Security）和**应用**（App）几个部分，底部是**锁定钱包**（Lock Wallet）和**断开账户**（Disconnect Accounts）。

<img src="/assets/images/extension/11-settings.png" alt="设置主页面，顶部是账户列表，下方依次是支付、安全和应用部分" style={{ maxWidth: "360px", width: "100%", height: "auto", display: "block", margin: "1.5rem auto" }} />

### 账户

- **Spark** - 网络选择、SDK 详情和连接状态
- **Arkade** - 网络选择、VTXO 设置、入场流程、生命周期设置，以及可选的轮换地址（HD）模式（支持通过 gap scan 恢复）
- **Arkade Intents** - 通过 RFQ 求解方用 Arkade 余额收付闪电。在**设置 > Arkade > Arkade Intents**（Settings > Arkade > Arkade Intents）中配置。收付都使用常规的发送和接收界面。核对页面会显示求解方费用；卡住的交换可以在同一设置页面中退款。
- **RGB** - 选择后端：**无节点**（Node-less，在设备上运行的 RGB，BTC 位于 Bitcoin L1；可设置网络、索引器 URL 和可选的 RGB 传输接口端点）或 **RLN 节点**（RLN node，通过直连或 Wallet Connect 连接你自己的 RGB Lightning Node）。在这里还可以管理 **UTXO**（UTXOs，可着色、已着色和普通 UTXO）、**发行资产**（Issue asset，从钱包铸造新资产）以及 RGB **备份**（Backup）
- **Liquid** - 网络选择以及 Esplora/waterfalls 同步接口端点（已提供一个高速默认端点，你也可以填入自己的）
- **Bark** - Second 的 Ark 网络：支持闪电收付的 BTC。仅限测试网络（signet）
- **Lightning Node** - 连接一个外部闪电节点，用于存入、提取和余额：**RGB Lightning 节点**、**LND**（REST HTTPS URL 加一个受限 macaroon）或 **Nostr Wallet Connect**。Core Lightning 和 LDK 显示为即将推出。同一时间只能启用一个节点
- **Nostr** - Nostr 身份（Nostr Identity）、Nostr Connect 和 Wallet Connect

### KaleidoSwap 用户名

你可以在**设置 > 支付 > Lightning Address**（Settings > Payments > Lightning Address）中申领一个 **Lightning Address 用户名**（`yourname@kaleidoswap.me`）。该用户名需要先连接 Spark，并指向你的 Spark 地址。输入时会实时检查可用性，并在你恢复钱包时自动重新关联。如果它不同步了，使用**刷新目标**（Refresh target）；如果想换个名字，使用**释放此用户名**（Release this handle）。

<img src="/assets/images/extension/20-handle-claim.png" alt="申领地址界面，包含名称输入框、kaleidoswap.me 后缀和实时可用性检查" style={{ maxWidth: "360px", width: "100%", height: "auto", display: "block", margin: "1.5rem auto" }} />

### Nostr

- **设置 > Nostr > Nostr 身份**（Settings > Nostr > Nostr Identity） - 查看公钥（npub）、在可用时查看／导出会话私钥，以及导入密钥，或把已导入的密钥恢复为从助记词派生的身份
- **设置 > 已连接应用**（Settings > Connected Apps） - 查看连接到钱包的每个网站和应用（包括 NIP-46（bunker）客户端），并可逐项撤销权限
- **设置 > Nostr > Nostr Connect**（NIP-46） - 生成 `bunker://` 连接字符串，让外部 Nostr 应用远程请求签名
- **设置 > Nostr > Wallet Connect** - 通过二维码以 NWC 方式配对外部应用，并设置带金额上限的预算

<img src="/assets/images/extension/39-settings-nostr.png" alt="设置中的 Nostr 页面，包含 Nostr 身份、Nostr Connect 和 Wallet Connect 三个入口" style={{ maxWidth: "360px", width: "100%", height: "auto", display: "block", margin: "1.5rem auto" }} />

<Warning>
切勿分享你的 Nostr 私钥（nsec）。任何拿到这个密钥的人都能签名事件并以你的身份行事。
</Warning>

### 安全

**设置 > 安全**（Settings > Security）是一个子页面，包含：

- **修改密码**（Change Password） - 更新钱包密码
- **Passkey 登录**（Passkey Login） - 注册或移除用于解锁钱包的 passkey（WebAuthn）
- **备份钱包**（Backup Wallet） - 确认密码后显示助记词；连接 RLN 时还可创建 RGB Lightning 节点备份文件。无节点 RGB 的备份位于**设置 > RGB > 备份**（Settings > RGB > Backup）。
- **自动锁定计时**（Auto-Lock Timer） - 设置无操作超时时间，从 1 分钟到 1 小时，或永不锁定
- **Chrome 同步说明** - 说明 Chrome 同步可能复制哪些数据，以及如何关闭扩展同步
