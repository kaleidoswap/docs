## Overview

The KaleidoSwap Extension includes an in-extension swap surface. It can use KaleidoSwap maker pairs when the optional RGB Lightning Node account is connected, and it can use Spark/Flashnet routes when Spark pools are available.

<img src="/assets/images/extension/10-swap.png" alt="KaleidoSwap swap screen" style={{ maxWidth: "360px", width: "100%", height: "auto", display: "block", margin: "1.5rem auto" }} />

<Note>
Swaps exchange one asset for another inside your wallet. To move funds between Spark and external chains (EVM networks, Solana, and more), use the [Bridge](/extensions/kaleidoswap-extension/bridge) instead.
</Note>

## Prerequisites

Before swapping:
1. At least one compatible swap venue must be available
2. The relevant account must be connected
3. You must have sufficient balance for the source asset and network fees

The amount input is gated by your **spendable** balance for the selected source asset, so you cannot quote more than the wallet can actually send.

## Swap Flow

<Steps>
  <Step title="Open Swap">
    Click the **Swap** button on the dashboard action grid.
  </Step>

  <Step title="Select Assets">
    Choose the **From** and **To** assets:
    - **From** - The asset you want to trade (e.g., BTC)
    - **To** - The asset you want to receive
  </Step>

  <Step title="Enter Amount">
    Enter the amount you want to swap. The extension fetches a quote from the selected venue showing:
    - Exchange rate
    - Output amount
    - Fees
    - Expiry
  </Step>

  <Step title="Review">
    The swap preview screen shows:
    - From asset and amount
    - To asset and amount
    - Exchange rate
    - Fee breakdown
    - Total cost
  </Step>

  <Step title="Confirm">
    Confirm the swap before the quote expires.
  </Step>

  <Step title="Track Status">
    The swap status screen shows a three-step progress tracker:
    - Requesting
    - Atomic Swap
    - Completing

    followed by a success or failure result.
  </Step>
</Steps>

## Real-Time Quotes

When you enter an amount, the KaleidoSwap Extension fetches a quote from the active venue:

| Quote Field | Description |
|------------|-------------|
| **Rate** | Exchange rate between the two assets |
| **Output Amount** | How much you will receive |
| **Fee** | Protocol and network fees |
| **Expiry** | How long the quote is valid |
| **Venue** | The route provider, such as KaleidoSwap maker or Flashnet |

Quotes update in real time as you change the amount.

### Slippage Protection

Flashnet swaps enforce a built-in maximum slippage of 5%: the minimum output amount is derived from that limit, and the swap fails rather than executing at a worse rate. Slippage is not user-configurable.

## Swap Status

After confirming, the status screen tracks the swap through three steps:

| Step | Description |
|------|-------------|
| **Requesting** | The swap order is being created |
| **Atomic Swap** | The swap is executing atomically |
| **Completing** | The swap is being finalized |

When the swap finishes, the screen shows a success result. If a step fails, an error message with the failure details is shown instead.

<img src="/assets/images/extension/25-swap-status.png" alt="Swap in progress with a three step tracker for requesting, atomic swap, and completing, showing the pair being exchanged" style={{ maxWidth: "360px", width: "100%", height: "auto", display: "block", margin: "1.5rem auto" }} />

<Note>
If no compatible venue or pair is available, the KaleidoSwap Extension shows an empty state instead of a quote. Wallet features such as deposits, withdrawals, balances, and settings still work.
</Note>

## Tips

<AccordionGroup>
  <Accordion title="Check your balance first">
    Make sure you have enough of the source asset to cover both the swap amount and any fees.
  </Accordion>

  <Accordion title="Confirm quickly">
    Quotes expire after a short period. Review and confirm promptly to avoid needing a new quote.
  </Accordion>

  <Accordion title="Read the failure message">
    If a swap fails, the status screen shows an error message with the failure details.
  </Accordion>
</AccordionGroup>
