The Swap SDK lets your wallet or app swap between Bitcoin, Lightning, Liquid, RGB, and Arkade against the KaleidoSwap maker. Your users never hand their funds to anyone: every swap is locked so that either both sides settle, or your user gets their money back.

## What you can build

| Outcome | Route | Signet | Guide |
|---|---|---|---|
| Pay a Lightning invoice from on-chain funds | BTC, L-BTC, L-USDT, USDT-RGB → Lightning | **Available** | [Pay Lightning from on-chain](/sdk/submarine-swaps) |
| Receive on-chain funds by paying over Lightning | Lightning → BTC, L-BTC, L-USDT, USDT-RGB | **Available** | [Receive on-chain from Lightning](/sdk/reverse-swaps) |
| Move funds from one chain to another | BTC → L-USDT | **Available** | [Move funds between chains](/sdk/chain-swaps) |
| Swap bitcoin and USDT on RGB | BTC ↔ USDT-RGB | Over Lightning: **available**. Atomic on L1: regtest only | [Swap BTC and USDT on RGB](/sdk/rgb-swaps) |
| Pay and receive Lightning from an Arkade wallet | Arkade ↔ Lightning | **Available** | [Lightning to and from Arkade](/sdk/arkade) |
| Let a Lightning payer fund an on-chain payout | Lightning → any address | When the maker enables it | [Pay an address from Lightning](/sdk/pay-through) |

Mainnet is not available yet: asking the SDK for it returns an error, never another provider. The maker's catalogue (`submarinePairs()`, `reversePairs()`, `chainPairs()`, the corridor card) is the source of truth, so read it at runtime. See [Networks](/sdk/networks).

## What the SDK does, and what your app does

| The SDK | Your app |
|---|---|
| Derives each swap's keys and secret from your wallet mnemonic | Stores the swap mnemonic and a counter of used swap indexes |
| Creates the swap and **checks the maker's answer** against your keys before you fund anything | Funds the lockup or pays the invoice from its own wallet |
| Builds and signs claim and refund transactions | Stores each swap record, and each signed transaction before broadcasting it |
| Tells you whether a claim or refund is possible right now | Checks open swaps on start, on resume, and on a schedule |

The SDK holds no funds, runs no background timers, and stores nothing. That keeps it small and lets it run anywhere, but it means **your app is responsible for persistence and for coming back before a swap's deadline**. [Common mistakes](/sdk/common-mistakes) lists what goes wrong when it does not.

## Packages

One Rust engine, published for four runtimes. All four share one version number.

| Runtime | Package |
|---|---|
| TypeScript (browsers, Node, extensions) | `@kaleidorg/swap-sdk` |
| React Native (iOS, Android) | `@kaleidorg/swap-sdk-react-native` |
| Python | `kaleidorg_swap_sdk` |
| Rust | `kaleidorg-swap-sdk` from a git tag |

<Note>
Running your own RGB Lightning Node and want to control it from code (channels, RGB assets, payments)? That is the [Node SDK](/cli/node-sdk/introduction), documented with the CLI.
</Note>
