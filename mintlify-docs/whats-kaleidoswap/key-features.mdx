## Multi-Asset Management

### Full Node Control

KaleidoSwap allows you to run a self-hosted RGB Lightning Node or connect to a remote one.

<Tabs>
  <Tab title="Run Your Own Node">
    **Self-Hosted RGB Lightning Node**
    
    Take full control of your infrastructure with a locally running node.
    
    - Maximum privacy
    - Direct P2P connections
    - No reliance on third parties

    ```bash
    # Set up and start your RGB Lightning node
    kaleido setup --mode local --create-node --defaults
    ```
  </Tab>

  <Tab title="Connect to Existing Node">
    **Remote Node Connection**
    
    Connect to a professionally hosted node or your own remote server.
    
    - Access from multiple devices
    - Managed infrastructure options
    - Connect via REST, gRPC, or WebSocket
  </Tab>
</Tabs>

## Multi-Protocol Trading

### Atomic Swaps

Execute trustless, instant asset swaps without intermediaries.

**Supported Swap Types**:

<CardGroup cols={3}>
  <Card title="Lightning to Lightning RGB Asset Swaps" icon="bolt">
    Swap RGB assets (like USDT) directly for BTC through Lightning channels.
  </Card>

  <Card title="On-Chain to Lightning Liquidity Management" icon="arrow-right-arrow-left">
    Open channels with your on-chain funds for instant trading.
  </Card>

  <Card title="Lightning to On-Chain Settlement" icon="bitcoin">
    Move assets from Lightning channels back on-chain for cold storage.
  </Card>

### Trading Features

<AccordionGroup>
  <Accordion title="Multiple Order Types" icon="list-check">
    - **Market Maker** — automated quotes filled instantly against liquidity providers
    - **Manual Swaps** — pick the counterparty and rate yourself for a single trade
    - **DCA** — scheduled recurring buys or sells to average into a position over time
    - **Limit Orders** — set a target rate and execute only when the market reaches it
  </Accordion>

  <Accordion title="Real-Time Quotes" icon="chart-line">
    - Live market rates for every trading pair
    - Estimated receive amount before you confirm
    - Exchange rate and fees shown on each quote
    - Price impact calculated per trade
  </Accordion>

  <Accordion title="Slippage Protection" icon="shield-halved">
    - Set a maximum acceptable slippage per trade
    - Swaps abort if the rate moves beyond your limit
    - Time-limited quotes, confirmed before they expire
  </Accordion>

  <Accordion title="Order History" icon="clock-rotate-left">
    - Full swap history in the **History** tab
    - Detailed execution data per swap
    - Records for reconciliation and accounting
  </Accordion>

  <Accordion title="Multiple LSP Support" icon="handshake">
    - Connect to multiple liquidity providers
    - Compare rates across market makers
    - Pick the maker yourself on manual swaps
  </Accordion>
</AccordionGroup>

### Channel Operations

#### Opening Channels

1. Select LSP or Peer
2. Choose Channel Capacity
3. Allocate RGB Assets (optional)
4. Set Channel Parameters
5. Confirm and Open

**Channel Options**:
- **Public Channels**: Participate in routing, earn fees
- **Private Channels**: Direct payments only, more privacy
- **Anchor Channels**: Use anchor outputs for security
- **Zero Reserve**: Spend full channel capacity

#### Managing Liquidity

<Tabs>
  <Tab title="Inbound Liquidity">
    **Receive Payments**

    Get inbound liquidity from LSPs:
    - Order channels with inbound capacity
    - Submarine swaps
    - Lightning Service Provider services
  </Tab>

  <Tab title="Outbound Liquidity">
    **Send Payments**

    Ensure outbound capacity:
    - Fund channels with on-chain deposit
    - Receive payments to build inbound
    - Channel rebalancing services
  </Tab>

  <Tab title="Circular Rebalancing">
    **Optimize Channels**

    Balance channel liquidity:
    - Pay yourself through different route
    - Maintain optimal channel states
    - Automated rebalancing bots
  </Tab>
</Tabs>

## Security Features

### Non-Custodial Architecture

KaleidoSwap is built on the principle of "Your Keys, Your Coins".

<Check>
  Private keys never leave your device
</Check>
<Check>
  No third-party access to funds
</Check>
<Check>
  Complete control over transactions
</Check>
<Check>
  Trustless trading protocol via atomic swaps
</Check>

### Secure Key Management

**Encryption Layer**:

- **Software Wallet**
    - AES-256 Encryption
    - Password Protection
    - Mnemonic Backup
- **Hardware Wallet Support (Coming Soon)**

### Channel Backups

<AccordionGroup>
  <Accordion title="Automatic Backups" icon="arrows-rotate">
    - Channels are backed up after every state change
    - Each backup reflects the channel state at the time it was created
  </Accordion>

  <Accordion title="Encrypted Storage" icon="lock">
    - Backup file encrypted with your node password
    - Same password required to decrypt it on restore
  </Accordion>

  <Accordion title="Multiple Locations" icon="hard-drive">
    - Save to local disk, external drive, or encrypted cloud storage
    - Keep redundant copies you can still access later
  </Accordion>

  <Accordion title="Easy Restore" icon="rotate-left">
    - Restore with your mnemonic phrase plus the backup file
    - Node force-closes the channels listed in the backup
  </Accordion>
</AccordionGroup>

### Security Best Practices

<Warning>
  **Important Security Tips**:
  - Always verify binary signatures before installation
  - Store your mnemonic phrase securely offline
  - Use strong, unique passwords
  - Enable automatic backups
  - Keep your software updated
</Warning>
