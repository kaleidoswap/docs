## Overview

KaleidoSwap SDK provides a comprehensive TypeScript interface for interacting with the KaleidoSwap API. This SDK enables seamless integration of onchain and Lightning Network swaps for RGB assets.

## Key Features

- 📊 **Asset Management** - Utilities for managing trading pairs and assets
- 🔄 **Utilities** - Built-in utilities, such a precision handling and retry mechanism
- 🔒 **Type Safe** - Full TypeScript support with comprehensive type definitions

## What You Can Build

- **Trading Applications** - Build DEX interfaces and trading bots
- **Portfolio Management** - Track and manage Bitcoin and RGB assets
- **Payment Systems** - Integrate atomic swaps into payment flows
