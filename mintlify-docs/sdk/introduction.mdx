## Official SDKs

KaleidoSwap provides official SDKs for both Python and TypeScript/JavaScript. Our unified documentation makes it easy to build applications in your preferred language with type-safe interfaces, comprehensive examples, and full support for all KaleidoSwap features.

## What is KaleidoSwap?

KaleidoSwap is a decentralized exchange protocol for Bitcoin and RGB assets. It enables trustless trading of digital assets through atomic swaps on the Lightning Network and on-chain Bitcoin transactions.

### Kaleido Protocol

The Kaleido Protocol is an open-source framework that allows users to:

**🔗 Lightning Channels with RGB Assets**
- Buy and sell Lightning channels pre-funded with RGB assets
- Open channels with RGB assets as channel funding
- Trade assets through channel liquidity management

**📊 Market Making & Trading**
- Get real-time quotes for asset pairs
- Execute atomic swaps using Request-for-Quote (RFQ) mechanism
- Connect directly to market makers for trading

**🔄 Atomic Swaps on Lightning**
- Execute trustless swaps using the maker-init → taker → maker-execute flow
- Support for both Lightning Network and on-chain settlements
- Full RGB asset support with UTXO management

### SDK Dual Purpose

Our SDK serves two primary functions:

**🏪 Kaleido API Integration**
Connect to KaleidoSwap's market maker APIs for:
- Getting quotes for asset pairs
- Executing swaps through market makers
- Managing orders and trading positions

**⚡ RLN (RGB Lightning Network) Operations**
Direct interaction with RGB Lightning nodes for:
- Wallet management and RGB asset operations
- Lightning channel management with RGB assets
- Node-to-node atomic swap coordination

## Understanding the Architecture

### Market Maker APIs
Connect to centralized market makers for trading:
- **Quote Requests**: Get prices for asset pairs
- **Order Management**: Create and track swap orders
- **WebSocket Feeds**: Real-time market data and order updates

### RLN (RGB Lightning Network) Operations
Direct peer-to-peer operations through RGB Lightning nodes:
- **Wallet Operations**: Manage RGB assets and Bitcoin
- **Channel Management**: Open/close channels with RGB assets
- **Atomic Swaps**: Coordinate swaps between nodes using the RFQ protocol

### The RFQ Swap Flow
1. **Maker Init**: Market maker initializes a swap quote
2. **Taker**: Client accepts the quote and provides settlement details
3. **Maker Execute**: Market maker executes the swap on Lightning Network

This trustless flow ensures atomic settlement of RGB assets across the Lightning Network.

### Market Maker Trading

<CodeGroup>
```typescript TypeScript
import { KaleidoClient } from '@kaleidoswap/kaleidoswap-sdk';

const client = new KaleidoClient({
  baseUrl: 'https://api.staging.kaleidoswap.com/api/v1'
});

// Get available trading pairs
const pairs = await client.listPairs();
console.log(`Found ${pairs.pairs.length} trading pairs`);

// Get a quote for BTC/USDT
const quote = await client.quoteRequest('BTC', 'rgb:im7mWgoS-4QX_1b1-DT23iPq-niObDFM-qGN7R2x-lFLJYak', 1000000);
console.log(`BTC/USDT Rate: ${quote.price}`);
```

```python Python
import asyncio
from kaleidoswap_sdk import KaleidoClient

async def market_trading():
    async with KaleidoClient(
        api_url="https://api.staging.kaleidoswap.com/api/v1"
    ) as client:
        # Get available trading pairs
        pairs = await client.list_pairs()
        print(f"Found {len(pairs.pairs)} trading pairs")

        # Get a quote for BTC/USDT
        quote = await client.get_quote(
            from_asset="BTC",
            to_asset="rgb:im7mWgoS-4QX_1b1-DT23iPq-niObDFM-qGN7R2x-lFLJYak",
            amount=1000000
        )
        print(f"BTC/USDT Rate: {quote.price}")

asyncio.run(market_trading())
```
</CodeGroup>

### RLN Node Operations

<CodeGroup>
```typescript TypeScript
import { KaleidoClient } from '@kaleidoswap/kaleidoswap-sdk';

const client = new KaleidoClient({
  baseUrl: 'https://api.staging.kaleidoswap.com/api/v1',
  nodeUrl: '<Your RGB Lightning Node URL>'
});

// Get node info and balance
const nodeInfo = await client.getNodeInfo();
const balance = await client.getBtcBalance();
console.log(`Node: ${nodeInfo.pubkey}`);
console.log(`BTC Balance: ${balance.vanilla.spendable} sats`);
```

```python Python
import asyncio
from kaleidoswap_sdk import KaleidoClient

async def rln_operations():
    async with KaleidoClient(
        api_url="https://api.staging.kaleidoswap.com/api/v1",
        node_url="<Your RGB Lightning Node URL>"
    ) as client:
        # Get node info and balance
        node_info = await client.get_node_info()
        balance = await client.get_btc_balance()
        print(f"Node: {node_info.pubkey}")
        print(f"BTC Balance: {balance.vanilla.spendable} sats")

asyncio.run(rln_operations())
```
</CodeGroup>
