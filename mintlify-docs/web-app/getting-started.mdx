## Accessing the Web App

The KaleidoSwap Web App is available at:

<Card title="Launch Web App" icon="rocket" href="https://app.kaleidoswap.com">
  app.kaleidoswap.com
</Card>

## Before You Start

<Steps>
  <Step title="Install a Wallet">
    Install one of the supported wallet extensions:

    | Wallet | Description | Install |
    |--------|-------------|---------|
    | **Alby** | Lightning-native wallet | [getalby.com](https://getalby.com) |
    | **Xverse** | Bitcoin Web3 wallet | [xverse.app](https://xverse.app) |
    | **BitMask** | RGB & Lightning wallet | [bitmask.app](https://bitmask.app) |
  </Step>

  <Step title="Fund Your Wallet">
    Ensure your wallet has:
    - Sufficient BTC for trading
    - Or RGB assets you want to swap
    - Small amount for network fees
  </Step>

  <Step title="Navigate to App">
    Open [app.kaleidoswap.com](https://app.kaleidoswap.com) in your browser.
  </Step>
</Steps>

## First Steps

### 1. Connect Your Wallet

Click the **Connect** button in the top right corner:

<AccordionGroup>
  <Accordion title="Connect Alby">
    1. Click **Connect**
    2. Select **Alby** from the wallet list
    3. Approve the connection in the Alby popup
    4. Your address will appear in the header
  </Accordion>

  <Accordion title="Connect Xverse">
    1. Click **Connect**
    2. Select **Xverse** from the wallet list
    3. Approve the connection in Xverse
    4. Your address will appear in the header
  </Accordion>

  <Accordion title="Connect BitMask">
    1. Click **Connect**
    2. Select **BitMask** from the wallet list
    3. Approve the connection request
    4. Your address will appear in the header
  </Accordion>
</AccordionGroup>

### 2. Select Assets to Trade

**From Card (Top)**
- Click the asset selector
- Choose the asset you want to swap FROM
- Enter the amount

**To Card (Bottom)**
- Click the asset selector
- Choose the asset you want to RECEIVE
- The amount updates automatically based on the quote

### 3. Review and Execute

Once you've entered an amount:
1. Review the **exchange rate**
2. Check the **fees**
3. Verify the **output amount**
4. Click **Swap** to execute

## Interface Elements

### Header
- **Logo** - Return to home
- **Wallet Button** - Connect/disconnect wallet
- **Settings** - Display options (BTC/sats)

### Swap Panel
- **From Card** - Source asset and amount
- **Swap Arrow** - Click to reverse direction
- **To Card** - Destination asset and amount
- **Quote Info** - Rate, fees, expiry

### Footer Info
- **Min/Max** - Amount limits for the selected pair
- **Network** - Protocol layer being used

## Display Options

Click the **Settings** icon to customize:

| Option | Description |
|--------|-------------|
| **BTC Display** | Show as BTC or satoshis |
| **Currency** | USD equivalent display |

## Quick Tips

<AccordionGroup>
  <Accordion title="Swap Direction">
    Click the swap arrow (↕️) to quickly reverse the trade direction.
  </Accordion>

  <Accordion title="Amount Shortcuts">
    - Enter amounts in the From field for exact input
    - Or enter in To field for exact output
  </Accordion>

  <Accordion title="Check Limits">
    Each trading pair has min/max limits shown below the input fields.
  </Accordion>

  <Accordion title="Real-Time Updates">
    Quotes refresh automatically. The displayed rate is what you'll receive.
  </Accordion>
</AccordionGroup>

## Troubleshooting

<Warning>
If you see "Wallet not detected", ensure:
1. The wallet extension is installed
2. You've refreshed the page after installing
3. The extension is enabled for this site
</Warning>

| Issue | Solution |
|-------|----------|
| Quote not loading | Check internet connection, try refreshing |
| Amount too low | Increase to meet minimum shown |
| Amount too high | Decrease to meet maximum shown |
| Wallet won't connect | Restart browser, reinstall extension |
