## Installation Issues

### Native Module Build Failures

**Problem:** Error building native module during installation

**Symptoms:**
```
npm ERR! code 1
npm ERR! prebuild-install || node-gyp rebuild
```

**Solutions:**

<Tabs>
  <Tab title="TypeScript">
    1. Ensure Node.js 18+:
    ```bash
    node --version  # Should be v18+
    nvm install 18
    ```

    2. Install build tools:
    ```bash
    # macOS
    xcode-select --install

    # Linux
    sudo apt-get install build-essential
    ```

    3. Clear cache:
    ```bash
    rm -rf node_modules package-lock.json
    npm cache clean --force
    npm install
    ```
  </Tab>
  <Tab title="Python">
    1. Ensure Python 3.9+:
    ```bash
    python --version  # Should be 3.9+
    ```

    2. Use a fresh virtual environment:
    ```bash
    python -m venv venv
    source venv/bin/activate
    pip install kaleidoswap
    ```
  </Tab>
</Tabs>

## Runtime Errors

### Network Errors

**Problem:** `NetworkError: Connection refused` or timeout errors

**Causes:**
- API server unreachable
- Firewall blocking connections
- DNS resolution failure

**Solutions:**

1. Check API availability:
```bash
curl https://api.regtest.kaleidoswap.com/health
```

2. Verify URL configuration:
<CodeGroup>
```typescript TypeScript
console.log('API URL:', process.env.KALEIDO_API_URL);
```

```python Python
print(f"API URL: {config.base_url}")
```
</CodeGroup>

3. Increase timeout:
<CodeGroup>
```typescript TypeScript
const client = new KaleidoClient({
  baseUrl: '...',
  timeout: 60,  // Increase from 30
});
```

```python Python
config = KaleidoConfig(
    base_url="...",
    timeout=60.0,  # Increase from 30
)
```
</CodeGroup>

### Quote Expired Errors

**Problem:** `QuoteExpiredError` when executing swap

**Cause:** Too much time between getting quote and executing

**Solution:** Get fresh quotes immediately before execution:

<CodeGroup>
```typescript TypeScript
async function executeSwap(pair: string, amount: number) {
  // Get fresh quote
  const quote = await client.getQuoteByPair(pair, amount);
  
  // Execute immediately
  return await client.initSwap({
    rfq_id: quote.rfqId,
    from_asset: quote.fromAsset,
    from_amount: quote.fromAmount,
    to_asset: quote.toAsset,
    to_amount: quote.toAmount,
  });
}
```

```python Python
def execute_swap(pair, amount):
    # Get fresh quote
    quote = client.get_quote_by_pair(pair, from_amount=amount)
    
    # Execute immediately
    return client.init_swap({
        "rfq_id": quote.rfq_id,
        "from_asset": quote.from_asset.asset_id,
        "from_amount": quote.from_asset.amount,
        "to_asset": quote.to_asset.asset_id,
        "to_amount": quote.to_asset.amount,
    })
```
</CodeGroup>

### Invalid Amount Errors

**Problem:** `ValidationError` for amount out of range

**Cause:** Amount below minimum or above maximum for the pair

**Solution:**

<CodeGroup>
```typescript TypeScript
// Get pair limits
const pair = await client.getPairByTicker('BTC/USDT');

// Adjust amount
let amount = requestedAmount;
if (amount < pair.minBaseOrderSize) {
  amount = pair.minBaseOrderSize;
}
if (amount > pair.maxBaseOrderSize) {
  amount = pair.maxBaseOrderSize;
}

const quote = await client.getQuoteByPair('BTC/USDT', amount);
```

```python Python
# Get pair limits
pair = client.get_pair_by_ticker("BTC/USDT")

# Adjust amount
amount = requested_amount
if pair.routes:
    route = pair.routes[0]
    if route.min_from_amount and amount < route.min_from_amount:
        amount = route.min_from_amount
    if route.max_from_amount and amount > route.max_from_amount:
        amount = route.max_from_amount

quote = client.get_quote_by_pair("BTC/USDT", from_amount=amount)
```
</CodeGroup>

## WebSocket Issues

### Stream Disconnects

**Problem:** WebSocket stream disconnects unexpectedly

**Solution:** Implement reconnection logic:

<CodeGroup>
```typescript TypeScript
async function resilientStream(pair: string, onQuote: (q: any) => void) {
  let retries = 0;
  const maxRetries = 5;

  while (retries < maxRetries) {
    try {
      const stream = await client.createQuoteStream(pair);
      
      while (stream.isConnected()) {
        const quoteJson = await stream.recv(30.0);
        if (quoteJson) onQuote(JSON.parse(quoteJson));
      }
      
      stream.close();
      retries = 0;  // Reset on success
    } catch (error) {
      retries++;
      console.log(`Reconnecting (${retries}/${maxRetries})...`);
      await new Promise(r => setTimeout(r, 1000 * retries));
    }
  }
}
```

```python Python
import time

def resilient_stream(pair, on_quote):
    retries = 0
    max_retries = 5
    
    while retries < max_retries:
        try:
            with client.subscribe_quotes(pair) as stream:
                for quote in stream.iter_quotes(timeout=30.0):
                    on_quote(quote)
            retries = 0  # Reset on success
        except Exception as e:
            retries += 1
            print(f"Reconnecting ({retries}/{max_retries})...")
            time.sleep(retries)
```
</CodeGroup>

### No Quotes Received

**Problem:** `stream.recv()` always returns `null`

**Causes:**
- No market activity
- Wrong pair ticker
- WebSocket connection failed

**Solutions:**

1. Verify pair exists:
<CodeGroup>
```typescript TypeScript
const pairs = await client.listPairs();
const exists = pairs.some(p => 
  `${p.baseAsset}/${p.quoteAsset}` === 'BTC/USDT'
);
```

```python Python
pairs = client.list_pairs()
exists = any(
    f"{p.base.ticker}/{p.quote.ticker}" == "BTC/USDT"
    for p in pairs if p.base and p.quote
)
```
</CodeGroup>

2. Increase timeout:
```typescript
const quote = await stream.recv(60.0);  // 60 seconds
```

## Type Issues

### Raw vs Parsed Responses

**Problem:** TypeScript type errors with `{ raw: true }`

**Solution:** Use proper type handling:

```typescript
// Without raw - returns typed objects
const assets = await client.listAssets();
assets.forEach(a => console.log(a.ticker));  // ✅ TypeScript knows type

// With raw - returns JSON string
const assetsJson = await client.listAssets({ raw: true });
if (typeof assetsJson === 'string') {
  const parsed = JSON.parse(assetsJson);
}
```
