## v0.5.0（当前版本）

**发布日期：** 21 June 2026

**支持平台：** macOS（Apple Silicon 和 Intel）、Windows (x64)、Linux（AppImage、deb、rpm）

<Warning>
KaleidoMind 目前是早期预览版。它还不够完善，各版本之间的行为也会变化。在批准任何支出前，请务必核对确认界面上的详情。
</Warning>

### 新增

- **KaleidoMind**，一个运行在本地设备上的 AI 智能体。你可以在本地与钱包和节点对话，只需一次确认就能完成完整的原子交换或购买通道，还能调度带风险限额、默认演练模式的自主任务。
- KaleidoMind 新增 Windows (x64) 支持，此前已支持 macOS 和 Linux。
- 可在设置中修改密码，并新增一键连接 Docker regtest 的预设。
- 韩语翻译。

### 变更

- 购买通道流程现在会沿用你配置的 LSP 或做市商，不再重置为网络默认值，并在整个下单过程中显示当前连接的 LSP。
- 重新设计了存入、提取和历史记录界面，基于 Tailwind v4 和 kaleido-ui 设计令牌重建。
- 做市商与 LSP 配置统一收纳到设置中。
- 所有 RGB 资产模式（NIA、CFA、UDA、IFA）现在在钱包和交易界面中都可见。

### 修复

- 节点重连更快。远程节点被锁定时会明确报告为已锁定，而不再报成认证失败。
- 精度为 `0` 的资产现在会被正确处理，空订单或失败的通道订单不再写入历史记录。

## v0.4.0

**发布日期：** 16 April 2026

### 新增

- **Docker 节点后端。** 可直接从应用中以容器方式运行 RGB Lightning Node，支持自动拉取镜像、容器生命周期管理和健康监控。
- **限价单**与**定投（DCA）**，两者都支持本地持久化并由调度器驱动执行。
- 反向报价，实现双向询价交易。
- BIP21 存入 URI、端口冲突自动处理，以及本地节点的托盘图标和后台运行控制。

### 变更

- 交易页面拆分为做市商视图和限价单视图，并通过并行初始化加快加载速度。
- 迁移到 KaleidoSDK v0.1.0。
- 交易、钱包历史、初始设置和通道管理等模块的多语言覆盖更加完整。

### 修复

- 停用浅色模式以避免渲染不一致，深色模式成为唯一支持的主题。
- 解锁重试超时时间从约 3 分钟提高到约 1 小时，同步较慢的节点不会再误报“已达到最大尝试次数”错误。
- `rustls-webpki` 和 `tar` 的安全更新。

## v0.3.2

**发布日期：** 10 November 2025

### 新增

- 支持向见证接收方发送 RGB 资产，可为见证 UTXO 填写比特币金额，最低 512 聪。
- Windows 安装包中内置 WebView2 引导程序。

### 变更

- 加强了存入和提取流程中 RGB 发票分配的校验与错误处理。

## v0.3.1

**发布日期：** 3 November 2025

### 新增

- 助记词查看器，可在安全警告和明确确认之后，在应用内显示你的助记词。
- Windows 安装包的 NSIS 配置。

### 修复

- 链上发送 RGB 资产时缺少金额参数的问题。
- 提取时若分配为 null 或 undefined 会导致崩溃的问题。

## v0.3.0

**发布日期：** 20 October 2025

### 新增

- 支持直接在通道中购买资产，通道会作为购买流程的一部分自动建立。
- 通道订单的开通费、容量费和时长费实时估算。
- 订单详情视图，包含资产交付状态、重试交付和重启订单流程。
- RGB 发票的隐私模式，可在盲化 UTXO 和标准链上地址之间切换。

### 变更

- macOS 版本使用 Apple 证书签名，安装时不再出现安全警告。
- 在没有可用通道时支持使用链上余额交易，并提示你创建通道。

## v0.2.0

**发布日期：** 23 July 2025（alpha）

### 新增

- 通道关闭确认、地址校验，以及已连接对等节点的选择。
- 带精度管理的资产选择，以及交易时的资产冲突校验。
- 带消息队列和重试逻辑的 WebSocket 服务。

### 修复

- 购买通道流程中的最大可发送金额。
- Windows manifest 集成与 MSVC 构建流程。
