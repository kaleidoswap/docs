title: "Reverse Swaps: Lightning to On-chain"
sidebarTitle: "Reverse Swaps"
description: "Turn a Lightning payment into on-chain BTC, L-BTC, or L-USDT with a Swap SDK reverse swap, and claim the payout with your own preimage"
---

In a reverse swap you pay a Lightning hold invoice and the maker locks funds on chain for you. Both are locked to the hash of a preimage only you know. When you claim the on-chain output, the preimage becomes public and the maker uses it to settle your payment. Until you claim, your payment is held, not settled.

## 1. Create the swap

<CodeGroup>
```typescript TypeScript
import { SwapClient, SwapMasterKey, SwapScript, toJson } from "@kaleidorg/swap-sdk";

const client = SwapClient.forNetwork("signet");
const master = SwapMasterKey.fromSwapMnemonic(swapMnemonic, "signet");
const claimKey = master.deriveSwapKey(index);
const preimage = master.derivePreimage(index);

const card = (await client.reversePairs())?.BTC?.["L-BTC"];
if (!card) throw new Error("Lightning -> L-BTC is not offered right now");

const amount = 50_000n;
if (amount < card.limits.minimal || amount > card.limits.maximal) throw new Error("outside limits");

const swap = await client.createReverseSwap("signet", {
  from: "BTC",          // Lightning BTC
  to: "L-BTC",          // BTC, L-BTC, L-USDT, USDT-RGB
  invoiceAmount: amount,
  preimageHash: preimage.sha256,
  claimPublicKey: claimKey.publicKey,
  pairHash: card.hash,
});

const script = SwapScript.fromReverse("liquid", "signet", swap, claimKey.publicKey);
await store.put(swap.id, toJson({ index, makerUrl, response: swap }));
```

```python Python
claim_key = master.derive_swap_key(index)
preimage = master.derive_preimage(index)
lbtc = sdk.lbtc_chain_from_network(sdk.Network.SIGNET)
btc = sdk.btc_chain_from_network(sdk.Network.SIGNET)

swap = await client.create_reverse_swap(
    sdk.CreateReverseRequest(
        invoice_amount=50_000,
        _from=btc,
        to=lbtc,
        preimage_hash=preimage.sha256(),
        claim_public_key=claim_key.public(),
    )
)
script = sdk.SwapScript.from_reverse(chain=lbtc, reverse_response=swap, our_pubkey=claim_key.public())
```
</CodeGroup>

The SDK checks that the invoice commits to your preimage hash and that the lockup script matches your key before it returns.

## 2. Pay the invoice

Pay `swap.invoice` from any Lightning wallet. The maker then broadcasts its lockup to the swap script: `transaction.mempool`, then `transaction.confirmed`.

## 3. Claim

Once the lockup is confirmed, claim it to your own address:

```typescript TypeScript
const claim = await script.constructClaim(preimage.preimage, {
  outputAddress: myLiquidAddress,
  swapId: swap.id,
  keysSecretHex: claimKey.secretKey,
  makerBaseUrl,
  network: "signet",
  liquidEsploraUrl,
});
// Persist claim.hex() and claim.txid() first.
await claim.broadcast("signet", undefined, liquidEsploraUrl);
```

The swap ends in `invoice.settled`. The claim must confirm before the swap's timeout; after that, the maker may refund its lockup. `claimReverseSwap` checks your chain evidence and the remaining margin before it reveals the preimage; see [Claims and refunds](/sdk/claims-and-refunds#stateless-reconciliation-helpers-typescript).

<Warning>
Check the payout address before you pay. Liquid networks encode addresses similarly enough that a wrong-network payout is unrecoverable, and the claim is the first step that would reject a bad address, after the invoice is already paid.
</Warning>

## Other destination assets

- **BTC** uses `SwapScript.fromReverse("bitcoin", ...)` and a Bitcoin Esplora URL.
- **L-USDT** claims use a caller-funded PSET: your wallet adds an L-BTC input for the fee, then the SDK finalizes. See `prepareLiquidClaim`.
- **USDT-RGB** claims produce a PSBT your rgb-lib wallet colors. See [RGB swaps](/sdk/rgb-swaps).
