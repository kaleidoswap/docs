设置面板可从应用右上角的下拉菜单打开。它分为 **应用设置**(Application Settings)、**做市商与 LSP 设置**(Maker & LSP Settings) 和 **节点连接设置**(Node Connection Settings) 三部分，旁边还有 **安全与备份**(Security & Backup) 和 **节点状态**(Node Status) 面板。多数修改在点击「保存设置」(Save Settings) 后生效；修改节点连接设置时，会弹出「重启节点？」(Restart Node?) 对话框，可选择「立即重启」(Restart Now) 或「稍后」(Later)。

## 应用设置

<img src="/assets/images/desktop-app/27_settings.png" alt="应用设置面板" width={1498} height={863} />

### 功能 (Capabilities / App Mode)

**作用：** 决定显示 KaleidoSwap 的哪些部分：

- **Node + Mind** — 同时运行钱包/节点和本地 AI 大脑（KaleidoMind）
- **Only Node** — 仅运行 RGB Lightning 节点、通道和交换功能
- **Only Mind** — 仅运行本地 AI 大脑，无需节点

<img src="/assets/images/desktop-app/26_settings-capabilities.png" alt="功能（应用模式）设置项" width={595} height={228} />

### 比特币单位 (Bitcoin Unit)

**作用：** 控制应用中比特币金额的显示方式。

- **Satoshi (SAT)** — 以聪（最小单位）显示金额（例如 100,000 聪）
- **Bitcoin (BTC)** — 以比特币小数形式显示金额（例如 0.001 BTC）

**何时需要修改：** 如果你觉得小额交易的小数金额不好读，切换成聪可以减少误读，也不会出现一长串前导零。

### 法币 (Fiat Currency)

**作用：** 设置用于显示余额和交换估值的法币币种。

### 语言 (Language)

**作用：** 设置应用的显示语言。下拉菜单中提供多种语言。

### 主题 (Theme)

「主题」(Theme) 一栏固定为「深色」(Dark)；应用只支持深色模式。浅色模式已被停用，以避免不同界面渲染不一致，因此设置中没有主题切换开关，应用也会忽略操作系统的主题偏好。

## 做市商与 LSP 设置

<img src="/assets/images/desktop-app/29_settings-maker.png" alt="做市商与 LSP 设置面板" width={910} height={451} />

### 做市商 URL (Maker URLs)

**作用：** 管理应用可连接的做市商接口端点列表，用于获取报价和执行交换。你可以添加多个做市商、删除它们，并把其中一个标记为**默认**（星形图标）。

### LSP URL

**作用：** 设置节点连接的闪电服务提供商 URL，用于获取通道流动性和交换路由。它通常与你的默认做市商 URL 一致。

**何时需要修改：** 在 Mutinynet 上已预先配置 KaleidoSwap 做市商/LSP；其他网络没有默认值，需要填写你的做市商 URL。此外，如果你自己运行 LSP、偏好的 LSP 使用其他 URL，或者默认地址无法访问，就需要修改。

## 节点连接设置

<Note>
  这些设置需要重启节点才能生效。点击「保存设置」后，会弹出「重启节点？」对话框，可选择「立即重启」或「稍后」。
</Note>

### 节点连接串 (Node Connection String)

**作用：** 指定应用连接的 RGB Lightning Node (RLN)，所有钱包、通道和支付操作都通过它完成（例如 `http://localhost:3001`）。

**何时需要修改：** 默认情况下，应用会管理一个内置的本地节点。如果你要连接远程或自建的 RGB Lightning Node，或者要在多个节点实例之间切换，就需要修改这一项。

### Bitcoin Core 节点 (Bitcoin Core node，可选 · 高级)

**作用：** 留空则从索引器同步（默认，无需安装任何东西）。填写 `user:password@host:port` 后，闪电网络会从你自己的 Bitcoin Core 节点同步。

### 索引器 URL (Indexer URL)

**作用：** 节点用于查询区块链的 Electrum/Esplora 索引器。

### RGB 代理端点 (RGB Proxy Endpoint)

**作用：** 用于交换 RGB 转账数据的 RGB 代理接口端点。

### Bearer 令牌 (Bearer Token)

**作用：** 可选令牌，发送给需要身份验证的远程节点。

<Note>
  修改任何节点连接设置，都会让应用连接到另一个节点或后端。保存前请确认目标节点及相关服务正在运行且可以访问，然后在收到提示时重启节点。
</Note>

## 安全与备份

安全与备份面板提供以下功能：

- **查看助记词**(View Recovery Phrase) — 显示钱包的助记词种子短语
- **修改密码**(Change Password) — 更新钱包的加密密码
- **备份**(Backup) — 创建完整节点数据的加密备份。完整说明请参见[通道备份](/cn/desktop-app/channels/channel-backups)页面。

<img src="/assets/images/desktop-app/31_settings-security.png" alt="安全与备份设置面板" width={435} height={397} />

## 节点状态

显示节点当前是运行中还是已离线，以及它是本地节点还是远程节点。在这里你可以 **「登出」(Logout)** 或 **「关闭」(Shutdown)** 节点。「登出」会锁定节点（本地节点还会被停止），然后返回启动界面。对于本地节点，页面底部会显示「节点日志」(Node Logs)，并提供导出和清空操作。

<img src="/assets/images/desktop-app/32_settings-node-status.png" alt="节点状态与日志面板" width={433} height={326} />
