KaleidoSwap 正在为比特币原生原子交换构建流动性层，让任何人都能自由、私密地交换比特币资产，无需中间人。

其垂直整合的技术栈涵盖桌面应用与浏览器扩展等终端用户应用、多语言 SDK、面向自主 AI 代理与本地 AI 大脑的 AI 工具，以及做市商软件。

## 平台总览

![KaleidoSwap 平台架构图：桌面端、扩展、移动端和 Web 应用客户端通过 swap-sdk 与 wallet-sdk 集成层，连接到比特币、闪电网络和二层协议图标、KaleidoSwap LSP 与做市商，以及 KaleidoMind 和 KaleidoAgent 智能层](/assets/images/overview/kaleidoswap-platform-overview.jpg)

整个技术栈是垂直整合的：同一套 SDK 驱动我们发布的每一个客户端和每一个第三方集成，因此每个入口面对的都是同一个交换引擎、同一批协议和同一份流动性。

- **客户端与集成方** — 桌面端、扩展、移动端和 Web 应用，以及基于相同接口构建的第三方钱包、新型银行、支付服务商和 AI 代理。
- **集成层** — 用于交换集成的 `kaleido-sdk`（TypeScript 和 Python，Rust 核心正在开发中），以及提供钱包基础能力的 `@kaleidorg/wallet-engine`（TypeScript）。[从 SDK 开始 →](/cn/sdk/introduction)
- **协议** — 比特币链上与闪电网络，以及交换可结算的各类比特币分层协议。[工作原理 →](/cn/whats-kaleidoswap/background)
- **流动性层** — 目前由 KaleidoSwap LSP 提供初始流动性；外部做市商将从 2027 年起加入。
- **智能层** — KaleidoMind 是自托管的 AI 大脑（QVAC 运行时、Skills 与 MCP 库、微调模型），KaleidoAgent 是自主交易代理，可基于本地模型或 Claude 与 OpenAI 运行。[了解 AI 工具 →](/cn/ai-tools/introduction)

标记为 LIVE 的组件已在生产环境中运行；其余部分列在 2026 年路线图中。

## 面向开发者

使用我们的 SDK、API 和 AI 工具在 KaleidoSwap 上构建应用：

### 快速上手

<Steps>
  <Step title="安装 SDK">
    TypeScript 使用 `npm install kaleido-sdk`，Python 使用 `pip install kaleido-sdk`。
    [安装指南 →](/cn/sdk/installation)
  </Step>

  <Step title="创建客户端">
    将 `KaleidoClient.create()` 指向 signet 接口端点 —— 主网即将上线。
    [客户端参考 →](/cn/sdk/api-reference)
  </Step>

  <Step title="请求报价">
    从做市方获取交易对和实时报价。
    [市场 API →](/cn/api-reference/market-apis)
  </Step>

  <Step title="执行交换">
    完整跑通你的第一笔非托管原子交换。
    [如何交换 →](/cn/sdk/how-to-swap)
  </Step>
</Steps>

<CodeGroup>
```typescript TypeScript
import { KaleidoClient } from 'kaleido-sdk';

const client = KaleidoClient.create({
  baseUrl: 'https://api.signet.kaleidoswap.com'
});

// 获取可用的交易对
const pairs = await client.maker.listPairs();

// 获取报价
const quote = await client.maker.getQuote({
  from_asset: { asset_id: 'BTC', layer: 'BTC_LN', amount: 100000 },
  to_asset: { asset_id: 'USDT', layer: 'RGB_LN' }
});
```

```python Python
from kaleido_sdk import KaleidoClient

client = KaleidoClient.create(
    base_url="https://api.signet.kaleidoswap.com"
)

# 获取可用的交易对
pairs = client.maker.list_pairs()

# 获取报价
quote = client.maker.get_quote({
    "from_asset": {"asset_id": "BTC", "layer": "BTC_LN", "amount": 100000},
    "to_asset": {"asset_id": "USDT", "layer": "RGB_LN"}
})
```
</CodeGroup>
