# KaleidoSwap Mintlify Documentation

This directory holds the Mintlify source for [docs.kaleidoswap.com](https://docs.kaleidoswap.com): the `.mdx` pages, `docs.json` (configuration and navigation) and `openapi.json`.

See the [root README](../README.md) for the directory structure, translations, local preview and contribution guidelines.

Quick preview from this directory:

```bash
npm i -g mint
mint dev
```
