After creating your wallet, you must unlock your node each time you open the KaleidoSwap Desktop App. This is done using the password you set during node initialization.

<FeatureVideo name="desktop-unlock" title="Switching between nodes, unlocking and locking them" />

## Quick Unlock Flow

1. **Open the App**  
   Launch the KaleidoSwap Desktop App.

2. **Select Your Account**  
   Click the account under **Your Accounts** on the start screen.

3. **Switch to It**  
   Click **Switch to This Node** in the dialog. A local node starts, and the unlock screen appears if the node is locked.  
   For a Docker account whose container is stopped, click **Start Docker Node**.

4. **Enter Your Password**  
   Type it into **Wallet Password** and click **Unlock Wallet**.  
   <img src="/assets/images/desktop-app/7_unlock_wallet.png" alt="Wallet unlock screen with password field in the KaleidoSwap Desktop App" width={1600} height={1000} />

## Node Sync Before Unlocking

After entering the correct password, the node will begin syncing with the blockchain **before** it becomes fully accessible.  
The duration of this process depends on how many blocks need to be synced, which varies based on how long the node has been offline.  
Please be patient while the node completes this step.

<img src="/assets/images/desktop-app/8_unlocking_animation.png" alt="Loading animation while the RGB Lightning Node unlocks" width={1600} height={1000} />

## Understanding Unlock Parameters

- **Password**  
  Secures access to your wallet and node. This is the same password you set during the initial node setup.

- **Network**  
  The network is fixed when the account is created — it is not chosen at unlock. The unlock screen simply connects to the account's configured network (e.g. Regtest, Signet, Mutinynet or Testnet).

- **Connection Details**  
  A read-only panel showing Node URL, Bitcoind RPC ("Not used: syncing from the indexer" when no Bitcoin Core node is set), Indexer and RGB Proxy. To change them, use **Edit** in the account card's menu under **Your Accounts**, or Settings after unlocking.

**Logout** (account menu, top right) locks the wallet on the node again and returns to the start screen.
