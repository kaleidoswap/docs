This page takes you from nothing to a finished swap on signet, in TypeScript.

## Before you start

| You need | Where to get it |
|---|---|
| Node 22 or later | [nodejs.org](https://nodejs.org) |
| A way to pay a Lightning invoice on **Mutinynet** | The KaleidoSwap signet maker runs on [Mutinynet](https://mutinynet.com), a custom signet, so an ordinary signet or testnet wallet cannot pay its invoices. The [Mutinynet faucet](https://faucet.mutinynet.com) pays a BOLT11 invoice for you: paste the invoice the script prints. |
| A Liquid testnet address to receive into | Any Liquid wallet set to testnet. For test L-BTC, use the [Liquid testnet faucet](https://liquidtestnet.com/faucet). |
| A 12-word BIP39 mnemonic, used only for swaps | Any wallet can generate one. Use a test mnemonic only, never one that holds real funds. |

## 1. Install

```bash
npm install @kaleidorg/swap-sdk
```

## 2. List what the maker trades

No keys, no funds. If this prints routes, the SDK and the maker are both reachable.

```typescript routes.ts
import { init, SwapClient } from "@kaleidorg/swap-sdk";

await init();
const client = SwapClient.forNetwork("signet");

const catalogues = {
  "on-chain -> Lightning": await client.submarinePairs(),
  "Lightning -> on-chain": await client.reversePairs(),
  "chain -> chain": await client.chainPairs(),
};

for (const [kind, pairs] of Object.entries(catalogues)) {
  for (const [from, tos] of Object.entries(pairs)) {
    for (const [to, card] of Object.entries(tos)) {
      console.log(`${kind}: ${from} -> ${to}  ${card.limits.minimal}-${card.limits.maximal}  fee ${card.fees.percentage}%`);
    }
  }
}
```

Each route has a **card** with its limits (in sats for BTC and L-BTC) and its fees.

## 3. Receive L-BTC from a Lightning payment

You pay a Lightning invoice and receive L-BTC on Liquid. The [`KaleidoSwap` API](/sdk/kaleidoswap) does it in three calls: `quote` prices the route, `start` creates the swap, and following the swap claims the L-BTC for you.

```typescript swap.ts
import { createKaleidoSwap, FileStore, isQuote, mnemonicSigner } from "@kaleidorg/swap-sdk";

const kaleido = await createKaleidoSwap({
  network: "signet",
  store: new FileStore("./swaps"),                            // one file per swap
  signer: mnemonicSigner(process.env.SWAP_MNEMONIC!, "signet"),
});

// Finish or refund anything a previous run left open.
await kaleido.resume();

const answer = await kaleido.quote({
  pay: "lightning:BTC",
  receive: "liquid:BTC",
  amount: { pay: 50_000 },
});
if (!isQuote(answer)) throw new Error(`${answer.reason}: ${answer.message}`);

// Creates the swap, checks the maker's answer, and saves it. Nothing is paid yet.
const swap = await kaleido.start(answer, { destination: process.env.LIQUID_ADDRESS! });
console.log(`Pay this invoice (${answer.fromAmount} sat):\n${swap.action.invoice}`);

// Follows the swap to the end and claims the L-BTC when the maker's lockup confirms.
for await (const phase of swap.phases()) console.log(phase);

if (swap.phase !== "settled") throw new Error(`Swap ${swap.id} ended ${swap.phase}`);
console.log(`Received about ${answer.toAmount} sat of L-BTC`);
```

Run it with `SWAP_MNEMONIC` and `LIQUID_ADDRESS` set, and pay the printed invoice (for example through the Mutinynet faucet). The script prints each phase and ends on `settled`.

If you stop the script after paying, run it again: `resume()` picks the swap up from `./swaps` and claims it.

<Warning>
`./swaps` holds what the SDK needs to claim or refund your swaps. Use a mnemonic that is only for swaps, keep the folder out of version control, and never delete it or restore an older copy while swaps are open. See [Keys and recovery](/sdk/keys-and-recovery#the-swap-store).
</Warning>
