创建钱包之后，每次打开 KaleidoSwap 桌面应用都需要解锁节点。解锁使用的是你在节点初始化时设置的密码。

<FeatureVideo name="desktop-unlock" title="在节点之间切换、解锁和锁定" />

## 快速解锁流程

1. **打开应用**  
   启动 KaleidoSwap 桌面应用。

2. **选择账户**  
   在启动界面的「你的账户」(Your Accounts) 下点击该账户。

3. **切换到该账户**  
   在对话框中点击「切换到此节点」(Switch to This Node)。本地节点会随之启动；如果节点处于锁定状态，会出现解锁界面。  
   对于容器已停止的 Docker 账户，点击「启动 Docker 节点」(Start Docker Node)。

4. **输入密码**  
   在「钱包密码」(Wallet Password) 中输入密码，然后点击「解锁钱包」(Unlock Wallet)。  
   <img src="/assets/images/desktop-app/7_unlock_wallet.png" alt="KaleidoSwap 桌面应用的钱包解锁界面，带密码输入框" width={1600} height={1000} />

## 解锁前的节点同步

输入正确密码后，节点会**先**与区块链同步，然后才完全可用。  
这一过程的耗时取决于需要同步的区块数量，而这又取决于节点离线了多久。  
请耐心等待节点完成这一步。

## 理解解锁参数

- **密码**  
  用于保护对钱包和节点的访问。就是你在首次配置节点时设置的那个密码。

- **网络**  
  网络在账户创建时即固定 —— 解锁时不需要选择。解锁界面只会连接到该账户已配置的网络（例如 regtest、signet、Mutinynet 或测试网）。

- **连接信息** (Connection Details)  
  只读面板，显示节点 URL (Node URL)、Bitcoind RPC（未设置 Bitcoin Core 节点时显示「Not used: syncing from the indexer」）、索引器 (Indexer) 和 RGB 代理 (RGB Proxy)。如需修改，可在「你的账户」下账户卡片菜单中点击「编辑」(Edit)，或解锁后在设置中修改。

「登出」(Logout，右上角账户菜单) 会在节点上重新锁定钱包并返回启动界面。
