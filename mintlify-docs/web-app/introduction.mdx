## What is the KaleidoSwap Web App?

The KaleidoSwap Web App will provide browser-based access to RGB asset trading on the Lightning Network, complementing our desktop application with a lightweight, accessible interface.

## Key Differences from Desktop App

| Feature | Desktop App | Web App |
|---------|-------------|---------|
| **Installation** | Download required | No installation |
| **Node Hosting** | Self-hosted or remote | Remote only |
| **Platform** | macOS, Windows, Linux | Any browser |
| **Wallet** | Built-in wallet | External wallet connection |
| **Best For** | Power users, node operators | Quick access, casual trading |

## Supported Browsers

The web app will support:

- Chrome/Chromium (v90+)
- Firefox (v88+)
- Safari (v14+)
- Edge (v90+)
