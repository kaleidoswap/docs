## 协议文档

扩展会从同一组助记词为每个分层派生一个账户。下面是各协议的上游参考资料。

<CardGroup cols={2}>
  <Card title="Spark" icon="bolt-lightning" href="https://docs.spark.money">
    基于状态链的转账、Lightning 收发，以及 Spark 账户背后的代币机制。
  </Card>
  <Card title="Arkade" icon="alien-8bit" href="https://docs.arkadeos.com">
    VTXO、进出通道（boarding/offboarding），以及 Arkade 账户背后的批量结算模型。
  </Card>
  <Card title="Liquid" icon="droplet" href="https://docs.liquid.net">
    L-BTC 和 USDt 等已发行资产背后的联邦侧链。
  </Card>
  <Card title="RGB 协议" icon="gem" href="https://docs.rgb.info">
    客户端验证和资产接口，同时适用于无节点 RGB-L1 和 Lightning 上的 RGB。
  </Card>
</CardGroup>

## DApp 标准

扩展注入网页的各个提供方所依据的规范。各提供方的具体暴露方式见 [DApp 连接](/cn/extensions/kaleidoswap-extension/dapp-connectivity)。

<CardGroup cols={2}>
  <Card title="WebLN" icon="bolt" href="https://www.webln.dev/">
    面向 Lightning 的浏览器提供方标准，注入在 `window.webln` 上。
  </Card>
  <Card title="NIP-07" icon="signature" href="https://github.com/nostr-protocol/nips/blob/master/07.md">
    页面内的 Nostr 签名，注入在 `window.nostr` 上。
  </Card>
  <Card title="NIP-46" icon="tower-broadcast" href="https://github.com/nostr-protocol/nips/blob/master/46.md">
    通过 `bunker://` 字符串，经中继完成的 Nostr Connect 远程签名。
  </Card>
  <Card title="Model Context Protocol" icon="plug" href="https://modelcontextprotocol.io">
    KaleidoSwap [MCP 服务器](/cn/ai-tools/mcp-servers)背后的工具协议。
  </Card>
</CardGroup>

## 获取帮助

如果是报错，请查看[故障排查](/cn/extensions/kaleidoswap-extension/troubleshooting)；如果是疑问，请查看[常见问题](/cn/extensions/kaleidoswap-extension/faq)。

其他情况请从下面的渠道中选择一个反馈问题，并附上：

1. 浏览器名称和版本
2. KaleidoSwap 扩展版本（Settings > About）
3. 节点类型和版本
4. 复现步骤
5. 错误信息或截图
6. 控制台日志（右键点击扩展弹出窗口 > Inspect > Console）
