The [swap-sdk repository](https://github.com/kaleidoswap/swap-sdk) ships runnable programs. The TypeScript ones run against the live signet maker.

## TypeScript

```bash
git clone https://github.com/kaleidoswap/swap-sdk && cd swap-sdk/typescript-sdk
npm install && npm run build
cd examples && npm install
node 01-pairs.ts
```

Node 22+ runs the `.ts` files directly.

| Example | What it does | Needs |
|---|---|---|
| [`01-pairs.ts`](https://github.com/kaleidoswap/swap-sdk/blob/trunk/typescript-sdk/examples/01-pairs.ts) | Prints every route the maker trades and on what terms | Nothing |
| [`02-submarine.ts`](https://github.com/kaleidoswap/swap-sdk/blob/trunk/typescript-sdk/examples/02-submarine.ts) | On-chain BTC → a Lightning invoice; refunds with `--refund` | A swap mnemonic, a BOLT11 invoice, signet bitcoin |
| [`03-reverse.ts`](https://github.com/kaleidoswap/swap-sdk/blob/trunk/typescript-sdk/examples/03-reverse.ts) | A Lightning payment → L-BTC on Liquid; claims and broadcasts | A swap mnemonic, a Liquid address, 50,000 signet sats |
| [`04-corridor.ts`](https://github.com/kaleidoswap/swap-sdk/blob/trunk/typescript-sdk/examples/04-corridor.ts) | Quotes the Arkade Intents corridor and shows a refusal | Nothing |
| [`05-rgb-spend.ts`](https://github.com/kaleidoswap/swap-sdk/blob/trunk/typescript-sdk/examples/05-rgb-spend.ts) | The RGB wallet adapter boundary for claims and refunds | An rgb-lib wallet adapter |
| [`06-atomic.ts`](https://github.com/kaleidoswap/swap-sdk/blob/trunk/typescript-sdk/examples/06-atomic.ts) | Quotes, verifies, and tracks an atomic BTC ↔ USDT-RGB swap | A regtest maker with atomic pairs, an rgb-lib wallet |

Start with `01-pairs.ts`. If it prints a table, the SDK, its WebAssembly binary, and the maker are all reachable.

The examples read their configuration from the environment:

| Variable | Default | Meaning |
|---|---|---|
| `KALEIDO_NETWORK` | `signet` | `signet` or `regtest` |
| `KALEIDO_MAKER_URL` | The network's maker | Override the maker URL |
| `KALEIDO_SWAP_INDEX` | `0` | BIP85 child index for this swap. Never reuse one |
| `KALEIDO_SWAP_MNEMONIC` | — | The persisted 12-word swap mnemonic |
| `BOLT11_INVOICE` | — | `02`: the invoice the maker should pay |
| `LIQUID_CLAIM_ADDRESS` | — | `03`: where the L-BTC payout lands |
| `REFUND_ADDRESS` | — | `02 --refund`: where refunded bitcoin lands |

<Note>
The examples take the swap index from an environment variable so you can see it. A real application keeps a persisted counter.
</Note>

## Python

[`bindings/python/examples/`](https://github.com/kaleidoswap/swap-sdk/tree/trunk/bindings/python/examples) has `submarine.py`, `reverse.py`, `chain.py`, `corridor_quote.py`, and `rgb_spend.py`. They target the regtest harness; do not run them against real funds.

## Rust

[`examples/`](https://github.com/kaleidoswap/swap-sdk/tree/trunk/examples) has:

- `lusdt_submarine.rs` and `lusdt_reverse.rs`: the full L-USDT ↔ BTC workflow, including the caller-funded PSET claim.
- `corridor_quote.rs`: an Arkade corridor quote.
- `signet_smoke.rs`: a read-only check of the signet maker and chain access.
- `rgb-regtest/`: live USDT-RGB swaps with real rgb-lib wallets on regtest.

```bash
cargo run --example lusdt_reverse
```
