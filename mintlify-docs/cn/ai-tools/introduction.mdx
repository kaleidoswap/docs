## AI 工具包含什么

KaleidoSwap 通过开源软件，把交换、钱包和节点基础设施开放给 AI 代理。三类接入方式覆盖了全部场景：从一个完整的自主代理，到在现有客户端里接入单个 MCP 连接。

产品总览请见 [kaleidoswap.com/products/ai-tools](https://kaleidoswap.com/products/ai-tools)。

<Warning>
  市场查询和离线示例不需要钱包资金；实际钱包操作使用已配置的钱包或节点。请参阅[安装](/cn/ai-tools/installation)，了解如何把测试种子与主网种子分开保管。
</Warning>

## 发布基线

| 包 | 版本 | 用途 |
| --- | --- | --- |
| `kaleido-mcp` | `0.5.0` | 统一 MCP 服务器 |
| `@kaleidorg/mind` | `0.11.0` | 代理引擎与可选本地数据集 |
| `@kaleidorg/mind-provider` | `0.11.0` | Mind Node 辅助进程 |
| `@kaleidorg/create-mind` | `0.3.6` | 项目生成器 |

Mind 要求 QVAC >=0.20.0；本基线使用 0.21.0 验证。
HTTP 默认仅绑定本机，远程绑定必须配置认证。默认诊断日志不保存自由文本；数据集收集需要明确启用。
迁移说明见 [MCP 更新日志](https://github.com/kaleidoswap/kaleido-mcp/blob/main/CHANGELOG.md)、
[Mind 更新日志](https://github.com/kaleidoswap/kaleido-mind/blob/main/CHANGELOG.md) 和
[数据集指南](https://github.com/kaleidoswap/kaleido-mind/blob/main/docs/DATASETS.md)。

真实模型质量评测、应用内同意与审核界面、精选数据集和微调属于后续工作。
本次发布提供库级能力，不会自动收集用户数据或训练模型。
