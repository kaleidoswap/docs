## 开发与测试

上主网之前请先在测试网络上开发。两个环境都已上线，且都不需要 API key。

按下面的写法把它们传入 `baseUrl` / `base_url` —— `/api/v1` 路径由 SDK 自动追加。

| 环境 | Base URL | 适用场景 |
|-------------|----------|----------|
| **signet (MutinyNet)** | `https://api.signet.kaleidoswap.com` | 在贴近真实的条件下做集成测试 |
