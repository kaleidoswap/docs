## What is the KaleidoSwap Web App?

The KaleidoSwap Web App provides instant, browser-based access to decentralized RGB asset trading on the Lightning Network. Available at [app.kaleidoswap.com](https://app.kaleidoswap.com), it offers a seamless trading experience without requiring any software installation.

## Key Features

### Lightning-Fast Trading
Execute atomic swaps in seconds using the Lightning Network. Trade BTC for USDT, XAUT, or other RGB assets with instant settlement.

### Multi-Wallet Support
Connect your preferred Bitcoin wallet:
- **Alby** - Lightning-native browser wallet
- **Xverse** - Bitcoin Web3 wallet
- **BitMask** - RGB & Lightning wallet

### Protocol Support
Trade across different protocols and layers:
- **RGB on Lightning** - Instant RGB asset swaps
- **RGB On-chain** - On-chain RGB settlements
- **Bitcoin Lightning** - Native BTC swaps

### Real-Time Market Data
- Live quotes with automatic refresh
- USD price equivalents
- Fee estimation before execution
- Min/max amount validation

## Interface Overview

The trading interface provides:

1. **From Card** - Select the asset you want to swap from
2. **To Card** - Select the asset you want to receive
3. **Network Selection** - Choose the protocol layer
4. **Quote Display** - Real-time exchange rate and fees
5. **Swap Button** - Execute the trade
