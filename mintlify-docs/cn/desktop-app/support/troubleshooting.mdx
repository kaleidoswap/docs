## 交易

<AccordionGroup>
  <Accordion title="交易失败该怎么办？" icon="arrows-rotate">
    **现象**：原子交换未能完成。

    **解决办法**：
    1. 检查通道流动性
    2. 核对 RGB 资产详情
    3. 确认节点已正常同步
    4. 如问题持续，请联系支持
  </Accordion>

  <Accordion title="无法输入想要的通道容量" icon="sliders">
    **现象**：「通道容量」(Channel Capacity) 的数值跳到一个更低的数字。

    **原因**：该字段的上限是你用链上余额最多能注资的金额；50,000 聪的下限会在点击「继续」(Continue) 时校验。

    **解决办法**：使用 100k/250k/500k/1M 预设值或滑块，或者存入更多 BTC。
  </Accordion>
</AccordionGroup>

## 钱包

<AccordionGroup>
  <Accordion title="我该如何恢复钱包？" icon="wallet">
    恢复钱包的步骤：
    1. 使用你此前创建的备份文件
    2. 用你的密码解密备份文件
    3. 等待节点同步完成

    v0.5.0 或更早版本的备份无法在 v0.5.1 中恢复。
  </Accordion>

  <Accordion title="解锁时提示节点运行的是不受支持的版本" icon="code-compare">
    **原因**：应用要求 RGB Lightning Node 0.10.0 或更高版本。

    **解决办法**：将节点升级到 RGB Lightning Node 0.10.0 或更高版本，然后重新解锁。
  </Accordion>
</AccordionGroup>

## 连接 {#connectivity}

<AccordionGroup>
  <Accordion title="无法连接到 LSP" icon="link-slash">
    **现象**：出现关于 LSP 连接的错误提示，或无法开通通道。

    **解决办法**：
    1. 检查网络连接是否稳定
    2. 核对 LSP 地址——在 Mutinynet 上默认为 `https://api.mutinynet2.kaleidoswap.com/`（其他网络没有默认值），位于「设置」(Settings) → 「做市方与 LSP 设置」(Maker & LSP Settings)
    3. 检查防火墙/VPN 设置；需要开放的端口为 9735（闪电 P2P）和 3001（节点 API）
    4. 查看该 LSP 的状态页面，或在有其他 LSP 可选时切换一个
  </Accordion>

  <Accordion title="Windows 上无法使用原生二进制" icon="ban">
    **现象**：在 Windows 上，「原生二进制」(Native Binary) 显示「不可用」(Not available)。

    **原因**：原生节点无法在 Windows 上运行。

    **解决办法**：
    1. 安装并启动 Docker Desktop，然后选择「本地节点 → Docker 容器」(Local Node → Docker Container)
    2. 或连接远程节点（参见[节点托管](/cn/desktop-app/getting-started/node-hosting)），例如 [ThunderStack](/cn/desktop-app/getting-started/node-hosting#option-3-hosted-provider-thunderstack) 这类专业托管方案
    3. 使用 Docker 节点或远程节点时，交易和钱包功能的使用方式完全相同
  </Accordion>

  <Accordion title="我自行托管的节点无法启动" icon="server">
    **现象**：节点在启动过程中退出，或桌面应用无法访问它的 API。

    **检查项**：
    1. 如果配置了 Bitcoin Core 节点，确认它正在运行，且可通过所配置的 `user:password@host:port` 访问；否则节点只从索引器同步
    2. 确认所配置的索引器和 RGB proxy 接口端点在线
    3. 查看节点日志中出现的第一条启动错误，修正相关连接设置后重启
  </Accordion>

  <Accordion title="桌面应用无法连接到我的远程节点" icon="plug-circle-xmark">
    **现象**：应用提示远程节点不可达，或始终处于未连接状态。

    **检查项**：
    1. 在「设置 → 节点连接设置」(Settings → Node Connection Settings) 中核对节点地址，并确认节点正在运行且已解锁
    2. 确保服务器防火墙放行节点 API 端口（默认：`3001`）以及 `9735` 上的闪电对等节点流量
    3. 如果你使用了 VPN、反向代理或隧道，请确认它会把流量转发到应用中配置的同一地址和端口
  </Accordion>

  <Accordion title="我的节点卡在同步状态" icon="arrows-rotate">
    **现象**：节点持续处于同步状态，钱包或通道操作不可用。

    **检查项**：
    1. 如果配置了 Bitcoin Core 节点，确认它正在运行，且可通过所配置的 `user:password@host:port` 访问；否则节点只从索引器同步
    2. 检查所配置的 Electrum 或 Esplora 索引器是否已追上所选网络的进度
    3. 确认节点、比特币后端和索引器使用的是同一网络
  </Accordion>

  <Accordion title="Mutinynet 节点或交易无法正常工作" icon="triangle-exclamation">
    **现象**：signet 节点无法连接，或交易在 Mutinynet 上不确认。

    **检查项**：
    1. 使用支持 Mutinynet/signet 的比特币构建版本和 Electrs 配置
    2. 确认节点配置了 `NETWORK=signet` 以及正确的 Mutinynet 种子节点
    3. 在 [Mutinynet 浏览器](https://mutinynet.com/)上查看网络状态和交易确认情况
  </Accordion>
</AccordionGroup>

## 获取帮助

如果遇到的是疑问而不是报错，请查看[常见问题](/cn/desktop-app/support/faq)；上游文档与相关链接见[更多资源](/cn/desktop-app/support/additional-resources)。

其他情况请通过下方任一渠道反馈问题，并附上以下信息：

1. 你的操作系统及版本（macOS、Windows 或 Linux）
2. KaleidoSwap 桌面应用版本
3. 节点类型（本地或远程）及版本
4. 复现步骤
5. 错误信息或截图
6. 日志文件：
   - macOS：`~/Library/Logs/com.kaleidoswap.dev/`
   - Windows：`%APPDATA%\com.kaleidoswap.dev\logs`
   - Linux：`~/.local/share/com.kaleidoswap.dev/logs`
