## Architecture

The SDK follows a **Rust-first architecture** with language bindings generated via UniFFI:

```
┌─────────────────────────────────────────────────────────────────┐
│                        Language Bindings                         │
├───────────────────────┬───────────────────────┬─────────────────┤
│    Python (PyO3)      │   TypeScript (NAPI)   │     Swift       │
│      kaleidoswap      │   @kaleidoswap/sdk    │   (planned)     │
└───────────────────────┴───────────────────────┴─────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                      Core Rust Library                          │
│                     kaleidoswap-core                            │
└─────────────────────────────────────────────────────────────────┘
```

### Key Benefits

- **Native Performance**: Rust core with zero-cost bindings
- **Type Safety**: Auto-generated types from OpenAPI specs
- **Consistent API**: Identical functionality across languages
- **Memory Safe**: Rust's guarantees extended to bindings

## What is KaleidoSwap?

KaleidoSwap is a decentralized exchange protocol for Bitcoin and RGB assets. It enables trustless trading of digital assets through atomic swaps on the Lightning Network and on-chain Bitcoin transactions.

### SDK Dual Purpose

Our SDK serves two primary functions:

**🏪 Kaleido API Integration**
Connect to KaleidoSwap's market maker APIs for:
- Getting quotes for asset pairs
- Executing swaps through market makers
- Managing orders and trading positions

**⚡ RLN (RGB Lightning Network) Operations**
Direct interaction with RGB Lightning nodes for:
- Wallet management and RGB asset operations
- Lightning channel management with RGB assets
- Node-to-node atomic swap coordination

## Key Features

- **Sub-client Architecture**: Organized API access via `client.market`, `client.orders`, `client.swaps`, `client.lsp`, and `client.node`
- **Type Safety**: Full TypeScript types and Python Pydantic models
- **WebSocket Support**: Real-time updates for trades, orders, and market data
- **Error Handling**: Comprehensive exception hierarchy across both SDKs
- **Dual API Support**: Seamlessly work with both Market Maker APIs and RLN node operations
- **RGB Asset Trading**: Full support for trading RGB assets on Lightning and on-chain
- **Atomic Swaps**: Execute trustless swaps using the complete RFQ flow

### Market Maker Trading

<CodeGroup>
```typescript TypeScript
import { KaleidoClient } from '@kaleidoswap/sdk';

const client = new KaleidoClient({
  baseUrl: 'https://api.regtest.kaleidoswap.com'
});

// Get available trading pairs
const pairs = await client.listPairs();
console.log(`Found ${pairs.length} trading pairs`);

// Get a quote for BTC/USDT
const quote = await client.getQuoteByPair('BTC/USDT', 1_000_000);
console.log(`Price: ${quote.price}`);
console.log(`From: ${quote.fromAmount} -> To: ${quote.toAmount}`);
```

```python Python
from kaleidoswap import KaleidoClient, KaleidoConfig

config = KaleidoConfig(base_url="https://api.regtest.kaleidoswap.com")
client = KaleidoClient(config)

# Get available trading pairs
pairs = client.list_pairs()
print(f"Found {len(pairs)} trading pairs")

# Get a quote for BTC/USDT
quote = client.get_quote_by_pair("BTC/USDT", from_amount=1_000_000)
print(f"Price: {quote.price}")
print(f"From: {quote.from_asset.amount} -> To: {quote.to_asset.amount}")
```
</CodeGroup>

### RLN Node Operations

<CodeGroup>
```typescript TypeScript
import { KaleidoClient } from '@kaleidoswap/sdk';

const client = new KaleidoClient({
  baseUrl: 'https://api.regtest.kaleidoswap.com',
  nodeUrl: 'http://localhost:3001'  // Your RGB Lightning Node
});

// Check if node is configured
if (client.hasNode()) {
  // Get node info and balance
  const nodeInfo = await client.getRgbNodeInfo();
  const balance = await client.getBtcBalance();
  console.log(`Node connected`);
  console.log(`BTC Balance: ${balance.vanilla.spendable} sats`);
}
```

```python Python
from kaleidoswap import KaleidoClient, KaleidoConfig

config = KaleidoConfig(
    base_url="https://api.regtest.kaleidoswap.com",
    node_url="http://localhost:3001"  # Your RGB Lightning Node
)
client = KaleidoClient(config)

# Check if node is configured
if client.has_node():
    # Get node info and balance
    node_info = client.get_rgb_node_info()
    balance = client.get_btc_balance()
    print("Node connected")
    print(f"BTC Balance: {balance.vanilla.spendable} sats")
```
</CodeGroup>
