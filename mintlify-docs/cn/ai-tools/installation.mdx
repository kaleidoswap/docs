每个 AI 接入方式都可以独立安装。挑选与你的开发目标最匹配的那一个，或者先安装 MCP 网关 —— 它是跑通第一次工具调用的最短路径。

| 接入方式 | 安装路径 | 前置条件 |
|---------|-------------|---------------|
| **[MCP 服务器](#mcp-servers)** | `npx -y kaleido-mcp` | Node.js 20+，一个 MCP 宿主客户端 |
| **[KaleidoAgent](#kaleidoagent)** | 克隆仓库并从源码构建 | Node.js 20+、KaleidoCLI、Nanobot、一个 LLM API 密钥 |
| **[KaleidoMind](#kaleidomind)** | 随桌面应用一起提供，在你自己的宿主中 `npm install @kaleidorg/mind`，或构建仓库用于开发 | 项目模板需要 Node.js；仅本地推理需要 QVAC |

<Warning>
  可以先在无资金条件下试用：MCP 市场查询不需要钱包，Mind 提供离线示例。连接钱包时使用测试网络，并避免提交或分享种子。`dry_run` 是 KaleidoAgent 的设置，不是 MCP 或 Mind 的通用选项。
</Warning>

## MCP 服务器 {#mcp-servers}

`kaleido-mcp` 是跑通工具调用的最快路径，已发布到 npm。`KALEIDO_NETWORK=signet` 用一个变量把它指向 signet KaleidoSwap API 和 Spark 测试网络：

```bash
KALEIDO_NETWORK=signet npx -y kaleido-mcp
```

<Note>
  直接启动 stdio 服务器会等待 MCP 客户端请求，不会显示聊天提示。
  请将命令加入客户端配置，再发起工具调用。
</Note>

Spark 和 Liquid 钱包是可选的，普通的 `npx` 不会安装它们。如需启用，请运行 `npx -y -p kaleido-mcp -p @tetherto/wdk-wallet-spark -p @kaleidorg/wdk-wallet-liquid kaleido-mcp`，并设置 `WDK_SEED` / `LIQUID_MNEMONIC`。

使用 RGB 工具还需要一个 RGB Lightning Node。[KaleidoCLI](/cn/cli/installation) 可以在 Docker 中运行一个 signet 节点，完整流程见[构建本地 RGB 代理](/cn/ai-tools/build-local-rgb-agent)。

统一服务器已包含早期钱包服务器的功能域。工具目录和客户端配置见
[MCP 服务器](/cn/ai-tools/mcp-servers)，旧集成请参阅
[迁移说明](/cn/ai-tools/mcp-servers#retired-servers)。

## KaleidoAgent {#kaleidoagent}

前置条件：Node.js 20 或更高版本、位于 `$PATH` 中的 [KaleidoCLI](/cn/cli/installation)、[Nanobot](https://nanobot.dev) 运行时，以及一个 Anthropic 或 OpenAI API 密钥。

```bash
git clone https://github.com/kaleidoswap/kaleido-agent.git
cd kaleido-agent
npm run install:all
```

设置 API 密钥、在 `agent.config.json` 中配置钱包、启动仪表盘，以及容器部署方案，请查看 [KaleidoAgent 页面](/cn/ai-tools/kaleido-agent#run-it)。

## KaleidoMind {#kaleidomind}

KaleidoMind 是嵌入宿主应用中的引擎，而不是一个独立安装的程序。

### 先试用离线项目

```bash
npm create @kaleidorg/mind my-agent
cd my-agent
npm install
npm run start:offline
```

预期输出：示例余额、模拟发票和模拟转账。不需要节点、模型下载或真实资金。
下一步可用 `npm run start:mock` 加载本地模型，钱包仍保持模拟状态。

### 通过桌面应用

这是最快的路径。[桌面应用](/cn/desktop-app/getting-started/installation)将该引擎打包为应用内聊天，并负责管理本地模型的生命周期。在 **设置 > 能力** (Settings > Capabilities) 中选择 **Node + Mind** 或 **Only Mind** 即可开启。

<Note>
  KaleidoMind 依赖本地 AI 运行时，目前在 Windows 上可能尚不可用。所有交易与节点功能都不依赖它，因此如果你的平台上 Mind 暂不可用，可以用 **Only Node** 模式运行应用。
</Note>

### 在你自己的 Node.js 应用中 {#in-your-own-nodejs-app}

```bash
npm install @kaleidorg/mind @qvac/sdk
```

`@qvac/sdk` 是可选的 peer 依赖，因此引擎在没有它的情况下也能配合 mock provider 运行。快速上手见 [`@kaleidorg/mind` README](https://www.npmjs.com/package/@kaleidorg/mind)，[kaleido-mind 仓库](https://github.com/kaleidoswap/kaleido-mind)中还有可运行的示例（`examples/node-minimal`、`examples/rgb-agent`）。

### 从源码构建，用于开发

```bash
git clone https://github.com/kaleidoswap/kaleido-mind.git
cd kaleido-mind
corepack enable
pnpm install --frozen-lockfile && pnpm build
```

`apps/cli` 中的 CLI 负责本地模型管理，也可以直接运行代理：

```bash
cd apps/cli
npx tsx src/index.ts setup     # 引导式首次运行：选择并拉取模型
npx tsx src/index.ts run "what's my balance?"
npx tsx src/index.ts skills    # 列出已安装的 Skills
```

如果想在没有手机的情况下用某个模型验证引擎，可以在仓库根目录使用 playground：

```bash
pnpm play "pay bob 3 eur"
```

分层漏斗如何路由一次请求、跨传输方式共享的工具契约、引擎加载的 skills，以及它在桌面和手机上的运行方式，请查看 [KaleidoMind 页面](/cn/ai-tools/kaleido-mind)。
