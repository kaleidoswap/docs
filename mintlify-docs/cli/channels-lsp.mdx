## Channel Operations

The `channel` group covers direct Lightning channel management against your local node.

| Command | Purpose |
|--------|---------|
| `kaleido channel list` | List current channels |
| `kaleido channel open <peer>` | Open a channel to a peer |
| `kaleido channel close <channel-id> --peer <pubkey>` | Close a channel |

Peer arguments use `pubkey@host:port` format. Closing needs both the channel ID and `--peer`; add `--force` for a unilateral close, and only when the peer is unresponsive, since it locks funds until the timelock expires.

## Open A Channel

```bash
kaleido channel open 03abc...@peer.host:9735 --capacity 100000
```

Notable options:

- `--capacity`
- `--push-msat`
- `--asset-id`
- `--asset-amount`
- `--push-asset-amount`
- `--public` or `--private`
- `--with-anchors`
- `--fee-base-msat`
- `--fee-proportional-millionths`

Example colored channel:

```bash
kaleido channel open 03abc...@peer.host:9735 \
  --capacity 100000 \
  --asset-id rgb:abc... \
  --asset-amount 5000
```

## LSP Channel Orders

Use `channel order` when you want KaleidoSwap's LSP flow instead of manually opening a peer channel.

### Subcommands

| Command | Purpose |
|--------|---------|
| `kaleido channel order create [client-pubkey]` | Create a channel order, defaulting to the local node pubkey |
| `kaleido channel order get <order-id>` | Fetch status and details |
| `kaleido channel order pay <order-id>` | Pay an order with local wallet funds (`--onchain` or `--offchain`) |
| `kaleido channel order decide <order-id>` | Submit a rate decision |
| `kaleido channel order estimate-fees` | Estimate opening fees |

### Create an order

```bash
kaleido channel order create 03abc... \
  --lsp-balance 1000000 \
  --client-balance 500000
```

The pubkey is optional and defaults to your local node, so `kaleido channel order create --lsp-balance 1000000 --client-balance 500000` is equivalent when you are ordering for yourself.

Useful options:

- `--confirmations`, default 6
- `--funding-within`, default 144 blocks
- `--expiry-blocks`, at least 1
- `--refund-address`, defaulting to a local node address
- `--announce` or `--private`
- `--asset-id`
- `--lsp-asset-amount`, required with `--asset-id`
- `--client-asset-amount`, which must not exceed `--lsp-asset-amount`
- `--email`
- `--yes`, `-y` to accept the fetched RFQ price, required non-interactively

### Pay an order

```bash
kaleido channel order pay <order-id> --access-token <token> --offchain
```

Choose the funding source with `--onchain` or `--offchain`; interactively the CLI asks, but in `--agent` or `--json` mode exactly one is required, along with `--yes`. On-chain payments accept `--fee-rate` in sat/vbyte.

Example colored channel order:

```bash
kaleido channel order create 03abc... \
  --lsp-balance 1000000 \
  --client-balance 500000 \
  --asset-id rgb:xyz... \
  --lsp-asset-amount 5000 \
  --client-asset-amount 2000
```

## LSP Metadata

The `lsp` subgroup exposes server metadata and network details:

| Command | Purpose |
|--------|---------|
| `kaleido channel lsp info` | Show LSP information and available options |
| `kaleido channel lsp network-info` | Show network metadata for the LSP |

These commands are useful before creating orders or when wiring client defaults.

## Practical Sequence

```bash
kaleido channel lsp info
kaleido node swap pubkey
kaleido channel order estimate-fees --lsp-balance 1000000 --client-balance 500000
kaleido channel order create 03abc... --lsp-balance 1000000 --client-balance 500000
```

See [Market And Swaps](/cli/market-and-swaps) for server-side trading flows that often run alongside channels and liquidity management, or [Troubleshooting](/cli/troubleshooting#channels-and-lsp-orders) when a channel or an order will not go through.
