## Overview

The `KaleidoClient` is the main entry point for interacting with the KaleidoSwap API. It provides methods for asset discovery, quote generation, swap execution, wallet operations, and Lightning Network management.

<CodeGroup>
```typescript TypeScript
import { KaleidoClient } from '@kaleidoswap/sdk';

const client = new KaleidoClient({
  baseUrl: 'https://api.staging.kaleidoswap.com/api/v1',
  nodeUrl: 'https://your-lightning-node.com', // Optional
  wsUrl: 'wss://api.staging.kaleidoswap.com/api/v1', // Optional
  apiKey: process.env.KALEIDO_API_KEY, // leave empty for now
  timeout: 30000,
  retries: 3
});
```

```python Python
from kaleidoswap_sdk import KaleidoClient

client = KaleidoClient(
    api_url="https://api.staging.kaleidoswap.com/api/v1",
    node_url="<Your node URL>",
    api_key=None,  # Optional
    ping_interval=30,
    ping_timeout=10,
    close_timeout=10,
    max_size=2**20,
    max_queue=32,
    compression=None
)
```
</CodeGroup>

## Client Configuration

### Configuration Parameters

<CodeGroup>
```typescript TypeScript
// KaleidoConfig Interface
interface KaleidoConfig {
  baseUrl?: string;        // KaleidoSwap API base URL (default: staging)
  nodeUrl?: string;        // Lightning node URL (optional)
  wsUrl?: string;          // WebSocket URL (auto-derived from baseUrl)
  timeout?: number;        // Request timeout in ms (default: 30000)
  retries?: number;        // Automatic retries (default: 3)
  apiKey?: string;         // API key for authenticated requests
  userAgent?: string;      // Custom User-Agent header
}
```

```python Python
# KaleidoClient Parameters
class KaleidoClient:
    def __init__(
        self,
        api_url: str,                    # KaleidoSwap API base URL
        node_url: str,                   # RGB Lightning node URL
        api_key: Optional[str] = None,   # API key (future use)
        ping_interval: int = 30,         # WebSocket ping interval (seconds)
        ping_timeout: int = 10,          # WebSocket ping timeout (seconds)
        close_timeout: int = 10,         # WebSocket close timeout (seconds)
        max_size: int = 2**20,           # Max message size (1MB)
        max_queue: int = 32,             # Max message queue size
        compression: Optional[str] = None # WebSocket compression
    )
```
</CodeGroup>

### `get_quote()` / `quoteRequest()`

Generates a price quote for a potential trade.

**Parameters**:
- `from_asset: string` - Source asset ID or ticker
- `to_asset: string` - Destination asset ID or ticker
- `from_amount?: number` - Amount to trade in atomic units (use this OR to_amount)
- `to_amount?: number` - Target amount to receive in atomic units (use this OR from_amount)

**Returns**: Quote response

**Error Conditions**:
- `ValidationError` - Invalid parameters
- `NetworkError` - Connection issues
- `QuoteError` - Quote generation failed

**Example**:

<CodeGroup>
```typescript TypeScript
// Quote for selling 0.001 BTC (100,000 satoshis)
const quote = await client.quoteRequest({
  from_asset: 'BTC',
  from_amount: 100000,
  to_asset: 'USDT'
});
console.log('Rate:', quote.exchange_rate || quote.price);
console.log('Will receive:', quote.to_amount, 'atomic USDT');

// Alternative: Quote for buying specific amount
const buyQuote = await client.quoteRequest({
  to_asset: 'USDT',
  to_amount: 45000000,
  from_asset: 'BTC'
});
console.log('BTC required:', buyQuote.from_amount);
```

```python Python
# Quote for selling 0.001 BTC (100,000 satoshis)
quote = await client.get_quote(
    from_asset="BTC",
    to_asset="rgb:q1O5Mn5y-7EoxdTy-xu3ChkP-HmhgGvJ-vQ3ryQ9-CcMxkfg",  # USDT
    amount=100000
)
print(f"Rate: {quote.exchange_rate}")
print(f"Will receive: {quote.to_amount} atomic USDT")
```
</CodeGroup>

## Swap Operations

Methods for executing atomic swaps on-chain and off-chain.

### `init_maker_swap()` / `initMakerSwap()`

Initialize a swap transaction as the maker.

**Parameters**:
- `rfq_id: string` - Quote ID from previous quote request
- `from_asset: string` - Source asset
- `to_asset: string` - Destination asset
- `from_amount: number` - Amount to send (atomic units)
- `to_amount: number` - Amount to receive (atomic units)

**Returns**: Swap response with payment hash and swapstring

**Example**:

<CodeGroup>
```typescript TypeScript
const quote = await client.quoteRequest({
  from_asset: 'BTC',
  from_amount: 100000,
  to_asset: 'USDT'
});

const swap = await client.initMakerSwap({
  rfq_id: quote.rfq_id,
  from_asset: 'BTC',
  to_asset: 'USDT',
  from_amount: 100000,
  to_amount: quote.to_amount
});

console.log('Payment hash:', swap.payment_hash);
console.log('Swapstring:', swap.swapstring);
```

```python Python
from kaleidoswap_sdk import InitMakerSwapRequest

# First get a quote
quote = await client.get_quote("BTC", "USDT", 100000)

# Initialize the swap
swap = await client.init_maker_swap(
    InitMakerSwapRequest(
        rfq_id=quote.rfq_id,
        from_asset="BTC",
        to_asset="USDT",
        from_amount=100000,
        to_amount=quote.to_amount
    )
)
print(f"Payment hash: {swap.payment_hash}")
print(f"Swapstring: {swap.swapstring}")
```
</CodeGroup>

### `wait_for_swap_completion()` / `waitForSwapCompletion()`

Wait for a swap to complete with automatic polling.

**Parameters**:
- `payment_hash: string` - Payment hash from swap initialization
- `timeout_seconds?: number` - Maximum wait time (default: 300 seconds)
- `poll_interval_seconds?: number` - Seconds between status checks (default: 5 seconds)

**Returns**: Final swap status

**Error Conditions**:
- `TimeoutError` - Swap didn't complete within timeout
- `SwapError` - Status check failed

**Example**:

<CodeGroup>
```typescript TypeScript
try {
  const finalSwap = await client.waitForSwapCompletion(
    swap.payment_hash,
    600,  // 10 minutes
    2     // Poll every 2 seconds
  );

  if (finalSwap.status === 'Succeeded') {
    console.log('Swap completed successfully!');
  } else {
    console.error('Swap failed:', finalSwap.status);
  }
} catch (error) {
  if (error instanceof TimeoutError) {
    console.error('Swap timed out');
  }
}
```

```python Python
try:
    final_status = await client.wait_for_swap_completion(
        payment_hash=swap.payment_hash,
        timeout_seconds=300,
        poll_interval=5
    )
    print(f"Swap completed: {final_status.status}")
except TimeoutError:
    print("Swap did not complete in time")
```
</CodeGroup>

- `to_asset: string` - Destination asset
- `from_amount: number` - Send amount (atomic units)
- `to_amount: number` - Receive amount (atomic units)

**Returns**: Order response

**Example**:

<CodeGroup>

```typescript TypeScript
const order = await client.createOrder({

  to_asset: 'USDT',
  from_amount: 100000,
  to_amount: quote.to_amount
});

console.log('Payment address:', order.onchain_address);
```

```python Python
from kaleidoswap_sdk import CreateOrderRequest

        to_asset="USDT",
        from_amount=100000,
```
