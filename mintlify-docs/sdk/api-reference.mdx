Names are shown as TypeScript / Python. Rust uses the Python spelling on `BoltzApiClientV2` and `SwapScript`. React Native exposes the same surface as Python with camelCase names, generated from the same bindings. The published TypeScript declarations (`dist/index.d.ts`) document every type in full.

## `KaleidoSwap`

Quote, start, and resume swaps, with claims and refunds done by the SDK. [The KaleidoSwap API](/sdk/kaleidoswap) explains each call.

| TypeScript | Python | What it does |
|---|---|---|
| `createKaleidoSwap(options)` | `KaleidoSwap(KaleidoSwapOptions(...))` | Build the instance from a network, a store, and a signer |
| `quote({ pay, receive, amount })` | `quote(QuoteRequest(...))` | A `Quote` or a `Refusal` |
| `start(quote, { destination, refundAddress })` | `start(quote, StartOptions(...))` | Create, verify, and save the swap; returns a `Swap` |
| `swap(id)` | `swap(id)` | The `Swap` for a saved record |
| `resume()` | `resume()` | Move every open swap one step; returns a `ResumeReport` |

### `Swap`

| TypeScript | Python | What it does |
|---|---|---|
| `id`, `phase`, `protocol` | `id()`, `phase()`, `protocol()` | Read without waiting |
| `action` | `action()` | What to pay or fund: `invoice`, or `fundingAddress` and `fundingAmount` (plus `bip21`, `zeroConfLimit`) |
| `phases(signal?)` | `watch(listener)` | Follow to the end, reporting each phase |
| `settled(signal?)` | `settled()` | Resolve on `settled`; fail on `refunded` or `failed` |
| `refund()` | `refund()` | Refund now instead of waiting for the SDK to do it |
| `record()` | `record()` | The `SwapRecord`: ids, assets, phase, `rawStatus`, timestamps |

### Stores, signers, and helpers

| TypeScript | Python | What it is |
|---|---|---|
| `FileStore(dir)` (Node only) | `FileStore(dir)` | One JSON file per swap |
| `MemoryStore()` | `MemoryStore()` | Nothing persisted: tests only |
| `SwapStore` | `SwapStore` | The interface for a store of your own: `get`, `put`, `list`, `nextIndex` |
| `mnemonicSigner(mnemonic, network, passphrase?)` | `MnemonicSigner(mnemonic, passphrase, network)` | Signer for a swap mnemonic |
| `SwapSigner` | `SwapSigner` | The interface for a signer of your own: `deriveKey`, `derivePreimage` |
| `isQuote(answer)` | `answer.quote` / `answer.refusal` | Tell a quote from a refusal |
| `isSwapError(error)` | `Error.Swap` | A failure with a [code](/sdk/kaleidoswap#errors) |
| `TERMINAL_PHASES` | — | `settled`, `refunded`, `failed` |

The `Asset` values are `bitcoin:BTC`, `lightning:BTC`, `liquid:BTC`, `liquid:USDT`, `arkade:BTC`, `spark:BTC`, `bitcoin:rgb:<contract>`, `lightning:rgb:<contract>`, and `spark:<token>`. Python builds them with `Asset.BTC_ONCHAIN()`, `Asset.BTC_LIGHTNING()`, `Asset.BTC_LIQUID()`, and so on. Every asset can be named; [the routes served today](/sdk/kaleidoswap#routes) are a subset.

React Native exposes the same classes as Python with camelCase names.

## `SwapClient`

The maker API client. In TypeScript it comes from `SwapClient.forNetwork`, `new SwapClient(baseUrl, timeoutSecs?)`, `createKaleidoOrgClient`, or `createKaleidoMakerClient`. In Python: `SwapClient.default(network)`, `SwapClient(base_url, timeout)`, `SwapClient.kaleido_org(...)`, or `SwapClient.kaleido_maker(...)`.

## `SwapScript`

The swap script rebuilt on your side, and the claim and refund builder.

| Method | What it does |
|---|---|
| `fromSubmarine(chain, network, response, ourPubkey)` | Rebuild from a submarine create response |
| `fromReverse(chain, network, response, ourPubkey)` | Rebuild from a reverse create response |
| `fromChain(chain, network, side, details, ourPubkey)` | Rebuild one side (`"lockup"` or `"claim"`) of a chain swap |
| `fromRestored(entry, ourPubkey, network, side?)` | Rebuild from a restore entry |
| `constructClaim(preimage, params)` | Claim (cooperative by default) |
| `constructCooperativeClaim(preimage, params, lockupScript, refundKeySecret)` | Cooperative chain-swap claim |
| `constructRefund(params)` | Refund (cooperative by default) |
| `prepareLiquidClaim(...)` / `prepareLiquidRefund(...)` | Caller-funded PSET for L-USDT |
| `prepareRgbClaim(...)` / `prepareRgbRefund(...)` | PSBT for an rgb-lib wallet to color |
| `prepareRgbCooperativeRefund(...)` | Early co-signed RGB submarine refund |

`chain` is `"bitcoin"` or `"liquid"`. Python uses snake_case and takes a `SwapTransactionParams` with a `Fee.RELATIVE(sat_per_vb)` or `Fee.ABSOLUTE(sats)`.

## Numbers in TypeScript

- Parameters declared `bigint` need a `BigInt` (`0n`); a plain number throws a `TypeError` before the SDK can attach a code.
- 64-bit fields inside request objects accept `bigint | number`. Unsafe numbers above `Number.MAX_SAFE_INTEGER` are rejected before the request is sent.
- 64-bit response fields are always `bigint`, including amounts, timestamps, and the restore index. 32-bit fields (key indexes, output indexes, reverse and chain timeout heights) stay `number`.
- Serialize responses with `toJson`, not `JSON.stringify`.
