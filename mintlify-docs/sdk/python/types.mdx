## Overview

The SDK exports 340+ types including:
- **18 Enumerations** - String-based enums for API constants
- **80+ Request/Response Models** - Pydantic models for API calls
- **40+ Complex Models** - Nested data structures
- **6 Assignment Models** - RGB asset assignment types

All types are fully typed and validated using Pydantic v2, providing:
- Automatic data validation
- JSON serialization/deserialization
- IDE autocomplete support
- Type hints for better development experience

## Core Data Models

### Asset

Represents an RGB asset with balance information.

```python
class Asset(BaseModel):
    asset_id: str              # Unique asset identifier (e.g., "rgb:...")
    ticker: str                # Asset ticker (e.g., "USDT")
    name: str                  # Full asset name (e.g., "Tether USD")
    details: Optional[str]     # Additional details
    precision: int             # Decimal precision (e.g., 6 for USDT)
    issued_supply: int         # Total issued supply
    timestamp: int             # Creation timestamp
    added_at: int              # When added to platform
    balance: AssetBalance      # Balance information
    media: Optional[Media]     # Asset media/logo
    asset_iface: Optional[AssetIface]  # Asset interface type
    is_active: bool            # Whether asset is active for trading
```

**Usage**:
```python
assets = await client.list_assets()
for asset in assets.assets:
    print(f"{asset.ticker}: {asset.name}")
    print(f"  Balance: {asset.balance.spendable / (10 ** asset.precision)}")
```

### TradingPair

Represents a trading pair on the exchange.

```python
class TradingPair(BaseModel):
    id: str                    # Unique pair ID
    base_asset: str            # Base asset ticker (e.g., "BTC")

    is_active: bool            # Whether pair is active
    min_base_order_size: int   # Minimum order size (atomic units)
    max_base_order_size: int   # Maximum order size (atomic units)
    min_quote_order_size: int  # Minimum quote size (atomic units)
    max_quote_order_size: int  # Maximum quote size (atomic units)
```

**Usage**:
```python

```

## Type Hints and IDE Support

All SDK methods include full type hints for better IDE support:

```python
from kaleidoswap_sdk import KaleidoClient, QuoteRequest, QuoteResponse

async def get_price_quote(
    client: KaleidoClient,
    from_asset: str,
    to_asset: str,
    amount: int
) -> QuoteResponse:
    """Get a price quote with full type safety."""
    quote: QuoteResponse = await client.get_quote(
        from_asset=from_asset,
        to_asset=to_asset,
        amount=amount
    )
    return quote
```

## Validation

All Pydantic models include automatic validation:

```python
from kaleidoswap_sdk import CreateOrderRequest
from pydantic import ValidationError

try:
    # This will raise a validation error
    order = CreateOrderRequest(
        rfq_id="",  # Empty string not allowed
        from_amount=-100  # Negative amount not allowed
    )
except ValidationError as e:
    print(f"Validation error: {e}")
```
