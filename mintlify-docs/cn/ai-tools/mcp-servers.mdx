KaleidoSwap 通过 **`kaleido-mcp`** 这一个统一服务器，把钱包、DEX 和支付能力开放给 AI 代理（Claude Desktop、[KaleidoAgent](/cn/ai-tools/kaleido-agent)、基于 [KaleidoMind](/cn/ai-tools/kaleido-mind) 的宿主，或任何其他 [MCP](https://modelcontextprotocol.io) 客户端），新集成应使用这个统一服务器。它已取代早期的独立钱包服务器；旧集成的迁移说明位于本页末尾。

## 需要准备什么

| 操作 | 前置条件 |
|---|---|
| 市场查询与报价 | MCP 客户端和 Node.js；不需要种子或本地节点 |
| RGB 钱包与 RGB 原子交换 | 可访问且已解锁的 RGB Lightning Node |
| Spark 或 Liquid 钱包 | 可选钱包包及其助记词 |
| 潜水艇交换 | 可选 swap SDK、Node.js 22+ 和已配置的付款钱包 |

模型通过 MCP 客户端调用工具。直接在终端启动服务器只会等待协议请求，不会打开聊天界面。

## 安装与配置 {#installation-and-configuration}

`kaleido-mcp` 已发布到 npm，这是跑通第一次工具调用的最快方式。请从 signet 开始：

```bash
KALEIDO_NETWORK=signet npx -y kaleido-mcp
```

<Note>
  本页描述的是 `kaleido-mcp` 0.3.0 及以上版本。0.3.0 新增了 `KALEIDO_NETWORK` 预设和
  `kaleido_node_*` 生命周期工具，并移除了基于订单的交换工具，改为只使用原子交换。如果
  `npx` 解析到了较旧的缓存版本，请运行一次 `npx -y kaleido-mcp@latest`，或从源码构建。
</Note>

<Note>
  自 0.3.1 起，Spark 和 Liquid 钱包是可选的 peer 依赖，普通的 `npx -y kaleido-mcp`
  不会安装它们。设置了 `WDK_SEED` 或 `LIQUID_MNEMONIC` 但缺少对应包时，服务器仍会启动，
  并输出安装提示。启用方法：

  ```bash
  npx -y -p kaleido-mcp -p @tetherto/wdk-wallet-spark -p @kaleidorg/wdk-wallet-liquid kaleido-mcp
  ```
</Note>

实际使用中由 MCP 宿主替你执行这条命令，把宿主配置指向该命令即可（见下面的[客户端配置](#client-configuration)）。若用于开发，或要运行某个特定提交，请改为从源码构建：

```bash
git clone https://github.com/kaleidoswap/kaleido-mcp
cd kaleido-mcp
npm install
npm run build
```

无论哪种方式，服务器读取的环境变量都相同，并且默认使用 stdio 通信：

```bash
# stdio（Claude Desktop、Claude Code、KaleidoAgent 等）
KALEIDO_NETWORK=signet WDK_SEED="word1 word2 ..." node dist/index.js

# HTTP 传输
PORT=3010 KALEIDO_NETWORK=signet WDK_SEED="word1 word2 ..." node dist/index.js
```

### 网络预设 {#network-preset}

`KALEIDO_NETWORK` 用一个变量选定一组默认值，可取 `signet`（自 0.3.1 起为默认）或 `mainnet`：

| 预设 | KaleidoSwap API | Spark 网络 |
|--------|-----------------|---------------|
| `signet` | `https://api.signet.kaleidoswap.com` | Spark 测试网络（Spark SDK 中名为 `REGTEST`） |
| `mainnet` | 无：把 `KALEIDOSWAP_API_URL` 设为你自己的做市商端点 | `MAINNET` |

预设只负责填充默认值。你显式设置的任何变量（例如 `KALEIDOSWAP_API_URL` 或 `SPARK_NETWORK`）都会覆盖它。KaleidoSwap 目前没有公开的主网 API，因此 `mainnet` 未设置 `KALEIDOSWAP_API_URL` 时，服务器会在启动时直接退出；未知取值同样如此。`RLN_NODE_URL` 不属于预设：请把它指向你自己的节点，在 signet 上通常就是 [KaleidoCLI](/cn/cli/installation) 运行在 `http://localhost:3001` 的那个节点。

| 环境变量 | 是否必需 | 说明 |
|---------|----------|--------------|
| `KALEIDO_NETWORK` | 否 | `signet`（默认）或 `mainnet`。设置[网络预设](#network-preset)中的默认值 |
| `WDK_SEED` | 使用 Spark 工具时必需 | Spark 钱包的 BIP-39 助记词，同时需要可选包 `@tetherto/wdk-wallet-spark`。两者缺一服务器仍能启动，只是 Spark 工具会被禁用 |
| `LIQUID_MNEMONIC` | 使用 Liquid 工具时必需 | Liquid 钱包的 BIP-39 助记词，同时需要可选包 `@kaleidorg/wdk-wallet-liquid` |
| `SPARK_NETWORK` | 否 | 覆盖预设中的 Spark 网络：`MAINNET`，或代表 Spark 测试网络的 `REGTEST` |
| `SPARK_SCAN_API_KEY` | 否 | SparkScan API 密钥 |
| `SPARK_USDT_TOKEN` | 否 | 默认的 Spark 代币标识符 |
| `RLN_NODE_URL` | 否 | RLN 守护进程 URL，默认 `http://localhost:3001` |
| `KALEIDOSWAP_API_URL` | 使用 `mainnet` 时必填 | KaleidoSwap 做市商 API URL，覆盖预设。主网没有公开端点，因此 `mainnet` 必须设置。也接受 `KALEIDO_API_URL` |
| `KALEIDO_BIN` | 否 | `kaleido` 可执行文件的路径，供节点生命周期工具使用 |
| `KALEIDO_NODE_URL` | 否 | 以 `--node-url` 传给节点生命周期工具的节点 URL |
| `KALEIDO_API_URL` | 否 | 以 `--api-url` 传给节点生命周期工具的 API URL，同时作为 `KALEIDOSWAP_API_URL` 的备选 |
| `KALEIDO_ENV_NAME` | 否 | 节点生命周期工具的默认环境名 |
| `PORT` | 否 | 启用 Streamable HTTP 传输，替代 stdio |
| `MCP_AUTH_TOKEN` | 否 | HTTP 模式下的 Bearer token |

### 遗留别名

为兼容早期集成，部分工具仍可通过旧名称调用（`rln_*` 对应 `wdk_*`，通用 `get_*` 对应 `l402_get_*` 行情工具）。新的集成应使用规范的 `wdk_*` / `l402_*` 名称。

## 客户端配置 {#client-configuration}

把服务器添加到 Claude Desktop 或 Claude Code 这类 MCP 宿主中。已发布的网关用 `npx` 即可；独立的钱包服务器则从本地构建运行。

<Warning>
  下方初始配置不需要助记词。如果之后添加钱包种子，请将配置保密，并排除在版本控制之外。
</Warning>

<CodeGroup>
```json Claude Desktop
{
  "mcpServers": {
    "kaleido": {
      "command": "npx",
      "args": ["-y", "kaleido-mcp"],
      "env": {
        "KALEIDO_NETWORK": "signet",
        "RLN_NODE_URL": "http://localhost:3001"
      }
    }
  }
}
```

```bash Claude Code
claude mcp add kaleido \
  --env KALEIDO_NETWORK=signet \
  --env RLN_NODE_URL=http://localhost:3001 \
  -- npx -y kaleido-mcp
```
</CodeGroup>

在 Claude Desktop 中，配置文件是 `claude_desktop_config.json`（**Settings > Developer > Edit Config**）。`WDK_SEED` 和 `@tetherto/wdk-wallet-spark` 包都是可选的：不提供时 Spark 工具会被禁用，而 RGB 节点、DEX、支付和行情工具照常可用。`REGTEST` 是 Spark SDK 对其托管测试网络的命名。

## 首次运行 {#first-run}

先查询市场和钱包，再请求报价，最后才执行。余额查询和报价不会转移资金；支付与执行工具才会。

<Steps>
  <Step title="把网关添加到宿主客户端">
    把 `kaleido-mcp` 配置块加入你的 MCP 宿主配置，并把 `KALEIDO_NETWORK` 设为 `signet`。完整 JSON 见上面的[客户端配置](#client-configuration)。
  </Step>

  <Step title="重启宿主客户端">
    MCP 宿主只在启动时读取配置。已经在运行的客户端不会自动识别新服务器，必须重启。
  </Step>

  <Step title="调用一个只读工具">
    先从不会动用资金的操作开始。请求行情数据，它既不需要种子也不需要节点：

    ```
    What is the current Bitcoin price and the Fear and Greed index?
    ```

    这会触发 `l402_get_price` 和 `l402_get_sentiment`。请核对客户端是否报告了成功的工具调用；仅有模型文字回答不能证明连接成功。
  </Step>

  <Step title="确认钱包已接好">
    启用可选 Spark 包并设置种子后，再确认钱包工具能正常解析：

    ```
    Show me my Spark balance and my Spark address.
    ```

    这会调用 `spark_get_balance` 和 `spark_get_address`。如果工具发现成功但调用失败，请检查可选钱包包、种子、网络及工具返回的错误。
  </Step>

  <Step title="交易前先报价">
    只询价，不执行：

    ```
    Quote 100000 sats of BTC into USDT. Do not execute anything.
    ```

    `kaleidoswap_get_quote` 会返回一个 `rfq_id`、原始数量、费用和过期时间。请仔细核对原始数量：它们以资产的最小单位计价，不是显示单位。
  </Step>

  <Step title="报价确认无误后再执行">
    一笔原子交换需要 DEX 工具和钱包工具配合，并且节点必须在通道中持有该资产。下面的[跨服务器调用顺序](#atomic-swap-across-servers)按顺序列出了每一次调用。
  </Step>
</Steps>

<Warning>
  通用 MCP 宿主是保护最弱的一条路径。`kaleido-mcp` 不编码确认标志，所以如果你的客户端自动批准工具调用，LLM 就能不经询问地从配置的钱包中花钱。在完全弄清客户端如何处理批准之前，请只使用测试网络种子。
</Warning>

## 原子交换流程 {#atomic-swap-across-servers}

一笔原子交换需要 DEX 工具和钱包工具配合。`kaleido-mcp` 用它的 `kaleidoswap_*` 工具与做市方通信，并用 `wdk_*` 工具驱动接单方节点。任何一步都不涉及托管，HTLC 在闪电网络上结算。

```
kaleidoswap_get_quote        → rfq_id + raw amounts
kaleidoswap_atomic_init      → swapstring + payment_hash
wdk_atomic_taker             → whitelist the HTLC on the node
wdk_get_node_info            → taker_pubkey
kaleidoswap_atomic_execute   → trigger HTLC settlement
kaleidoswap_atomic_status    → poll until Succeeded
```

上面每一步都走同一条 `kaleido-mcp` 连接，因为两组前缀同时可用。

## 付费 API 访问 {#paid-api-access}

Machine Payments Protocol 流程让代理无需 API 密钥、无需注册就能买到受门控资源的访问权，直接通过闪电网络支付发票。

```
mpp_request_challenge(url)          → challenge { invoice, challenge_id }
wdk_mpp_pay(invoice, challenge_id)  → payment credential
mpp_submit_credential(url, cred)    → { ok, data, receipt }
```


## 运行时兼容性

排查集成问题时，请核对实际安装的包版本。使用 QVAC 的 Mind 宿主需要
`@qvac/sdk >=0.20.0`。`kaleidoswap_submarine_*` 工具还需要可选的
`@kaleidorg/swap-sdk` 包，以及 Node.js 22 或更新版本。
工具出现在目录中不代表钱包、节点或可选依赖已配置完成。
`/health` 成功仅表示 HTTP 进程正在运行。

[自动生成的 MCP 参考](https://github.com/kaleidoswap/kaleido-mcp/blob/main/docs/TOOLS.md)
列出了当前参数结构。固定版本的集成应查看对应 release tag 中的参考。

## 已退役的服务器 {#retired-servers}

下列名称仅用于旧集成迁移，不是需要额外安装的服务器：

| 旧入口 | 当前用法 |
|---|---|
| `wdk-wallet-mcp` | `kaleido-mcp` 中的 `wdk_*` |
| `wdk-wallet-spark-mcp` | `spark_*` 加可选 Spark 包；用 `WDK_SEED` 替代 `WDK_SPARK_SEED` |
| `wdk-wallet-liquid-mcp` | `liquid_*` 加可选 Liquid 包 |
| `kaleidoswap-mcp` | `kaleidoswap_*`；已移除的 REST 订单流程请改为原子交换 |
| `l402-gateway-mcp` | `mpp_*` / `l402_*` |
| `kaleido-node-mcp` | `kaleido_node_*` 管理节点，`wdk_*` 操作钱包 |

宿主需要的 `rln_*` 别名仍可保留。新建原始 MCP 集成应使用规范名称，迁移参数前请核对所安装版本的自动生成参数结构。
