This page goes from an installed package to a first swap on signet. If you have not installed the SDK yet, start with [Installation](/sdk/installation).

## 1. Connect and list routes

`forNetwork("signet")` resolves the live KaleidoSwap maker, so this runs as written with no keys or funds.

<CodeGroup>
```typescript TypeScript
import { init, SwapClient } from "@kaleidorg/swap-sdk";

await init();
const client = SwapClient.forNetwork("signet");

const submarine = await client.submarinePairs(); // on-chain -> Lightning
const reverse = await client.reversePairs();     // Lightning -> on-chain
const chain = await client.chainPairs();         // on-chain -> on-chain

for (const [from, tos] of Object.entries(reverse)) {
  for (const [to, card] of Object.entries(tos)) {
    console.log(`${from} -> ${to}`, card.limits.minimal, card.limits.maximal, card.fees.percentage);
  }
}
```

```python Python
import asyncio
import kaleidorg_swap_sdk as sdk

async def main():
    client = sdk.SwapClient.default(sdk.Network.SIGNET)
    reverse = await client.get_reverse_pairs()
    print(reverse)

asyncio.run(main())
```

```rust Rust
use kaleidorg_swap_sdk::boltz::BoltzApiClientV2;
use kaleidorg_swap_sdk::network::Network;

let client = BoltzApiClientV2::default(Network::Signet)?;
let reverse = client.get_reverse_pairs().await?;
```
</CodeGroup>

Each catalogue is a map of `from → to → pair card`. A card carries the route's `limits` (in the sending asset's base units: sats for BTC and L-BTC), its `fees` (a percentage plus miner fees), its `rate`, and a `hash`. Passing that `hash` back when you create a swap holds the maker to the terms you showed the user.

## 2. Derive a swap key and preimage

Swap keys and preimages derive from a **swap mnemonic**, which is a BIP85 child of your wallet mnemonic (index 26589). Derive it once, store it, and use a fresh index for every swap.

<CodeGroup>
```typescript TypeScript
import { SwapMasterKey } from "@kaleidorg/swap-sdk";

const master = SwapMasterKey.fromWalletMnemonic(walletMnemonic, "signet");
// Persist master.swapMnemonic() and reload with SwapMasterKey.fromSwapMnemonic().

const index = 0n; // from your persisted counter; never reuse one
const claimKey = master.deriveSwapKey(index);
const preimage = master.derivePreimage(index);
```

```python Python
master = sdk.SwapMasterKey.from_wallet_mnemonic(wallet_mnemonic, sdk.Network.SIGNET)
claim_key = master.derive_swap_key(0)
preimage = master.derive_preimage(0)
```
</CodeGroup>

<Warning>
Reusing an index reuses claim and refund material across swaps. Keep a persisted counter, not a constant. See [Keys and recovery](/sdk/keys-and-recovery).
</Warning>

## 3. Create a reverse swap

A reverse swap turns a Lightning payment into an on-chain output you claim. This one pays out L-BTC on Liquid.

```typescript TypeScript
import { SwapScript, toJson } from "@kaleidorg/swap-sdk";

const card = (await client.reversePairs())?.BTC?.["L-BTC"];
if (!card) throw new Error("BTC -> L-BTC is not offered right now");

const swap = await client.createReverseSwap("signet", {
  from: "BTC",
  to: "L-BTC",
  invoiceAmount: 50_000n,          // amounts are bigint in TypeScript
  preimageHash: preimage.sha256,
  claimPublicKey: claimKey.publicKey,
  pairHash: card.hash,
});

// Rebuild the swap script against your own key before paying anything.
const script = SwapScript.fromReverse("liquid", "signet", swap, claimKey.publicKey);

await store.put(swap.id, toJson({ index, swap })); // includes swapAuth, issued once
console.log("Pay this invoice:", swap.invoice);
```

`createReverseSwap` already checks the response against your key and preimage hash. `SwapScript.fromReverse` gives you the script you will claim from, and fails if the lockup it derives does not match the maker's address.

## 4. Claim

After you pay the invoice, the maker locks L-BTC to the swap script. Wait for the lockup to confirm, then claim it with the preimage:

```typescript TypeScript
const claim = await script.constructClaim(preimage.preimage, {
  outputAddress: myLiquidAddress,
  swapId: swap.id,
  keysSecretHex: claimKey.secretKey,
  makerBaseUrl: "https://maker.signet.kaleidoswap.com/v2",
  network: "signet",
  liquidEsploraUrl: "https://blockstream.info/liquidtestnet/api",
});

const txid = await claim.broadcast("signet", undefined, "https://blockstream.info/liquidtestnet/api");
```

Broadcasting the claim reveals the preimage on chain, and the maker uses it to settle your Lightning payment. The swap ends in `invoice.settled`.

<Tip>
The SDK repository ships this flow as a runnable program, plus a submarine swap with refund and an Arkade corridor quote. See [Examples](/sdk/examples).
</Tip>
