## 获取帮助

报错请查看[故障排查](/cn/sdk/troubleshooting)，疑问请查看[常见问题](/cn/sdk/faq)。

其他情况请通过下面任一渠道反馈问题，并附上：

1. SDK 版本（`getVersion()` / `get_version()`）
2. 语言与运行时版本（Node.js / Python）
3. 错误信息和堆栈跟踪
4. 可复现问题的最小代码
5. 所在环境（signet / 主网）
