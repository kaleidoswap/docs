## Overview

The `KaleidoClient` is the main entry point for interacting with the KaleidoSwap API. It provides async methods for asset discovery, quote generation, swap execution, wallet operations, and Lightning Network management.

```python
from kaleidoswap_sdk import KaleidoClient

client = KaleidoClient(
    api_url="https://api.staging.kaleidoswap.com/api/v1",
    node_url="<Your node URL>",
    api_key=None,  # Optional
    ping_interval=30,
    ping_timeout=10,
    close_timeout=10,
    max_size=2**20,
    max_queue=32,
    compression=None
)
```

## Client Configuration

### KaleidoClient Parameters

| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `api_url` | `str` | Yes | - | KaleidoSwap API base URL |
| `node_url` | `str` | Yes | - | RGB Lightning node URL |
| `api_key` | `str` | No | `None` | API key for authenticated requests (future use) |
| `ping_interval` | `int` | No | `30` | WebSocket ping interval in seconds |
| `ping_timeout` | `int` | No | `10` | WebSocket ping timeout in seconds |
| `close_timeout` | `int` | No | `10` | WebSocket close timeout in seconds |
| `max_size` | `int` | No | `2**20` | Maximum WebSocket message size (1MB) |
| `max_queue` | `int` | No | `32` | Maximum WebSocket message queue size |
| `compression` | `str` | No | `None` | Optional WebSocket compression method |

## Market Operations

Methods for retrieving market data, assets, and quotes.

### `list_assets()`

Lists all available assets on the platform.

**Parameters**: None

**Returns**: `ListAssetsResponse`

**Example**:
```python
assets = await client.list_assets()
for asset in assets.assets:
    print(f"{asset.ticker}: {asset.name} ({asset.asset_id})")
```

**Response Structure**:
```python
class ListAssetsResponse(BaseModel):
    assets: List[Asset]
    network: str
    timestamp: int
```

---

### `list_pairs()`

Retrieves all available trading pairs with their configuration.

**Parameters**: None

**Returns**: `ListPairsResponse`

**Example**:
```python
pairs = await client.list_pairs()
for pair in pairs.pairs:
    if pair.is_active:
        print(f"{pair.base_asset}/{pair.quote_asset}")
```

**Response Structure**:
```python
class TradingPair(BaseModel):
    id: str
    base_asset: str
    base_asset_id: str
    base_precision: int
    quote_asset: str
    quote_asset_id: str
    quote_precision: int
    is_active: bool
    min_base_order_size: int
    max_base_order_size: int
    min_quote_order_size: int
    max_quote_order_size: int
```

### `get_quote(from_asset, to_asset, amount, to_amount=None)`

Generates a price quote for a potential trade.

**Parameters**:
- `from_asset: str` - Source asset ID or ticker
- `to_asset: str` - Destination asset ID or ticker
- `amount: int` - Amount to trade in atomic units
- `to_amount: int` (optional) - Target amount to receive

**Returns**: `QuoteResponse`

**Example**:
```python
# Quote for selling 0.001 BTC (100,000 satoshis)
quote = await client.get_quote(
    from_asset="BTC",
    to_asset="rgb:q1O5Mn5y-7EoxdTy-xu3ChkP-HmhgGvJ-vQ3ryQ9-CcMxkfg",  # USDT
    amount=100000
)
print(f"Rate: {quote.exchange_rate}")
print(f"Will receive: {quote.to_amount} atomic USDT")
```

**Error Conditions**:
- `ValidationError` - Invalid parameters
- `NetworkError` - Connection issues
- `QuoteError` - Quote generation failed

---

### `get_quote_websocket(from_asset, to_asset, amount, callback)`

Get real-time quote updates via WebSocket.

**Parameters**:
- `from_asset: str` - Source asset ID or ticker
- `to_asset: str` - Destination asset ID or ticker
- `amount: int` - Amount to trade in atomic units
- `callback: Callable` - Async callback function for quote updates

**Returns**: None (uses callback)

**Example**:
```python
async def quote_handler(quote):
    print(f"Real-time rate: {quote.exchange_rate}")

await client.connect()  # Connect WebSocket first
await client.get_quote_websocket(
    from_asset="BTC",
    to_asset="USDT",
    amount=100000,
    callback=quote_handler
)
```

## Swap Operations

Methods for executing atomic swaps on-chain and off-chain.

### `init_maker_swap(request: InitMakerSwapRequest)`

Initialize a swap transaction as the maker.

**Parameters**:
- `request: InitMakerSwapRequest` - Swap initialization parameters

**Returns**: `InitMakerSwapResponse`

**Example**:
```python
from kaleidoswap_sdk import InitMakerSwapRequest

# First get a quote
quote = await client.get_quote("BTC", "USDT", 100000)

# Initialize the swap
swap = await client.init_maker_swap(
    InitMakerSwapRequest(
        rfq_id=quote.rfq_id,
        from_asset="BTC",
        to_asset="USDT",
        from_amount=100000,
        to_amount=quote.to_amount
    )
)
print(f"Payment hash: {swap.payment_hash}")
print(f"Swapstring: {swap.swapstring}")
```

---

### `execute_maker_swap(request: ExecuteMakerSwapRequest)`

Execute a previously initialized swap.

**Parameters**:
- `request: ExecuteMakerSwapRequest` - Execution parameters

**Returns**: `ExecuteMakerSwapResponse`

**Example**:
```python
from kaleidoswap_sdk import ExecuteMakerSwapRequest

result = await client.execute_maker_swap(
    ExecuteMakerSwapRequest(
        payment_hash=swap.payment_hash,
        swapstring=swap.swapstring
    )
)
print(f"Swap executed: {result.success}")
```

---

### `complete_maker_swap(payment_hash, swapstring, invoice, input_asset)`

**Example**:

### `wait_for_swap_completion(payment_hash, timeout_seconds=300, poll_interval=5)`

Wait for a swap to complete with automatic polling.

**Parameters**:
- `payment_hash: str` - Payment hash from swap initialization
- `timeout_seconds: int` - Maximum wait time (default: 300)
- `poll_interval: int` - Seconds between status checks (default: 5)

**Returns**: `SwapStatus`

**Example**:
```python
try:
    final_status = await client.wait_for_swap_completion(
        payment_hash=swap.payment_hash,
        timeout_seconds=300,
        poll_interval=5
    )
    print(f"Swap completed: {final_status.status}")
except TimeoutError:
    print("Swap did not complete in time")
```

## Order Management

Methods for creating and managing swap orders.

### `create_order(request: CreateOrderRequest)`

Create a new swap order.

**Parameters**:
- `request: CreateOrderRequest` - Order parameters

**Returns**: `OrderResponse`

**Example**:
```python
from kaleidoswap_sdk import CreateOrderRequest

order = await client.create_order(
    CreateOrderRequest(
        rfq_id=quote.rfq_id,
        from_type="ONCHAIN",
        to_type="LIGHTNING",
        from_asset="BTC",
        to_asset="USDT",
        from_amount=100000,
        to_amount=quote.to_amount
    )
)
print(f"Order ID: {order.id}")
print(f"Payment address: {order.onchain_address}")
```

**Response Structure**:
```python
class OrderResponse(BaseModel):
    id: str
    rfq_id: str
    pay_in: str  # ONCHAIN or LIGHTNING
    onchain_address: Optional[str]
    ln_invoice: Optional[str]
    rgb_recipient_id: Optional[str]
    rgb_invoice: Optional[str]
    status: str  # PENDING_PAYMENT, COMPLETED, FAILED
```

## Context Manager Support

The Python SDK supports async context managers for automatic resource management:

```python
async with KaleidoClient(api_url="...", node_url="...") as client:
    # Client is automatically connected
    pairs = await client.list_pairs()
    # Client is automatically disconnected and closed
```
