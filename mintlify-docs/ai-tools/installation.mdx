Each AI surface installs independently. Pick the one that matches what you are building, or install the MCP gateway first since it is the smallest step to a working tool call.

| Surface | Install path | Prerequisites |
|---------|-------------|---------------|
| **[MCP servers](#mcp-servers)** | `npx -y kaleido-mcp` | Node.js 20+, an MCP host |
| **[KaleidoAgent](#kaleidoagent)** | Clone and build from source | Node.js 20+, KaleidoCLI, Nanobot, an LLM API key |
| **[KaleidoMind](#kaleidomind)** | Ships inside the Desktop App, `npm install @kaleidorg/mind` for your own host, or build the repo for development | Node.js for the starter; QVAC only for on-device inference |

<Warning>
  You can start without funds: MCP market reads need no wallet, and Mind has an offline example. When connecting a wallet, use test networks and keep seeds out of committed or shared files. `dry_run` is a KaleidoAgent setting, not a global MCP or Mind option.
</Warning>

## MCP Servers

`kaleido-mcp` is the quickest path to a first tool call, published to npm. `KALEIDO_NETWORK=signet` points it at the signet KaleidoSwap API and Spark's test network in one variable:

```bash
KALEIDO_NETWORK=signet npx -y kaleido-mcp
```

<Note>
  Directly launching the stdio server waits for an MCP client; it is not a chat prompt.
  Add the command to your client's configuration, then request a tool call.
</Note>

Spark and Liquid wallets are optional and not installed by plain `npx`. To enable them, run `npx -y -p kaleido-mcp -p @tetherto/wdk-wallet-spark -p @kaleidorg/wdk-wallet-liquid kaleido-mcp` and set `WDK_SEED` / `LIQUID_MNEMONIC`.

For the RGB tools you also need an RGB Lightning Node. [KaleidoCLI](/cli/installation) runs one on signet in Docker, see [Build a Local RGB Agent](/ai-tools/build-local-rgb-agent) for the full path.

For the tool catalog and client configuration, see [MCP Servers](/ai-tools/mcp-servers).
The unified server includes the older wallet servers' domains. Existing users can
follow the [migration notes](/ai-tools/mcp-servers#retired-servers).

## KaleidoAgent

Prerequisites: Node.js 20 or newer, [KaleidoCLI](/cli/installation) in `$PATH`, the [Nanobot](https://nanobot.dev) runtime, and an Anthropic or OpenAI API key.

```bash
git clone https://github.com/kaleidoswap/kaleido-agent.git
cd kaleido-agent
npm run install:all
```

To set the API key, configure the wallet in `agent.config.json`, start the dashboard, or deploy in a container, check the [KaleidoAgent page](/ai-tools/kaleido-agent#run-it).

## KaleidoMind

KaleidoMind is an engine for your application. Start with its offline project template, use it through the Desktop App, or embed the package directly.

### Try the offline starter

```bash
npm create @kaleidorg/mind my-agent
cd my-agent
npm install
npm run start:offline
```

Expected result: sample balances, a mock invoice and a simulated transfer. This
uses a fake wallet and scripted responses, with no node or model download.
`npm run start:mock` adds a real local model while keeping the wallet simulated.

### Through the Desktop App

The fastest path. The [Desktop App](/desktop-app/getting-started/installation) bundles the engine as in-app chat, and manages the on-device model lifecycle. Switch it on from **Settings > Capabilities** by selecting **Node + Mind** or **Only Mind**.

<Note>
  KaleidoMind depends on a local AI runtime and may not be available on Windows yet. Every trading and node feature works without it, so run the app in **Only Node** mode if Mind is unavailable on your platform.
</Note>

### In your own Node.js app

```bash
npm install @kaleidorg/mind @qvac/sdk
```

`@qvac/sdk` is an optional peer dependency, so the engine also runs without it against a mock provider. The [`@kaleidorg/mind` README](https://www.npmjs.com/package/@kaleidorg/mind) has the quickstart, and the [kaleido-mind repository](https://github.com/kaleidoswap/kaleido-mind) carries runnable examples (`examples/node-minimal`, `examples/rgb-agent`).

### From source, for development

```bash
git clone https://github.com/kaleidoswap/kaleido-mind.git
cd kaleido-mind
corepack enable
pnpm install --frozen-lockfile && pnpm build
```

The CLI in `apps/cli` handles on-device model management and runs the agent directly:

```bash
cd apps/cli
npx tsx src/index.ts setup     # guided first run: pick and pull a model
npx tsx src/index.ts run "what's my balance?"
npx tsx src/index.ts skills    # list installed skills
```

To exercise the engine against a model without a phone, use the playground from the repository root:

```bash
pnpm play "pay bob 3 eur"
```

For how the tiered funnel routes a request, the tool contract shared across transports, the skills the engine loads, and where it runs on desktop and phone, check the [KaleidoMind page](/ai-tools/kaleido-mind).
