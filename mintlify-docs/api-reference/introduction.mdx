The KaleidoSwap maker is the counterparty for every swap. Its public API is **wire-compatible with the Boltz `/v2` protocol** for submarine, reverse, and chain swaps, and adds routes for RGB assets, single-transaction atomic swaps, pay-through, swap credentials, and Lightning channel orders.

<Warning>
**Use the [Swap SDK](/sdk/introduction) instead of calling this API directly.** Every swap the maker creates must be checked against your own keys before you fund it, and every claim and refund is a transaction you build and sign. The SDK does both. Call the API directly only if you are building your own client, and read [Swap flow](/api-reference/swap-protocol) first.
</Warning>

## Base URL

| Network | Base URL |
|---|---|
| Signet (Mutinynet) | `https://maker.signet.kaleidoswap.com` |
| Mainnet | Not available yet |

All routes live under `/v2`, for example `GET https://maker.signet.kaleidoswap.com/v2/version`. The interactive playground on each endpoint page calls the signet maker.

## What is in the API

| Group | What it covers |
|---|---|
| [Service](/api-reference/service/get-maker-version) | Version, capabilities, health, node identity |
| [Pairs and quotes](/api-reference/pairs-and-quotes/list-pairs) | The routes the maker trades, their limits and fees, and quotes |
| [Submarine swaps](/api-reference/submarine-swaps/create-a-submarine-swap) | On-chain → Lightning: you lock on chain, the maker pays your invoice |
| [Reverse swaps](/api-reference/reverse-swaps/create-a-reverse-swap) | Lightning → on-chain: you pay a hold invoice, the maker locks on chain, you claim |
| [Chain swaps](/api-reference/chain-swaps/create-a-chain-swap) | On-chain → on-chain: both sides lock, you claim the maker's lockup |
| [Swap status](/api-reference/swap-status/get-swap-status) | Status over HTTP and a WebSocket stream |
| [Recovery](/api-reference/recovery/restore-swaps) | Restore swaps from an xpub, recover swap credentials |
| [Atomic RGB swaps](/api-reference/atomic-rgb-swaps/get-an-atomic-quote) | BTC ↔ RGB asset swaps in one transaction |
| [Pay-through](/api-reference/pay-through/create-a-pay-through-order) | A Lightning payment turned into an on-chain payout to any address |
| [Lightning channels (LSPS1)](/api-reference/lightning-channels-lsps1/get-channel-options) | Buy an inbound channel from the maker |
| [Chain data](/api-reference/chain-data/get-fee-estimates) | The maker's view of chain tips and fees |

The endpoint pages are generated from the maker's OpenAPI specification. Swaps between Lightning and Arkade use a separate request-for-quote corridor that the Swap SDK speaks; it is not part of this reference.
